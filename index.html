このサイトの3原則

  1. 5分考えて分からない問題は、答えを見る。考え込む時間は勉強時間ではありません。解法を覚えて、使えるようにするのが数学の勉強です。
  2. 解けた問題より、解けなかった問題を3回転。1回目は書き写す、2回目は翌日に何も見ずに、3回目は1週間後に方針だけ言えるか確認します。
  3. 満点を目指さない。合格点・目標スコアから逆算し、取れる場所を確実に取る。これが「要領」です。

公開中の解説動画（高校数学）

すべて音声ナレーション付き。手順・検算・復習のしかたまで、1本で完結します。

  1. 放物線の頂点を求める（y = x² + 8x + 5）
  2. 2次方程式を解の公式で解く（x² − 5x + 3 = 0）
  3. 異なる実数解の個数を求める（x² − 6x + 10 = 0）
  4. 正弦定理で辺の長さを求める（A = 45°, C = 75°, BC = 2）
  5. 三角形が成立する範囲（3辺が 2, x + 3, 3）
  6. 仮平均法で平均値を求める
  7. 組合せの計算を工夫する（₁₀₀C₉₈、₂₁C₁₅ + ₂₁C₁₆）
  8. 平方完成、x² の係数が 1 でないとき（y = 2x² − 12x + 5）
  9. 定義域つきの最大・最小（y = x² − 4x + 1、0 ≦ x ≦ 3）
  10. グラフの平行移動（y = 2x² を x に −1、y に +4）
  11. 余弦定理で辺の長さを求める（b = 3, c = 5, A = 60°）
  12. 三角形の面積（AB = 5, AC = 6, A = 30°）
  13. 公約数と公倍数を書き出す（24 と 36）
  14. 2次不等式を解く（x² − 5x + 6 > 0）
  15. 分散と標準偏差を求める（2, 4, 6, 8, 10）
  16. 「少なくとも1回」の確率（余事象、11/36）
  17. sinθ + cosθ = 1/2 のとき sinθcosθ（−3/8）
  18. 「隣り合う」並び方の数（6人でAとBが隣り合う、240通り）
  19. 不定方程式の整数解（3x + 5y = 1）
  20. 等差数列の和（初項 3、公差 5、第20項までで 1010）
  21. 円の接線（x² + y² = 25 上の (3, 4)、3x + 4y = 25）
  22. 3次関数の極値（x³ − 3x² − 9x + 5、極大 10・極小 −22）
  23. 対数の計算（log₂ 6 + log₂ 12 − log₂ 9 = 3）
  24. 三角関数の合成（y = sinθ + √3 cosθ、最大 2・最小 −2）
  25. 定積分で面積を求める（y = x² − 2x と x 軸、面積 4/3）
  26. 等比数列の和（初項 3、公比 2、第8項までで 765）
  27. 漸化式の一般項（aₙ₊₁ = 2aₙ + 3、aₙ = 2ⁿ⁺¹ − 3）
  28. 数列の極限と不定形（√(n² + 3n) − n = 3/2）
  29. 置換積分（∫₀¹ x√(x² + 1) dx = (2√2 − 1)/3）
  30. ベクトルのなす角（(2, 1) と (1, 3) で 45°）
  31. 複素数の極形式とド・モアブル（(1 + √3i)⁶ = 64）
