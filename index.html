このサイトの3原則

  1. 5分考えて分からない問題は、答えを見る。考え込む時間は勉強時間ではありません。解法を覚えて、使えるようにするのが数学の勉強です。
  2. 解けた問題より、解けなかった問題を3回転。1回目は書き写す、2回目は翌日に何も見ずに、3回目は1週間後に方針だけ言えるか確認します。
  3. 満点を目指さない。合格点・目標スコアから逆算し、取れる場所を確実に取る。これが「要領」です。

公開中の解説動画（高校英語・基本問題）

文法は説明を覚えるのではなく、和文から英文が出てくる「型」で覚えます。基本問題は入試英作文と文法問題の土台です。

  1. 文型の見分け方（SVOC）（動詞の後ろが名詞＋形容詞ならSVOC。訳は「OをCにする」。）
  2. 現在完了と過去形の使い分け（last Friday → 過去形、yet → 現在完了。時の語が判定基準です。）
  3. 助動詞＋have＋過去分詞（助動詞は現在形のまま、内容が過去なら have + 過去分詞。）
  4. 受動態への書きかえ（SVOO）（目的語が2つなら受動態は2通り。物を主語にしたら to / for を入れます。）
  5. to不定詞と動名詞（動詞の型）（decide は to do、avoid は doing。動詞のグループで決まります。）
  6. 分詞（現在分詞と過去分詞）（名詞が動作をする側なら doing、される側なら done。）
  7. 関係詞で2文を1文にする（共通語を消して、空いた位置が主語なら who/which、目的語なら which（省略可）。）
  8. 比較の書きかえ（as 〜 as と最上級）（「〜ほど…ない」は not as 原級 as、「〜より…はいない」は No other + 単数 + 比較級。）
  9. 仮定法過去と仮定法過去完了（現在の仮定は過去形＋would 原形、過去の仮定は had p.p.＋would have p.p.。）
  10. 接続詞と前置詞の使い分け（後ろが名詞なら前置詞、主語＋動詞なら接続詞。）

公開中の解説動画（高校英語・中級レベル）

基本問題の型が入ったら、構文（分詞構文・強調・倒置）と応用（関係詞・比較・仮定法・否定）に進みます。長文を読む速度が変わる10本です。

  1. 分詞構文の作り方（接続詞を消し、同じ主語を消して doing。受け身は done、否定は Not doing。）
  2. 使役動詞と知覚動詞（make / let / have は原形、知覚は原形・doing・done の3択。受動態で to が出ます。）
  3. 強調構文と否定の倒置（It is 強調語 that 残り。否定語が文頭なら疑問文の語順に倒置します。）
  4. 名詞節と同格のthat（that / whether / 疑問詞の名詞節。名詞＋that＋完全な文は同格です。）
  5. 時制の一致と話法の転換（時制を1つ過去へ、疑問文は ask + if、命令文は tell O to do。）
  6. 関係代名詞whatと前置詞＋関係代名詞（what は先行詞を含む。前置詞を前に出したら that は不可・省略不可です。）
  7. 完了不定詞と完了動名詞（主節より前のことは to have done / having done。同時なら単純形です。）
  8. 比較の応用（the 比較級と差の表現）（The 比較級 …, the 比較級 …。2者間は the + 比較級 + of the two。）
  9. 仮定法の応用（But for と as if）（But for = If it were / had not been for。as if は同時なら過去形。）
  10. 否定・準否定の表現（No sooner had S p.p. … than S 過去形、not … until は「〜して初めて」。）
