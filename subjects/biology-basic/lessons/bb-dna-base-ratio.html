第4回　DNAの構造と塩基の割合（AとTは必ず等しい）

ある生物の2本鎖DNAで、アデニンが全塩基の28 %を占めていた。グアニンの割合を求めよ。また片方の鎖でアデニンが32 %のとき、もう一方の鎖のチミンの割合を求めよ。

塩基の計算は条件が2つだけです。1本鎖か2本鎖かを最初に見ます。

解法の型

  1. 相補性を式にする。2本鎖全体では A = T、G = C。
  2. 合計100 %。A + T + G + C = 100。ここに A = T、G = C を入れると1本の式になります。
  3. 1本鎖の問題は「相手に移す」。ある鎖のAの割合は、相補鎖のTの割合と同じです。

解答手順

  1. A = T を使う
    A = 28 % なので T = 28 %

    対になる塩基。

  2. 残りをG・Cで分ける
    100 − (28 + 28) = 44 %

    GとCの合計。

  3. Gを出す
    G = C = 44 ÷ 2 = 22 %

    GとCも等しい。

  4. 1本鎖の対応
    ある鎖のA 32 % → 相補鎖のT 32 %

    鎖をまたぐと入れ替わる。

  5. 答えをまとめる
    G = 22 %、相補鎖のT = 32 %

    全体と1本鎖を区別する。

検算：28 + 28 + 22 + 22 = 100 %。A = T、G = Cも満たしており整合します。

差がつく2行

  1. A = T、G = Cが成り立つのは2本鎖全体だけです。1本鎖では成り立ちません。
  2. G-Cの対は水素結合が3本で強いため、GC含量が高いDNAは熱に強くなります。

覚えるべきこと（在庫に入れる1行）

2本鎖ならA=T、G=C。合計100 %。1本鎖では成り立たない。

類題（翌日、何も見ずに）

  1. 2本鎖DNAでGが20 %のとき、Aの割合を求めよ。
    答え

    G = C = 20なので A = T = 30 %

  2. ある鎖の塩基配列がATGCのとき、相補鎖の配列を答えよ。
    答え

    TACG（向きを考えるとCGTA）

解説の全文を読む
  1. こんにちは。知多丸の落ちこぼれ救済チャンネルです。難関大学に合格して、錯覚資産を手に入れて、一流企業に入社しよう。今日の問題です。ある生物の2本鎖ディーエヌエーで、アデニンが全塩基の28パーセントを占めていました。グアニンの割合を求めてください。また片方の鎖でアデニンが32パーセントのとき、もう一方の鎖のチミンの割合も求めてください。
  2. 型はこうです。2本鎖のディーエヌエーでは、アデニンとチミン、グアニンとシトシンが必ず対になるので、割合も等しくなります。全部を足すと100パーセント。この2つの条件だけで割合の問題は全部解けます。片方の鎖だけを見る問題では、その鎖のアデニンが相手の鎖のチミンになる、という対応で読み替えます。
  3. まずアデニンが28パーセントなので、対になるチミンも28パーセントです。
  4. 全体が100パーセントなので、グアニンとシトシンの合計は100ひく56で44パーセントです。
  5. グアニンとシトシンも等しいので、44を2で割って、グアニンは22パーセントです。
  6. 次に1本鎖です。片方の鎖のアデニンは、相手の鎖ではチミンと対になっているので、相補鎖のチミンも32パーセントです。
  7. 答えは、グアニンが22パーセント、相補鎖のチミンが32パーセントです。
  8. 検算です。全体の割合を足します。アデニン28、チミン28、グアニン22、シトシン22。合計100パーセントで、条件を満たしています。またアデニンとチミンの和が56、グアニンとシトシンの和が44。等しくないのは問題ないので、これで正しいです。
  9. 差がつく2行です。ひとつ目、1本鎖だけを見るとアデニンとチミンは等しくなりません。等しいのは2本鎖全体を見たときだけです。ここが最も出題される落とし穴です。ふたつ目、アデニンとチミンの割合が高い生物ほど、熱に弱い傾向があります。グアニンとシトシンの対の方が結合が強いためです。
  10. 在庫に入れる1行です。2本鎖ならアデニン イコール チミン、グアニン イコール シトシン。合計100パーセント。1本鎖では成り立たない。チャンネル登録をして、次の動画でも一緒に、要領よく積み上げていきましょう。
