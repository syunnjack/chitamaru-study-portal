第4回　DNAの構造と塩基の割合（AとTは必ず等しい）

ある生物の2本鎖DNAで、アデニンが全塩基の28 %を占めていた。グアニンの割合を求めよ。また片方の鎖でアデニンが32 %のとき、もう一方の鎖のチミンの割合を求めよ。

塩基の計算は条件が2つだけです。1本鎖か2本鎖かを最初に見ます。

解法の型

  1. 相補性を式にする。2本鎖全体では A = T、G = C。
  2. 合計100 %。A + T + G + C = 100。ここに A = T、G = C を入れると1本の式になります。
  3. 1本鎖の問題は「相手に移す」。ある鎖のAの割合は、相補鎖のTの割合と同じです。

解答手順

  1. A = T を使う
    A = 28 % なので T = 28 %

    対になる塩基。

  2. 残りをG・Cで分ける
    100 − (28 + 28) = 44 %

    GとCの合計。

  3. Gを出す
    G = C = 44 ÷ 2 = 22 %

    GとCも等しい。

  4. 1本鎖の対応
    ある鎖のA 32 % → 相補鎖のT 32 %

    鎖をまたぐと入れ替わる。

  5. 答えをまとめる
    G = 22 %、相補鎖のT = 32 %

    全体と1本鎖を区別する。

検算：28 + 28 + 22 + 22 = 100 %。A = T、G = Cも満たしており整合します。

差がつく2行

  1. A = T、G = Cが成り立つのは2本鎖全体だけです。1本鎖では成り立ちません。
  2. G-Cの対は水素結合が3本で強いため、GC含量が高いDNAは熱に強くなります。

覚えるべきこと（在庫に入れる1行）

2本鎖ならA=T、G=C。合計100 %。1本鎖では成り立たない。

類題（翌日、何も見ずに）

  1. 2本鎖DNAでGが20 %のとき、Aの割合を求めよ。
    答え

    G = C = 20なので A = T = 30 %

  2. ある鎖の塩基配列がATGCのとき、相補鎖の配列を答えよ。
    答え

    TACG（向きを考えるとCGTA）
