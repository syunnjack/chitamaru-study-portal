第3回　光合成と呼吸（ATPを中心に置く）

光合成と呼吸について、①反応の場所 ②使う物質 ③できる物質 ④エネルギーの流れを対応させて答えよ。またATPが「エネルギーの通貨」と呼ばれる理由を1行で答えよ。

表で覚えると混ざります。逆向きの矢印1本にしてしまいます。

解法の型

  1. 2つを逆向きに書く。呼吸は有機物を分解してATPを得る、光合成は光でATPをつくり有機物を合成する。
  2. 場所を必ずセットで。呼吸＝ミトコンドリア、光合成＝葉緑体。
  3. ATPを中心に置く。「エネルギーを取り出す→ATP→使う」という流れで全体をつなぎます。

解答手順

  1. 呼吸を整理する
    ミトコンドリア：有機物 + O₂ → CO₂ + H₂O + ATP

    分解してATPを得る。

  2. 光合成を整理する
    葉緑体：CO₂ + H₂O + 光 → 有機物 + O₂

    光エネルギーを化学エネルギーに。

  3. エネルギーの流れ
    光 → 有機物（化学エネルギー）→ ATP → 生命活動

    一方向に流れる。

  4. ATPの理由
    どの反応でも共通に使える形でエネルギーを受け渡すから

    通貨のたとえ。

検算：光合成と呼吸で CO₂ と O₂ の役割が入れ替わっていることを確認します。逆向きの関係で整理できています。

差がつく2行

  1. 植物も昼夜を通じて呼吸しています。昼は光合成量が呼吸量を上回るだけです。
  2. ATPはADPとリン酸に分かれるときにエネルギーを放出します。逆に合成するときは吸収します。

覚えるべきこと（在庫に入れる1行）

呼吸＝ミトコンドリアで分解、光合成＝葉緑体で合成。ATPが通貨。

類題（翌日、何も見ずに）

  1. 光合成でつくられる気体と、呼吸で使われる気体を答えよ。
    答え

    どちらも酸素

  2. 暗所に置いた植物が二酸化炭素を出す理由を1行で答えよ。
    答え

    光合成が止まり呼吸だけが行われるから

解説の全文を読む
  1. こんにちは。知多丸の落ちこぼれ救済チャンネルです。難関大学に合格して、錯覚資産を手に入れて、一流企業に入社しよう。今日の問題です。光合成と呼吸について、反応の場所、使う物質、できる物質、エネルギーの流れを対応させて答えてください。またエーティーピーがエネルギーの通貨と呼ばれる理由も、1行で答えてください。
  2. 型はこうです。光合成と呼吸は互いに逆向きの反応です。呼吸はミトコンドリアで、有機物と酸素から二酸化炭素と水をつくり、エーティーピーを取り出します。光合成は葉緑体で、光のエネルギーを使って二酸化炭素と水から有機物と酸素をつくります。表を丸暗記せず、逆向きの矢印1本として覚えるのがコツです。
  3. まず呼吸です。場所はミトコンドリア。有機物と酸素を使って、二酸化炭素と水ができ、エーティーピーが取り出されます。
  4. 次に光合成です。場所は葉緑体。光のエネルギーを使って、二酸化炭素と水から有機物と酸素ができます。
  5. エネルギーは、光から有機物の化学エネルギーへ、そして呼吸でエーティーピーへ、最後に生命活動へと流れます。
  6. エーティーピーがエネルギーの通貨と呼ばれるのは、どの生物のどの反応でも共通に使える形でエネルギーを受け渡せるからです。
  7. 検算です。物質の向きで確かめます。光合成が二酸化炭素を使って酸素を出す、呼吸が酸素を使って二酸化炭素を出す。ちょうど入れ替わっているので、逆向きの関係として正しく整理できています。
  8. 差がつく2行です。ひとつ目、植物も呼吸をしています。昼は光合成の方が量が多いので見かけ上は二酸化炭素を吸っているだけで、呼吸を止めているわけではありません。ふたつ目、エーティーピーはリン酸どうしの結合が切れるときにエネルギーを出します。エーティーピーがエーディーピーとリン酸に分かれる、この1行を書けるようにしておきます。
  9. 在庫に入れる1行です。呼吸はミトコンドリアで分解、光合成は葉緑体で合成。エーティーピーがエネルギーの通貨。チャンネル登録をして、次の動画でも一緒に、要領よく積み上げていきましょう。
