第10回　植生の遷移と生態系（順番と物質の流れ）

裸地から始まる植生の遷移の順序を答えよ。また遷移が進むにつれて土壌と光の条件がどう変わるか、極相林で陰樹が優占する理由とあわせて答えよ。

遷移は順番の暗記ではなく、明るさの変化から結論を導きます。

解法の型

  1. 順序を1本の線に。裸地 → コケ・地衣類 → 草原 → 低木林 → 陽樹林 → 混交林 → 陰樹林（極相）。
  2. 変化の向きを覚える。土壌は厚く、保水力は増し、林床は暗くなります。
  3. 結論は明るさから導く。暗い林床で育つのは陰樹の幼木だけ。だから極相は陰樹林になります。

解答手順

  1. 順序を書く
    裸地 → コケ・地衣類 → 草原 → 低木林 → 陽樹林 → 混交林 → 陰樹林

    極相は陰樹林。

  2. 土壌の変化
    有機物がたまり土壌は厚くなる（保水力が増す）

    植物が住める条件が良くなる。

  3. 光の変化
    樹高が高くなり林床は暗くなる

    光が届かなくなる。

  4. 陰樹が残る理由
    暗い林床では陽樹の幼木は育たず、陰樹の幼木だけが育つ

    だから陰樹林が極相。

検算：実際に陰樹林が極相になる事実が、「林床が暗くなる」という説明の裏づけになります。

差がつく2行

  1. 倒木などでギャップができると光が入り、そこだけ陽樹が育ちます。極相林も一様ではありません。
  2. 生態系では物質は循環しますが、エネルギーは熱として出ていく一方通行です。

覚えるべきこと（在庫に入れる1行）

遷移は明るさで決まる。暗い林床で育つ陰樹が極相になる。

類題（翌日、何も見ずに）

  1. 陽樹と陰樹の幼木のうち、暗い林床で育つのはどちらか。
    答え

    陰樹の幼木

  2. 生態系で物質とエネルギーの流れ方の違いを1行で答えよ。
    答え

    物質は循環するが、エネルギーは熱として出ていく一方通行
