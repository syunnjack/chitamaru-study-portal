第15回　組成式の決定（質量比をmol比に直す）

銅の粉末4.0 gを空気中で完全に酸化させたところ、酸化物が5.0 g得られた。この酸化物の組成式を求めよ（Cu = 64、O = 16）。

質量比のまま比を取ると必ず間違います。原子量で割ってから比にします。

解法の型

  1. 酸素の質量を引き算で出す。質量保存の法則より、増えた分がすべて結びついた酸素です。
  2. 質量 ÷ 原子量 で mol にする。ここで初めて「個数」の情報になります。
  3. 最も簡単な整数比に直す。1:1 なら CuO、2:1 なら Cu₂O です。

解答手順

  1. 酸素の質量
    5.0 − 4.0 = 1.0 g

    増えた分が酸素。

  2. molに直す
    Cu：4.0/64 = 0.0625 mol、O：1.0/16 = 0.0625 mol

    原子量で割るだけ。

  3. 比を取る
    Cu : O = 0.0625 : 0.0625 = 1 : 1

    個数比になっている。

  4. 組成式を書く
    CuO（酸化銅(II)）

    質量比4:1ではない。

検算：CuO の式量80のうち銅は64で80 %。5.0 × 0.80 = 4.0 g となり、はじめの銅と一致します。

差がつく2行

  1. 質量比4:1をそのまま使うのは誤りです。原子1個の重さが違うので、必ず原子量で割ってから比を取ります。
  2. 比が 1 : 1.5 になったら2倍して 2 : 3。整数比になるまで、最小値で割ってから倍にします。

覚えるべきこと（在庫に入れる1行）

組成式は質量 ÷ 原子量 の比。質量比のまま比を取らない。

類題（翌日、何も見ずに）

  1. マグネシウム 4.8 g が完全に酸化して 8.0 g になった。組成式を求めよ（Mg = 24、O = 16）。
    答え

    Mg 0.20 : O 0.20 = 1:1 → MgO

  2. 鉄 5.6 g に酸素 2.4 g が結びついた酸化物の組成式を求めよ（Fe = 56、O = 16）。
    答え

    Fe 0.10 : O 0.15 = 2:3 → Fe₂O₃
