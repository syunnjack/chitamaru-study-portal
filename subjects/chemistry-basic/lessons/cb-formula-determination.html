第15回　組成式の決定（質量比をmol比に直す）

銅の粉末4.0 gを空気中で完全に酸化させたところ、酸化物が5.0 g得られた。この酸化物の組成式を求めよ（Cu = 64、O = 16）。

質量比のまま比を取ると必ず間違います。原子量で割ってから比にします。

解法の型

  1. 酸素の質量を引き算で出す。質量保存の法則より、増えた分がすべて結びついた酸素です。
  2. 質量 ÷ 原子量 で mol にする。ここで初めて「個数」の情報になります。
  3. 最も簡単な整数比に直す。1:1 なら CuO、2:1 なら Cu₂O です。

解答手順

  1. 酸素の質量
    5.0 − 4.0 = 1.0 g

    増えた分が酸素。

  2. molに直す
    Cu：4.0/64 = 0.0625 mol、O：1.0/16 = 0.0625 mol

    原子量で割るだけ。

  3. 比を取る
    Cu : O = 0.0625 : 0.0625 = 1 : 1

    個数比になっている。

  4. 組成式を書く
    CuO（酸化銅(II)）

    質量比4:1ではない。

検算：CuO の式量80のうち銅は64で80 %。5.0 × 0.80 = 4.0 g となり、はじめの銅と一致します。

差がつく2行

  1. 質量比4:1をそのまま使うのは誤りです。原子1個の重さが違うので、必ず原子量で割ってから比を取ります。
  2. 比が 1 : 1.5 になったら2倍して 2 : 3。整数比になるまで、最小値で割ってから倍にします。

覚えるべきこと（在庫に入れる1行）

組成式は質量 ÷ 原子量 の比。質量比のまま比を取らない。

類題（翌日、何も見ずに）

  1. マグネシウム 4.8 g が完全に酸化して 8.0 g になった。組成式を求めよ（Mg = 24、O = 16）。
    答え

    Mg 0.20 : O 0.20 = 1:1 → MgO

  2. 鉄 5.6 g に酸素 2.4 g が結びついた酸化物の組成式を求めよ（Fe = 56、O = 16）。
    答え

    Fe 0.10 : O 0.15 = 2:3 → Fe₂O₃

解説の全文を読む
  1. こんにちは。知多丸の落ちこぼれ救済チャンネルです。難関大学に合格して、錯覚資産を手に入れて、一流企業に入社しよう。今日の問題です。銅の粉末4.0グラムを空気中で完全に酸化させたところ、酸化物が5.0グラム得られました。この酸化物の組成式を求めてください。銅の原子量は64、酸素の原子量は16です。
  2. 型はこうです。組成式は原子の個数比を表しています。だから質量比をそのまま使ってはいけません。まず結びついた酸素の質量を、酸化物の質量から金属の質量を引いて求めます。次に、それぞれの質量を原子量で割って物質量にします。物質量の比が原子の個数比なので、最後に最も簡単な整数比に直せば組成式が出ます。質量比のまま比を取ってしまうのが、この分野で一番多い失点です。
  3. まず結びついた酸素の質量です。5.0グラムから4.0グラムを引いて1.0グラムです。
  4. 次に物質量です。銅は4.0を64で割って0.0625モル、酸素は1.0を16で割って0.0625モルです。
  5. 比を取ると、銅と酸素はちょうど1対1です。
  6. したがって組成式はCuO、酸化銅2です。質量比は4対1でしたが、組成式は1対1になります。
  7. 検算です。CuOの式量は64たす16で80。この中で銅の占める割合は64割る80で0.80、つまり80パーセント。5.0グラムの80パーセントは4.0グラムで、はじめの銅の質量と一致します。
  8. 差がつく2行です。ひとつ目、質量比のまま比を取ってはいけません。4対1で Cu₄O としてしまう誤りが最頻出です。ふたつ目、割り切れない比が出たときは、全部を最小の値で割ってから、必要なら2倍3倍します。たとえば1対1.5なら2対3にします。
  9. 在庫に入れる1行です。組成式は、質量を原子量で割った値の比。質量比のまま比を取らない。チャンネル登録をして、次の動画でも一緒に、要領よく積み上げていきましょう。
