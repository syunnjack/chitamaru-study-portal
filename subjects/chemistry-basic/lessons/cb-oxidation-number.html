第9回　酸化数と酸化還元（数字で判定する）

次の下線の原子の酸化数を求めよ。①H₂S の S ②HNO₃ の N ③KMnO₄ の Mn。また、酸化数が増えた原子は酸化されたか還元されたか答えよ。

酸化還元は感覚ではなく数字で判定します。酸化数を出すだけです。

解法の型

  1. 決まっている値から埋める。単体0、H は +1、O は −2、アルカリ金属は +1。
  2. 合計で方程式にする。化合物は合計0、多原子イオンは合計がその電荷。
  3. 増えたら酸化、減ったら還元。電子を失う＝酸化数が増える、と対応づけます。

解答手順

  1. H₂S の S
    (+1)×2 + x = 0 → x = −2

    Hは+1が2個。

  2. HNO₃ の N
    (+1) + x + (−2)×3 = 0 → x = +5

    Oは−2が3個。

  3. KMnO₄ の Mn
    (+1) + x + (−2)×4 = 0 → x = +7

    Kは+1。

  4. 酸化か還元か
    酸化数が増えた原子は「酸化された」

    電子を失った側。

検算：Mnの+7は最大の酸化数で、KMnO₄が強い酸化剤である事実と一致します。

差がつく2行

  1. 酸化剤は相手を酸化し、自分は還元されます。名前は「相手への作用」を表しています。
  2. 過酸化水素H₂O₂の酸素は−1です。Oが−2の例外はここだけ覚えれば足ります。

覚えるべきこと（在庫に入れる1行）

単体0・H+1・O−2で埋めて合計0。増えたら酸化、減ったら還元。

類題（翌日、何も見ずに）

  1. SO₂ の S の酸化数を求めよ。
    答え

    x + (−2)×2 = 0 より +4

  2. MnO₄⁻ の Mn の酸化数を求めよ。
    答え

    x + (−2)×4 = −1 より +7

解説の全文を読む
  1. こんにちは。知多丸の落ちこぼれ救済チャンネルです。難関大学に合格して、錯覚資産を手に入れて、一流企業に入社しよう。今日の問題です。次の原子の酸化数を求めてください。ひとつ目、硫化水素の硫黄。ふたつ目、硝酸の窒素。みっつ目、過マンガン酸カリウムのマンガン。また、酸化数が増えた原子は酸化されたのか還元されたのかも答えてください。
  2. 型はこうです。酸化数は決め方が固定されています。単体はゼロ、水素はプラス1、酸素はマイナス2。化合物なら合計がゼロ、イオンなら合計がその電荷と同じ。この規則で、残ったひとつを方程式で出すだけです。そして酸化数が増えたら酸化された、減ったら還元された。電子を失うと酸化数が増える、と結びつけて覚えます。
  3. ひとつ目、硫化水素です。水素がプラス1で2個あるので、プラス2たすエックスがゼロ。硫黄の酸化数はマイナス2です。
  4. ふたつ目、硝酸です。水素のプラス1、酸素マイナス2が3個で合計マイナス6。全体がゼロになるので、窒素はプラス5です。
  5. みっつ目、過マンガン酸カリウムです。カリウムがプラス1、酸素マイナス2が4個でマイナス8。マンガンはプラス7になります。
  6. そして酸化数が増えた原子は、電子を失ったので酸化されたことになります。
  7. 検算です。マンガンのプラス7は、マンガンが取りうる最大の酸化数です。だから過マンガン酸カリウムはこれ以上酸化されず、強い酸化剤としてはたらきます。実際の性質と一致するので、計算が合っていると確認できます。
  8. 差がつく2行です。ひとつ目、酸化剤と還元剤の見分けは、相手を酸化するのが酸化剤で、そのとき自分は還元されます。自分がどちらになるかで混乱するので、名前は相手への作用だと覚えます。ふたつ目、過酸化水素の酸素はマイナス1です。マイナス2の例外はこれだけ押さえれば十分です。
  9. 在庫に入れる1行です。単体ゼロ、水素プラス1、酸素マイナス2で埋めて合計ゼロ。増えたら酸化、減ったら還元。チャンネル登録をして、次の動画でも一緒に、要領よく積み上げていきましょう。
