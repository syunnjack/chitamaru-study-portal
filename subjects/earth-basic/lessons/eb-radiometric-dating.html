第12回　放射性同位体と年代測定（半分になる回数を数える）

半減期が7000万年の放射性同位体について、岩石中に残っている量が最初の8分の1になっていた。この岩石ができてからの年数を求めよ。

半減期は割り算ではなく「何回半分になったか」を数える問題です。

解法の型

  1. 残る割合を (1/2)^n の形にする。1/2、1/4、1/8、1/16 は順に n = 1, 2, 3, 4。
  2. n を読み取る。「何回半分になったか」だけを数えます。
  3. 年数 = 半減期 × n。掛け算1回で終わり。減った側の割合と混同しないこと。

解答手順

  1. 割合を指数にする
    1/8 = (1/2)^3

    半分が3回。

  2. 回数を読む
    n = 3（半減期が3回過ぎた）

    回数を数えるだけ。

  3. 年数を計算する
    7000万年 × 3 = 2億1000万年

    掛けるだけ。

  4. 答えをまとめる
    約 2.1 × 10^8 年（2億1000万年）

    桁も確認。

検算：7000万年で1/2、1億4000万年で1/4、2億1000万年で1/8。条件と一致します。

差がつく2行

  1. 「8分の7が減った」なら残りは8分の1。減少分は必ず残存量に直してから指数にします。
  2. 半減期の長さで使い分けます。炭素14は数万年以内、ウランやカリウムは数億年以上の岩石に使います。

覚えるべきこと（在庫に入れる1行）

残る割合 = (1/2)^n。年数は半減期 × n。

類題（翌日、何も見ずに）

  1. 半減期5000年の同位体が最初の1/4になった。経過年数を求めよ。
    答え

    (1/2)^2 より n = 2、5000 × 2 = 10000年

  2. 最初の量の15/16が失われたとき、半減期は何回過ぎたか。
    答え

    残りは1/16 = (1/2)^4 なので4回
