高校英語

英語は「理解した量」ではなく「回転させた量」で伸びます。文法は説明を暗記するのではなく、そのまま書ける例文を暗記します。

この科目の攻略方針

  1. 文法は例文暗記。ルールの説明よりも、和文から英文が出てくる状態を作ります。
  2. 単語は1冊を高速で何周も。1周目で覚えようとしないのが要領です。
  3. 長文は構文が取れた文だけ音読。意味が曖昧なまま音読しても伸びません。

基本問題：文と動詞の型（第1〜5回）

第1回・動画あり

文型の見分け方（SVOC）

動詞の後ろが「名詞＋形容詞」ならSVOC。make / keep / find / leave が目印です。

 第2回・動画あり

現在完了と過去形の使い分け

last Friday は過去形、yet は現在完了。時の語だけで判定します。

 第3回・動画あり

助動詞＋have＋過去分詞

判断は今、内容は過去。may / must / cannot / should have done の4本を型で覚えます。

 第4回・動画あり

受動態への書きかえ（SVOO）

目的語2つなら受動態は2通り。物を主語にしたときだけ to / for が必要です。

 第5回・動画あり

to不定詞と動名詞（動詞の型）

decide to do / avoid doing。動詞のグループで暗記し、remember・stop の差も押さえます。

基本問題：修飾と比較・仮定の型（第6〜10回）

第6回・動画あり

分詞（現在分詞と過去分詞）

名詞が「する側」なら doing、「される側」なら done。関係代名詞に戻して検算します。

 第7回・動画あり

関係詞で2文を1文にする

共通語を消し、空いた位置が主語か目的語かで関係詞を決めます。

 第8回・動画あり

比較の書きかえ（as 〜 as と最上級）

not as 原級 as と No other + 単数 + 比較級。最上級への言いかえで検算します。

 第9回・動画あり

仮定法過去と仮定法過去完了

現在の仮定は過去形＋would 原形、過去の仮定は had p.p.＋would have p.p.。

 第10回・動画あり

接続詞と前置詞の使い分け

後ろが名詞なら because of / during、主語＋動詞なら because / while。

中級レベル：構文の型（第11〜15回）

第11回・動画あり

分詞構文の作り方

接続詞を消し、同じ主語を消して doing。受け身は done、否定は Not doing。

 第12回・動画あり

使役動詞と知覚動詞

make / let / have は原形、知覚は原形・doing・done の3択。受動態で to が出ます。

 第13回・動画あり

強調構文と否定の倒置

It is 強調語 that 残り。否定語が文頭なら疑問文の語順に倒置します。

 第14回・動画あり

名詞節と同格のthat

that / whether / 疑問詞の名詞節。名詞＋that＋完全な文は同格です。

 第15回・動画あり

時制の一致と話法の転換

時制を1つ過去へ、疑問文は ask + if、命令文は tell O to do。

中級レベル：関係詞・比較・仮定の型（第16〜20回）

第16回・動画あり

関係代名詞whatと前置詞＋関係代名詞

what は先行詞を含む。前置詞を前に出したら that は不可・省略不可です。

 第17回・動画あり

完了不定詞と完了動名詞

主節より前のことは to have done / having done。同時なら単純形です。

 第18回・動画あり

比較の応用（the 比較級と差の表現）

The 比較級 …, the 比較級 …。2者間は the + 比較級 + of the two。

 第19回・動画あり

仮定法の応用（But for と as if）

No sooner had S p.p. … than S 過去形、not … until は「〜して初めて」。
