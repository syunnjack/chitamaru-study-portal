高校英語

英語は「理解した量」ではなく「回転させた量」で伸びます。文法は説明を暗記するのではなく、そのまま書ける例文を暗記します。

この科目の攻略方針

  1. 文法は例文暗記。ルールの説明よりも、和文から英文が出てくる状態を作ります。
  2. 単語は1冊を高速で何周も。1周目で覚えようとしないのが要領です。
  3. 長文は構文が取れた文だけ音読。意味が曖昧なまま音読しても伸びません。

基本問題：文と動詞の型（第1〜5回）

第1回・動画あり

文型の見分け方（SVOC）

動詞の後ろが「名詞＋形容詞」ならSVOC。make / keep / find / leave が目印です。

 第2回・動画あり

現在完了と過去形の使い分け

last Friday は過去形、yet は現在完了。時の語だけで判定します。

 第3回・動画あり

助動詞＋have＋過去分詞

判断は今、内容は過去。may / must / cannot / should have done の4本を型で覚えます。

 第4回・動画あり

受動態への書きかえ（SVOO）

目的語2つなら受動態は2通り。物を主語にしたときだけ to / for が必要です。

 第5回・動画あり

to不定詞と動名詞（動詞の型）

decide to do / avoid doing。動詞のグループで暗記し、remember・stop の差も押さえます。

基本問題：修飾と比較・仮定の型（第6〜10回）

第6回・動画あり

分詞（現在分詞と過去分詞）

名詞が「する側」なら doing、「される側」なら done。関係代名詞に戻して検算します。

 第7回・動画あり

関係詞で2文を1文にする

共通語を消し、空いた位置が主語か目的語かで関係詞を決めます。

 第8回・動画あり

比較の書きかえ（as ~ as と最上級）

not as 原級 as と No other + 単数 + 比較級。最上級への言いかえで検算します。

 第9回・動画あり

仮定法過去と仮定法過去完了

現在の仮定は過去形＋would 原形、過去の仮定は had p.p.＋would have p.p.。

 第10回・動画あり

接続詞と前置詞の使い分け

後ろが名詞なら because of / during、主語＋動詞なら because / while。
