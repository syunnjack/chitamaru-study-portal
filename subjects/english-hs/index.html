トップ ／ 高校英語

高校英語

英文法を説明だけで覚えず、判定手順＋例文をセットで在庫化します。第1回から順番に進めれば、高校英語の骨格を一周できます。

知多丸式の回し方

  1. 動画・解説で型を理解する。
  2. 例文を声に出し、日本語から英文を再現する。
  3. 翌日に何も見ずに判定する。
  4. 1週間後にもう一度解き、長期記憶へ移す。

英文法 基礎9講

第1回

5文型

動詞の後ろと S=C / O=C で判定。

第2回

時制

現在・過去・未来・完了を時間軸で整理。

第3回

助動詞

can・may・must・shouldを意味の強さで整理。

第4回

不定詞

to do の名詞・形容詞・副詞用法。

第5回

動名詞

doing と不定詞の使い分け。

第6回

分詞

doing / done を能動・受動で判断。

第7回

関係詞

先行詞と後ろの文の欠けを探す。

第8回

比較

原級・比較級・最上級を3つの型で攻略。

第9回

仮定法

現実から時制をずらす考え方で理解。

次段階

基礎9講の次は、受動態・疑問文・否定・接続詞・前置詞・英文解釈・長文読解・英作文へ拡張できる構造です。
