第30回　自由英作文：譲歩と反論の型

次のテーマについて、譲歩を入れた構成で80語程度の英語で書け。 Should students be allowed to use smartphones during class?

上級の答案は、反対意見を先に認めます。それだけで説得力が変わります。

解法の型

  1. 譲歩（1〜2文）。It is true that … / Admittedly, … 。
  2. 反論＋主張（1文）。However, I believe … 。
  3. 理由1つ＋結論。This is because … / Therefore, … 。

解答手順

  1. 譲歩を書く
    It is true that smartphones can help students look up information quickly.

    反対意見を認める。

  2. 反論して主張を出す
    However, I believe they should not be used freely during class.

    However の後が自分の主張。

  3. 理由を書く
    This is because most students cannot resist checking messages.

    理由は1つで十分。

  4. 条件つきの結論で閉じる
    Therefore, phones should be used only when the teacher asks students to use them.

    答え：譲歩＋反論＋理由＋条件つき結論

検算：譲歩を全否定すると論理が崩れます。条件をずらして両立させます。

差がつく2行

  1. 譲歩の表現は It is true that … / Admittedly, … / Of course, … の3つで足ります。
  2. 結論に only when / as long as の条件を入れると、答案が具体的になります。

覚えるべきこと（在庫に入れる1行）

上級の答案は「譲歩 → However で反論 → 理由 → 条件つき結論」。

類題（翌日、何も見ずに）

  1. 譲歩を表す表現を3つ挙げよ。
    答え

    It is true that … / Admittedly, … / Of course, …

  2. 結論を具体的にするために使える条件表現を挙げよ。
    答え

    only when 〜 / as long as 〜
