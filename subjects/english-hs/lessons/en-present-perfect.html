第2回　現在完了と過去形の使い分け

I ( lose ) my student ID last Friday, and I ( not find ) it yet.　( )内を適する形にせよ。

現在完了は「気持ち」で選ぶものではありません。文中の時の語で機械的に決まります。

解法の型

  1. 時の語を先に探す。意味から考えず、目印の語で決めます。
  2. 過去の一点（last Friday / yesterday / two days ago）→ 過去形。
  3. 今とのつながり（yet / already / just / since / for）→ have + 過去分詞。

解答手順

  1. 前半の時の語
    last Friday → 過去の一点

    現在完了とは一緒に使えない。

  2. 前半を決める
    I lost my student ID last Friday.
  3. 後半の時の語
    yet → 今の時点の話

    「まだ見つかっていない」＝今も継続中の結果。

  4. 後半を決める
    I haven't found it yet.

    答え：lost / haven't found

検算：「have lost … last Friday」は不可。現在完了は過去の一点を表す語と共存できません。

差がつく2行

  1. 現在完了の訳は「〜してしまっている」。今どうなのかまで含めて訳すと使い分けを間違えません。
  2. When で始まる疑問文は現在完了にできません。× When have you visited …? ○ When did you visit …?

覚えるべきこと（在庫に入れる1行）

last / ago があれば過去形、yet / since / for があれば have + 過去分詞。

類題（翌日、何も見ずに）

  1. She ( live ) in Osaka since 2021. を適する形に。
    答え

    has lived（since があるので現在完了）

  2. When ( you visit ) the science museum? を適する形に。
    答え

    did you visit（When の疑問文は過去形）
