第2回　現在完了と過去形の使い分け

I ( lose ) my student ID last Friday, and I ( not find ) it yet.　( )内を適する形にせよ。

現在完了は「気持ち」で選ぶものではありません。文中の時の語で機械的に決まります。

解法の型

  1. 時の語を先に探す。意味から考えず、目印の語で決めます。
  2. 過去の一点（last Friday / yesterday / two days ago）→ 過去形。
  3. 今とのつながり（yet / already / just / since / for）→ have + 過去分詞。

解答手順

  1. 前半の時の語
    last Friday → 過去の一点

    現在完了とは一緒に使えない。

  2. 前半を決める
    I lost my student ID last Friday.
  3. 後半の時の語
    yet → 今の時点の話

    「まだ見つかっていない」＝今も継続中の結果。

  4. 後半を決める
    I haven't found it yet.

    答え：lost / haven't found

検算：「have lost … last Friday」は不可。現在完了は過去の一点を表す語と共存できません。

差がつく2行

  1. 現在完了の訳は「〜してしまっている」。今どうなのかまで含めて訳すと使い分けを間違えません。
  2. When で始まる疑問文は現在完了にできません。× When have you visited …? ○ When did you visit …?

覚えるべきこと（在庫に入れる1行）

last / ago があれば過去形、yet / since / for があれば have + 過去分詞。

類題（翌日、何も見ずに）

  1. She ( live ) in Osaka since 2021. を適する形に。
    答え

    has lived（since があるので現在完了）

  2. When ( you visit ) the science museum? を適する形に。
    答え

    did you visit（When の疑問文は過去形）

解説の全文を読む
  1. こんにちは。知多丸の落ちこぼれ救済チャンネルです。難関大学に合格して、錯覚資産を手に入れて、一流企業に入社しよう。今日の問題です。括弧の中を適する形にしてください。アイ 括弧 ルーズ マイ スチューデント アイディー ラスト フライデー、アンド アイ 括弧 ノット ファインド イット イェット。
  2. 型は、時を表す語を先に探すことです。ラスト、イエスタデイ、アゴー のように過去の一点を指す語があれば過去形。イェット、オールレディ、シンス、フォー があれば現在完了です。
  3. 前半には ラスト フライデー があります。過去の一点なので過去形です。現在完了と一緒には使えません。
  4. 前半は アイ ロスト マイ スチューデント アイディー ラスト フライデー、となります。
  5. 後半には イェット があります。今の時点の話なので現在完了です。まだ見つかっていない、という今の状態を表します。
  6. 後半は アイ ハブント ファウンド イット イェット。答えは ロスト と ハブント ファウンド です。
  7. 検算です。逆にして I have lost it last Friday と書くと、今の話を表す現在完了に、過去の一点を指す ラスト フライデー が混ざって成り立ちません。この一文を作って違和感を確かめるのが検算です。
  8. 差がつく2行です。現在完了は「過去形＋今の状態」を1つで言う形なので、和訳では「〜してしまっている」と補います。それから、When で始まる疑問文は必ず過去形です。時の一点をたずねているからです。
  9. 在庫に入れる1行です。ラスト や アゴー があれば過去形、イェット、シンス、フォー があれば ハブ プラス 過去分詞。チャンネル登録をして、次の動画でも一緒に、要領よく積み上げていきましょう。
