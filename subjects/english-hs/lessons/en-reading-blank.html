第25回　長文：空所補充（論理関係で決める）

空所に入る語句を選べ。 Working in a group can save time because members share the load. (　), it also takes longer to make decisions, since everyone must agree. (A) For example (B) On the other hand (C) As a result

空所補充は訳さずに解けます。前後の符号を判定するだけです。

解法の型

  1. 前をプラス／マイナスで判定。「時間を節約できる」＝プラス。
  2. 後をプラス／マイナスで判定。「決定に時間がかかる」＝マイナス。
  3. 符号が変われば逆接。同じ向きなら追加・結果です。

解答手順

  1. 前を判定
    save time → プラス

    利点を述べている。

  2. 後を判定
    takes longer to make decisions → マイナス

    欠点を述べている。

  3. 符号の変化を見る
    プラス → マイナス

    したがって逆接。

  4. 答えを決める
    (B) On the other hand

    For example は例示、As a result は結果。

検算：日本語のつなぎ語を入れて読み直します。符号の判定と一致すれば正解です。

差がつく2行

  1. in addition / moreover / furthermore は追加。同じ向きの内容が続きます。
  2. nevertheless / nonetheless は「それでもなお」。前を認めた上で覆します。

覚えるべきこと（在庫に入れる1行）

空所補充は前後をプラス・マイナスで判定し、符号が変われば逆接。

類題（翌日、何も見ずに）

  1. The new system is cheaper. (　), it is easier to use.（However / Moreover）を選べ。
    答え

    Moreover（プラス→プラスの追加）

  2. The road was closed. (　), we had to take a longer route.（As a result / For example）を選べ。
    答え

    As a result（原因→結果）

解説の全文を読む
  1. こんにちは。知多丸の落ちこぼれ救済チャンネルです。難関大学に合格して、錯覚資産を手に入れて、一流企業に入社しよう。今日の問題です。空所補充です。集団で働くと、負担を分け合えるので時間を節約できる。空所、全員が合意しなければならないので、決定に時間がかかることもある。選択肢は、エー フォー イグザンプル、ビー オン ジ アザー ハンド、シー アズ ア リザルト。
  2. 型はこうです。空所の前後の内容を、プラスかマイナスかで判定します。プラスからマイナスへ変わるなら逆接。同じ向きなら追加や結果です。訳さずに符号だけで決められます。
  3. 前半は、時間を節約できる。プラスの内容です。
  4. 後半は、決定に時間がかかる。マイナスの内容です。
  5. プラスからマイナスへ変わっています。したがって逆接のつなぎ語が入ります。
  6. 答えはビー、オン ジ アザー ハンド。フォー イグザンプル は例示、アズ ア リザルト は結果なので合いません。
  7. 検算です。日本語のつなぎ語を入れて読み直します。一方で、決定には時間がかかる。自然です。たとえば、や、その結果、を入れると意味がつながらないので、逆接が正しいと分かります。
  8. 差がつく2行です。イン アディション、モアオーバー、ファーザーモア は追加で同じグループです。それから、ネバーザレス と ナンスザレス は、逆接の中でも、それでもなお、という強い譲歩を表します。
