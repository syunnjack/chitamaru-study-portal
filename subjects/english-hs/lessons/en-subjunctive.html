第9回　仮定法過去と仮定法過去完了

(1) もし今もっと時間があれば、その大会に参加するのに。(2) もし昨日 傘を持っていたら、濡れなかっただろう。　英語にせよ。

仮定法は特別な文法ではなく、時制をひとつ前にずらす操作です。事実の逆になるかで検算できます。

解法の型

  1. いつの話かを決める。現在の仮定か、過去の仮定か。
  2. 現在の仮定 → If + 過去形, would / could / might + 原形。
  3. 過去の仮定 → If + had + 過去分詞, would have + 過去分詞。

解答手順

  1. (1) いつの話か
    now → 現在の仮定

    事実は「今、時間がない」。

  2. (1) 型に入れる
    If I had more time now, I would take part in the contest.

    If の中は過去形 had、主節は would + 原形。

  3. (2) いつの話か
    yesterday → 過去の仮定

    事実は「昨日、傘がなかった」。

  4. (2) 型に入れる
    If I had had an umbrella yesterday, I would not have got wet.

    答え：had had と would not have got の組み合わせ。

検算：仮定法は必ず事実の逆。(1)「今は参加しない」(2)「昨日は濡れた」が言えれば時制の判定は正しいです。

差がつく2行

  1. 仮定法の be動詞は主語に関係なく were が原則（If I were you, …）。
  2. ありえる未来の条件は仮定法にしません（If it rains tomorrow, I will stay home.）。

覚えるべきこと（在庫に入れる1行）

現在の仮定は「過去形 … would + 原形」、過去の仮定は「had + p.p. … would have + p.p.」。

類題（翌日、何も見ずに）

  1. 「もし彼が医者なら、私を助けられるのに」を英語に。
    答え

    If he were a doctor, he could help me.

  2. 「もっと熱心に勉強していたら、私は合格していただろう」を英語に。
    答え

    If I had studied harder, I would have passed the exam.
