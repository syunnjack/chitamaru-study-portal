第5回　to不定詞と動名詞（動詞の型）

I finally decided ( join ) the debate club, but I still avoid ( speak ) first.　( )内を適する形にせよ。

to do か doing かは、意味で悩む問題ではありません。動詞ごとに決まっている型を在庫にするだけです。

解法の型

  1. to do をとる動詞。decide / hope / promise / plan / want / wish（これから）
  2. doing をとる動詞。avoid / enjoy / finish / mind / give up / practice（すでに・頭の中の映像）
  3. 両方とれて意味が変わる動詞。remember / forget / stop / try

解答手順

  1. 前半の動詞を確認する
    decide → to do

    「これから入ろうと決めた」。

  2. 前半を決める
    I finally decided to join the debate club.
  3. 後半の動詞を確認する
    avoid → doing

    avoid to speak は不可。

  4. 後半を決める
    I still avoid speaking first.

    答え：to join / speaking

検算：doingをとる動詞は、短い例文（I enjoy reading. / I gave up smoking.）ごと覚えると迷いません。

差がつく2行

  1. remember to do は「これからすることを覚えている」、remember doing は「したことを覚えている」。
  2. stop to do は「するために立ち止まる」、stop doing は「するのをやめる」。to は未来向き、doing は既にあること。

覚えるべきこと（在庫に入れる1行）

to do は「これから」、doing は「すでに・頭の中の映像」。動詞ごとに例文で覚える。

類題（翌日、何も見ずに）

  1. He promised ( call ) me back before noon. を適する形に。
    答え

    to call（promise は to do）

  2. Remember ( lock ) the door before you leave. を適する形に。
    答え

    to lock（これからすること。remember doing なら「鍵をかけたのを覚えている」）
