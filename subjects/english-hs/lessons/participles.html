高校英語 ／ 第6回 分詞

第6回　分詞 doing / done

能動 → doing ／ 受動 → done

例

a sleeping baby
a broken window

後置修飾

The girl standing by the door is my sister.

長い説明は名詞の後ろに置きます。

解説の全文を読む
  1. 第6回は分詞です。現在分詞 doing と過去分詞 done は、名詞を説明する形容詞のように働きます。
  2. 現在分詞は能動、進行のイメージ。a running boy は走っている少年。過去分詞は受動、完了のイメージ。a broken window は壊された、壊れている窓です。
  3. 語が長くなると名詞の後ろから説明します。The girl standing by the door is my sister. ドアのそばに立っている少女が私の姉です。
  4. 分詞構文も基本は同じです。主節の主語との能動、受動を見ます。まず名詞修飾を完全にしてから分詞構文へ進みましょう。
