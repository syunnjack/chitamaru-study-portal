第8回　接続詞と間接疑問（文をつなぐと語順が戻る）

次の空所に適する語または語順を入れよ。(1) ( ) it rains tomorrow, we will stay home. (2) I think ( ) this movie is interesting. (3) Do you know ( ) he lives?（どこに住んでいるか）(4) I don't know ( ) she will come.（来るかどうか）

if の中に will を入れてしまう人が、ここでいつも落としています。

解法の型

  1. when / if の中は現在形。未来のことでも will を入れません。
  2. that＝「〜ということ」。think, know, hope の後ろで、省略もできます。
  3. 間接疑問は語順が戻る。疑問詞 ＋ 主語 ＋ 動詞。「〜かどうか」は if / whether。

解答手順

  1. (1) 条件のif
    If it rains tomorrow, we will stay home.

    中は現在形。

  2. (2) that節
    I think (that) this movie is interesting.

    省略可。

  3. (3) 間接疑問
    Do you know where he lives?

    疑問詞＋主語＋動詞。

  4. (4) 〜かどうか
    I don't know if (whether) she will come.

    if＝かどうか。

検算：条件の if は中を現在形に、「〜かどうか」の if は will も可。間接疑問に does/did が残っていないか確認します。

差がつく2行

  1. when, if, before, after, until, as soon as の中は未来のことでも現在形にします。
  2. because のあとは理由、so のあとは結果。向きを逆にしないことです。

覚えるべきこと（在庫に入れる1行）

when/ifの中は現在形。間接疑問は疑問詞＋主語＋動詞に戻る。

類題（翌日、何も見ずに）

  1. 「明日晴れたら、私たちはテニスをします」を英語にせよ。
    答え

    If it is sunny tomorrow, we will play tennis.

  2. 「彼が何を欲しいのか私は知りません」を英語にせよ。
    答え

    I don't know what he wants.

動画の音声ナレーション

解説の全文を読む
  1. こんにちは。知多丸の落ちこぼれ救済チャンネルです。難関大学に合格して、錯覚資産を手に入れて、一流企業に入社しよう。今日の問題です。次の空所に適する語または語順を入れます。1、かっこ、イットレインズトゥモロウ、ウィーウィルステイホウム。2、アイシンク、かっこ、ジスムービーイズインタレスティング。3、ドゥーユーノウ、かっこ、ヒーリブズ。どこに住んでいるか、という意味です。4、アイドントノウ、かっこ、シーウィルカム。来るかどうか、という意味です。
  2. 型はこうです。ホウェンやイフで始まるかたまりの中は、未来のことでも現在形にします。イフイットレインズトゥモロウ、ウィルは入れません。ザットはということ、省略できます。そして間接疑問。文の中に疑問文が入ると語順が戻り、疑問詞、主語、動詞の順になります。かどうかならイフまたはホウェザーです。
  3. 1です。もし明日雨が降ったらなのでイフ。トゥモロウがあってもイフの中は現在形レインズです。主節のウィルステイは未来のままでよい、ここが対比になっています。
  4. 2です。思うという動詞の後ろなのでザット。ということ、という意味で、会話では省略されることが多いです。
  5. 3です。どこにという疑問詞ホウェアのあとが、主語ヒー、動詞リブズの順に戻ります。ホウェアダズヒーリブとは書きません。
  6. 4です。かどうかはイフまたはホウェザー。ここは条件ではなく名詞のはたらきなので、中にウィルを入れてかまいません。アイドントノウイフシーウィルカム。
  7. 検算です。イフの使い分けを確認します。もし〜ならの条件なら中は現在形、〜かどうかの意味なら中にウィルを入れてよい。イフが2つの意味を持つことを知っていれば、この違いで迷いません。そして間接疑問は疑問詞の後ろがダズやディドになっていないかを見ます。
  8. 差がつく2行です。ひとつ目、時と条件を表す接続詞の仲間です。ホウェン、イフ、ビフォー、アフター、アンティル、アズスーンアズ。どれも中は現在形です。アズスーンアズアイアライブ、アイウィルコールユー。ふたつ目、ソーとビコーズの向きです。ビコーズのあとは理由、ソーのあとは結果。イットワズコールド、ソーアイステイドホウム。順番を逆にしないことです。
  9. 在庫に入れる1行です。ホウェンやイフの中は現在形。間接疑問は疑問詞、主語、動詞の順に戻る。チャンネル登録をして、次の動画でも一緒に、要領よく積み上げていきましょう。
