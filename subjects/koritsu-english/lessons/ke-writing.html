第10回　条件英作文（2文の型で満点を取る）

次のテーマについて、英語2文以上で書け。テーマ：あなたが友達にすすめたい本や映画について、理由も入れて書きなさい。（語数の指定はないが、各文は5語以上とする）

英作文は、難しいことを書かない人が満点を取ります。

解法の型

  1. 1文目は結論。I want to recommend the movie “Blue Sky.”
  2. 2文目は理由。because ＋ 主語 ＋ 動詞 で書きます。
  3. 確実に書ける形に内容を合わせる。難しい日本語を訳そうとしないことです。

解答手順

  1. 1文目を書く
    I want to recommend a book called "The Long Road."

    結論を先に。

  2. 2文目を書く
    I like it because the main character never gives up.

    because＋主語＋動詞。

  3. 3文目で補強する
    If you read it, you will feel braver.

    余裕があれば1文追加。

  4. 見直しを固定する
    ① 主語と動詞 ② 三単現のs ③ 時制 ④ 冠詞・複数形

    4点だけ見る。

検算：各文に主語と動詞があるか、三単現の s と時制が合っているかを確認します。

差がつく2行

  1. I think that ~ / One reason is that ~ / For example, ~ の3つを持っておけば、どのテーマでも書けます。
  2. 綴りに不安がある語は避け、確実に書ける語を選びます。減点されない選択も実力です。

覚えるべきこと（在庫に入れる1行）

英作文は2文。結論→because で理由。見直しは主語・動詞・s・時制。

類題（翌日、何も見ずに）

  1. 「私は音楽が好きです。なぜならそれは私を元気にするからです」を英語にせよ。
    答え

    I like music because it makes me happy.

  2. 英作文の見直しで確認する4点を答えよ。
    答え

    主語と動詞・三単現のs・時制・冠詞と複数形

動画の音声ナレーション

解説の全文を読む
  1. こんにちは。知多丸の落ちこぼれ救済チャンネルです。難関大学に合格して、錯覚資産を手に入れて、一流企業に入社しよう。今日の問題です。次のテーマについて、英語2文以上で書きます。テーマは、あなたが友達にすすめたい本や映画について、理由も入れて書きなさい。語数の指定はありませんが、各文は5語以上とします。
  2. 型はこうです。英作文は2文で完成させます。1文目で結論、アイウォントトゥーレコメンドプラス作品名。2文目で理由、ビコーズを使って書く。大事なのは、日本語で思いついた難しい内容を英語にしようとしないこと。自分が確実に書ける英語の形に、内容を合わせます。減点されない英語を書くことが満点への道です。
  3. 1文目です。アイウォントトゥーレコメンドアブッククォールドザロングロード。すすめたいものを最初に言い切ります。作品名は自分で決めてかまいません。
  4. 2文目は理由です。アイライクイットビコーズザメインキャラクターネバーギブスアップ。ビコーズのあとは主語と動詞、これで理由の形になります。
  5. 余裕があれば3文目を足します。イフユーリードイット、ユーウィルフィールブレイバー。イフの中は現在形、これは第8回の型です。
  6. 最後の見直しは4点だけです。主語と動詞があるか、三人称単数のエスがついているか、時制がそろっているか、冠詞と複数形が正しいか。この4点で減点はほぼ防げます。
  7. 検算です。書いた各文に、主語と動詞が1つずつあるかを指で確認します。日本語では主語を省くので、英語で主語が抜けることが最も多い減点です。次に動詞の形。三人称単数のエス、過去形、これだけで英作文の点は安定します。
  8. 差がつく2行です。ひとつ目、使い回せる型を3つ持つことです。アイシンクザット、ワンリーズンイズザット、フォーイグザンプル。この3つがあれば、どんなテーマでも2文以上書けます。ふたつ目、綴りが不安な語は避けることです。ビューティフルが不安ならナイスやグッドで書く。減点されない語を選ぶのも実力です。
  9. 在庫に入れる1行です。英作文は2文。結論、そしてビコーズで理由。見直しは主語、動詞、三単現のエス、時制。チャンネル登録をして、次の動画でも一緒に、要領よく積み上げていきましょう。
