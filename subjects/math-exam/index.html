高校受験数学

高校入試の数学は、範囲は狭いのに「見たことのない形」で出されます。だからこそ、その場のひらめきではなく、型の在庫で勝負が決まります。ここでは入試の大問1・大問2で差がつく「計算の工夫」から積み上げます。

高校受験数学の進め方（知多丸式）

  1. 5分考えて手が動かなければ、解答を見る。悩む時間は勉強時間ではありません。
  2. 解説動画で「なぜその一手か」を、言葉で言えるようにする。
  3. 翌日、何も見ずに解き直す。1週間後に方針だけ30秒で言う。
  4. 難問は捨て問の判断も練習する。合格点から逆算します。

1(0²+1²) + 3(1²+2²) + … + 99(49²+50²) = ○⁴。50項を1行に潰す打ち消しの技。

 第3回・動画あり

 第4回・動画あり

直交する2弦と網目部分の面積（方べき）

AH=1、BH=2、DH=3 から HC=6。円の面積 25π/2、網目部分 25π/4 + 5/2。図つき。

 第5回・動画あり

たすきがけが効かない4乗の式は (x²+1)² − x² に。x+…+x⁶ など3問。

 第6回・動画あり

中点が動いてできる線と、面積の最大

PCの中点Qは半径1の円をえがく → 2π cm。△BPQ の最大は 2 cm²。図つき。

 第7回・動画あり

相似と面積比（辺の比の2乗）

DE ∥ BC、AD : DB = 2 : 1。△ADE : 四角形DBCE = 4 : 5。図つきで解説。

 第8回・動画あり

分数の打ち消し（部分分数）

1/(1·2) + … + 1/(9·10) = 9/10。差の形に直して両端だけ残す型。

 第9回・動画あり

放物線と直線の三角形の面積

y = x² と y = x + 2。y切片で切って ½ × 2 × 3 = 3。図つき。

 第12回・動画あり

倍数かつ約数の個数

 第13回・動画あり

余りの条件（不足でそろえる）

6で割って3余り、8で割って5余る。n + 3 が24の倍数で5番目は117。

 第14回・動画あり

n² + 48 が平方数

(m − n)(m + n) = 48 に直し、偶奇で絞って n = 1, 4, 11。
