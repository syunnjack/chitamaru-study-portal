第12回　n/24 と 1080/n がともに整数になる n の個数

n / 24 と 1080 / n がともに整数となる自然数 n の個数を求めよ。

分数の整数条件は「倍数」「約数」に言いかえるだけで、書き出さずに数えられます（動画・音声解説つき）。

解法の型

n / 24 が整数 → n は 24 の倍数　／　1080 / n が整数 → n は 1080 の約数

分数の条件は、必ず「倍数」「約数」の言葉に置きかえます。

解答手順

  1. n = 24m と置く
    1080 ÷ (24m) = 45 / m が整数 → m は 45 の約数
  2. 約数の個数を数える
    45 = 3² × 5 → (2+1)(1+1) = 6 個

検算：m = 1, 3, 5, 9, 15, 45 より n = 24, 72, 120, 216, 360, 1080 の 6 個。最小は 24、最大は 1080 です。

差がつく2行

  1. 約数の個数は素因数分解して指数に1を足してかける：1080 = 2³ × 3³ × 5 → 4 × 4 × 2 = 32 個。
  2. この置きかえができるのは24 が 1080 を割り切るから。割り切らなければ条件を満たす n は 0 個です。

覚えるべきこと（在庫に入れる1行）

整数条件は「倍数・約数」に言いかえ、n = 24m と置く

類題（翌日、何も見ずに）

  1. n / 12 と 360 / n がともに整数となる n の個数
    答え

    n = 12m → 30 / m が整数、30 = 2 × 3 × 5 → 8 個

  2. 540 の正の約数の個数
    答え

    540 = 2² × 3³ × 5 → 3 × 4 × 2 = 24 個

  3. n / 15 と 225 / n がともに整数となる n をすべて
    答え

    n = 15m → 15 / m が整数 → m = 1, 3, 5, 15 → n = 15, 45, 75, 225

解説の全文を読む
  1. こんにちは。知多丸の落ちこぼれ救済チャンネルです。難関大学に合格して、錯覚資産を手に入れて、一流企業に入社しよう。今日の問題は、24分のエヌ と、エヌ分の1080 がともに整数となる自然数 エヌ の個数を求めなさい。書き出しでも解けますが、型を使うと10秒で終わります。
  2. 型はこれです。分数が整数になる条件を、言葉に置きかえます。24分のエヌ が整数、これは エヌ が24の倍数。エヌ分の1080 が整数、これは エヌ が1080の約数。つまり求めるものは、24の倍数であって、同時に1080の約数である数の個数です。
  3. 手順1。エヌ は24の倍数なので、エヌ は 24エム と置けます。エム は自然数です。これを2つめの条件に入れます。1080 わる 24エム が整数。1080 わる 24 は 45 なので、エム分の45 が整数、つまり エム は 45 の約数になります。
  4. 手順2。45 の約数の個数を求めます。45 を素因数分解すると、3 の2乗 かける 5。指数に1を足してかけると、2たす1 かける 1たす1 で 6個。よって エム は6通り、エヌ も6個です。
  5. 検算です。実際に書き出します。エム が 1、3、5、9、15、45 なので、エヌ は 24、72、120、216、360、1080。たしかに6個です。いちばん小さいのは24、いちばん大きいのは1080、つまり エヌ は必ず 24 以上 1080 以下になります。
  6. 差がつく2行。1つめ。約数の個数は、素因数分解して指数に1を足してかける。1080 は 2の3乗 かける 3の3乗 かける 5 なので、約数は 4 かける 4 かける 2 で 32個です。2つめ。24の倍数がすべて1080の約数になるわけではありません。1080 が 24 で割り切れるからこそ、この置きかえができます。もし割り切れなければ、答えは0個です。
  7. おつかれさまでした。在庫に入れる1行は、これです。分数が整数、は「倍数」「約数」に言いかえて、エヌ を置きかえる。明日、何も見ずに、12分のエヌ と エヌ分の360 がともに整数となる エヌ の個数をやってみてください。答えは 8個 です。チャンネル登録をして、次の動画でも一緒に、要領よく積み上げていきましょう。
