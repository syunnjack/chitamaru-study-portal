第12回　n/18 と 756/n がともに整数になる n の個数

n / 18 と 756 / n がともに整数となる自然数 n の個数を求めよ。

分数の整数条件は「倍数」「約数」に言いかえるだけで、書き出さずに数えられます（動画・音声解説つき）。

解法の型

n / 18 が整数 → n は 18 の倍数　／　756 / n が整数 → n は 756 の約数

分数の条件は、必ず「倍数」「約数」の言葉に置きかえます。

解答手順

  1. n = 18m と置く
    756 ÷ (18m) = 42 / m が整数 → m は 42 の約数
  2. 約数の個数を数える
    42 = 2 × 3 × 7 → (1+1)(1+1)(1+1) = 8 個

検算：m = 1, 2, 3, 6, 7, 14, 21, 42 より n = 18, 36, 54, 108, 126, 252, 378, 756 の 8 個。最小は 18、最大は 756 です。

差がつく2行

  1. 約数の個数は素因数分解して指数に1を足してかける：756 = 2² × 3³ × 7 → 3 × 4 × 2 = 24 個。
  2. この置きかえができるのは18 が 756 を割り切るから。割り切らなければ条件を満たす n は 0 個です。

覚えるべきこと（在庫に入れる1行）

整数条件は「倍数・約数」に言いかえ、n = 18m と置く

類題（翌日、何も見ずに）

  1. n / 12 と 360 / n がともに整数となる n の個数
    答え

    n = 12m → 30 / m が整数、30 = 2 × 3 × 5 → 8 個

  2. 540 の正の約数の個数
    答え

    540 = 2² × 3³ × 5 → 3 × 4 × 2 = 24 個

  3. n / 15 と 225 / n がともに整数となる n をすべて
    答え

    n = 15m → 15 / m が整数 → m = 1, 3, 5, 15 → n = 15, 45, 75, 225
