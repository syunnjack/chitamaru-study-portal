第5回　1 + x² + x⁴ の因数分解（平方の差にする）

次の式を因数分解せよ。
(1) 1 + x² + x⁴
(2) x + x² + x³ + x⁴ + x⁵ + x⁶
(3) x + 2x² + 2x³ + x⁴

解法の型

4乗の式でたすきがけが効かないときは、（　）² − （　）² を作る。A² − B² = (A + B)(A − B)

項が多いときは、共通因数でくくって「2つずつの組」にする。

因数分解の検算は x = 1 の代入。10秒で終わります。

(1) 1 + x² + x⁴

  1. (x² + 1)² を作ってみる
    (x² + 1)² = x⁴ + 2x² + 1
    もとの式より x² が1つ多い
  2. 多い分を引く（平方の差になる）
    1 + x² + x⁴ = (x² + 1)² − x²
  3. A² − B² を開く
    = (x² + 1 + x)(x² + 1 − x) = (x² + x + 1)(x² − x + 1)

検算：x = 1 で もとの式 = 3、答え = 3 × 1 = 3。○

(2) x + x² + x³ + x⁴ + x⁵ + x⁶

  1. 共通因数 x をくくる
    = x(1 + x + x² + x³ + x⁴ + x⁵)
  2. 2つずつ組にする
    = x{(1 + x) + x²(1 + x) + x⁴(1 + x)} = x(1 + x)(1 + x² + x⁴)
  3. (1) の結果を使う
    = x(x + 1)(x² + x + 1)(x² − x + 1)

検算：x = 1 で もとの式 = 6、答え = 1 × 2 × 3 × 1 = 6。○

(3) x + 2x² + 2x³ + x⁴

  1. 共通因数 x をくくる
    = x(1 + 2x + 2x² + x³)
  2. 両端と真ん中に分ける
    1 + x³ = (1 + x)(1 − x + x²)　　2x + 2x² = 2x(1 + x)
  3. (1 + x) でくくる
    = x(1 + x){(1 − x + x²) + 2x} = x(x + 1)(x² + x + 1)

検算：x = 1 で もとの式 = 1 + 2 + 2 + 1 = 6、答え = 1 × 2 × 3 = 6。○

覚えるべきこと（在庫に入れる1行）

4乗が出たら平方の差を作る／項が多ければ共通因数と2つずつの組／検算は x = 1

類題（翌日、何も見ずに）

  1. x⁴ + 4 を因数分解せよ。
    答え

    x⁴ + 4 = (x² + 2)² − 4x² = (x² + 2x + 2)(x² − 2x + 2)

  2. x⁴ + x² + 25 を因数分解せよ。
    答え

    (x² + 5)² − 9x² = (x² + 3x + 5)(x² − 3x + 5)

  3. (1 + x)(1 − x + x²) を展開せよ。
    答え

    1 + x³（立方の和 a³ + b³ = (a + b)(a² − ab + b²)）
