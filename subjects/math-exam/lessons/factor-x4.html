第5回　x⁴ 型の因数分解（平方の差にする）

次の式を因数分解せよ。
(1) x⁴ + 4
(2) x⁴ + 4x² + 16
(3) 4x⁴ + 1

解法の型

4乗の式でたすきがけが効かないときは、（　）² − （　）² を作る。A² − B² = (A + B)(A − B)

両端から平方を作り、多い分を引く。これだけで3問とも終わります。

因数分解の検算は x = 1 の代入。10秒で終わります。

(1) x⁴ + 4

  1. 両端から平方を作る
    (x² + 2)² = x⁴ + 4x² + 4
    もとの式より 4x² が多い
  2. 多い分を引く（平方の差になる）
    x⁴ + 4 = (x² + 2)² − (2x)²
  3. A² − B² を開く
    = (x² + 2 + 2x)(x² + 2 − 2x) = (x² + 2x + 2)(x² − 2x + 2)

検算：x = 1 で もとの式 = 5、答え = 5 × 1 = 5。○

(2) x⁴ + 4x² + 16

  1. 両端 x⁴ と 16 から平方を作る
    (x² + 4)² = x⁴ + 8x² + 16
    もとの式より 4x² が多い
  2. 多い分を引く
    x⁴ + 4x² + 16 = (x² + 4)² − (2x)²
  3. 開く
    = (x² + 2x + 4)(x² − 2x + 4)

検算：x = 1 で もとの式 = 21、答え = 7 × 3 = 21。○

(3) 4x⁴ + 1

  1. 係数がついても同じ
    (2x² + 1)² = 4x⁴ + 4x² + 1
  2. 多い分を引く
    4x⁴ + 1 = (2x² + 1)² − (2x)²
  3. 開く
    = (2x² + 2x + 1)(2x² − 2x + 1)

検算：x = 1 で もとの式 = 5、答え = 5 × 1 = 5。○

覚えるべきこと（在庫に入れる1行）

4乗が出たら、両端から平方を作って多い分を引く（平方の差）／検算は x = 1

類題（翌日、何も見ずに）

  1. x⁴ + x² + 25 を因数分解せよ。
    答え

    (x² + 5)² − 9x² = (x² + 3x + 5)(x² − 3x + 5)

  2. x⁴ + 64 を因数分解せよ。
    答え

    (x² + 8)² − 16x² = (x² + 4x + 8)(x² − 4x + 8)

  3. x⁴ + 2x² + 9 を因数分解せよ。
    答え

    (x² + 3)² − 4x² = (x² + 2x + 3)(x² − 2x + 3)
