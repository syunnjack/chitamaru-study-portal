第14回　n² + 48 が平方数になる自然数 n をすべて求める

n² + 48 が平方数となる自然数 n をすべて求めよ。

平方数の条件は、積が定数の形に持ち込むだけです（動画・音声解説つき）。

解法の型

n² + 48 = m² と置く → (m − n)(m + n) = 48

「平方数になる」条件は、m² と置いて2乗の差を因数分解し、積が定数の形にします。

解答手順

  1. 偶奇で絞る
    (m − n) + (m + n) = 2m → 2数は同じ偶奇。積が偶数なので両方偶数

    48 = 2 × 24、4 × 12、6 × 8 の 3 通りだけ（1 × 48、3 × 16 は偶奇がちがうので不適）。

  2. 3 通りを計算
    2 と 24 → m = 13、n = 11　／　4 と 12 → m = 8、n = 4　／　6 と 8 → m = 7、n = 1
    答え n = 1, 4, 11

検算：1 + 48 = 49 = 7²、16 + 48 = 64 = 8²、121 + 48 = 169 = 13²。3つとも平方数です。

差がつく2行

  1. m − n < m + n を使えば、組の重複や数え漏れが消えます。
  2. この2乗の差の因数分解は高校の整数問題でもそのまま使う型。積が定数の形に持ち込むのが共通の要領です。

覚えるべきこと（在庫に入れる1行）

平方数 → m² と置き、(m − n)(m + n) = 定数 に変える

類題（翌日、何も見ずに）

  1. n² + 24 が平方数となる自然数 n
    答え

    (m − n)(m + n) = 24 → 2 × 12 で n = 5、4 × 6 で n = 1 → n = 1, 5

  2. n² + 9 が平方数となる自然数 n
    答え

    (m − n)(m + n) = 9 → 1 × 9 のみ → m = 5、n = 4（16 + 9 = 25）

  3. 96 + n² が平方数となる自然数 n の個数
    答え

    両方偶数の組は 2×48、4×24、6×16、8×12 → n = 23, 10, 5, 2 の 4 個
