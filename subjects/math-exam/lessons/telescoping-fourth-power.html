第1回　和が4乗になる式（差に化ける形を見抜く）

1(0² + 1²) + 3(1² + 2²) + 5(2² + 3²) + … + 99(49² + 50²) = ○⁴

○ にあてはまる数を求めます。項は50個。まっすぐ足す問題ではありません（動画・音声解説つき）。

方針の立て方（ここが勝負）

答えが「○の4乗」の形で聞かれている → 各項を「4乗の差」に直して打ち消す。

使う道具は中学範囲の a² − b² = (a + b)(a − b) だけです。

解答手順

  1. 4乗の差を分解する
    (k+1)⁴ − k⁴ = { (k+1)² }² − { k² }² = { (k+1)² + k² }{ (k+1)² − k² }
  2. 後ろのカッコを計算
    (k+1)² − k² = ( 2k + 1 ) × 1 = 2k + 1

    問題の 1, 3, 5, … 99 という奇数の正体がこれです。

  3. 問題の各項＝4乗の差だと気づく
    ( 2k + 1 ){ k² + (k+1)² } = (k+1)⁴ − k⁴
  4. 全部書き直して打ち消す
    ( 1⁴ − 0⁴ ) + ( 2⁴ − 1⁴ ) + … + ( 50⁴ − 49⁴ ) = 50⁴ − 0⁴
  5. 答え
    ○ = 50　（50⁴ = 6250000）

式変形の確認：k = 1 → 3(1 + 4) = 15、2⁴ − 1⁴ = 15。k = 2 → 5(4 + 9) = 65、3⁴ − 2⁴ = 65。小さい数で必ず試します。

検算：2k + 1 = 99 より k = 49。最後の項は 50⁴ − 49⁴ なので、上の端 50 が答え。打ち消しの問題は「最後の項の上端」で確認できます。

覚えるべきこと（在庫に入れる1行）

累乗の形で聞かれたら、各項を「差の形」に直して打ち消す。道具は a² − b² = (a+b)(a−b)。

類題（翌日、何も見ずに）

  1. 1 + 3 + 5 + … + 99
    答え

    (1²−0²) + (2²−1²) + … + (50²−49²) = 50² = 2500

  2. (1² + 1·2 + 2²) + (2² + 2·3 + 3²) + … + (9² + 9·10 + 10²)
    答え

    k² + k(k+1) + (k+1)² = (k+1)³ − k³ なので、和は 10³ − 1³ = 999

  3. 101² − 99²
    答え

    (101 + 99)(101 − 99) = 200 × 2 = 400
