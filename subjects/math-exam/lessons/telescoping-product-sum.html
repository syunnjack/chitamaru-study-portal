第1回　連続する2数の積の和（差に化ける形を見抜く）

1×2 + 2×3 + 3×4 + … + 20×21 の値を求めよ。

項は20個。まっすぐ足す問題ではありません（動画・音声解説つき）。

方針の立て方（ここが勝負）

項が多い和は、各項を「差の形」に直して打ち消す。残るのは両端だけになります。

そのために「1つ長い積」を用意するのが、この型の要領です。

解答手順

  1. 1つ長い積を用意する
    T(k) = k(k+1)(k+2)　,　T(k−1) = (k−1)k(k+1)
  2. 差をとる（3倍が出てくる）
    T(k) − T(k−1) = k(k+1){ (k+2) − (k−1) } = 3 · k(k+1)
  3. 全部書き直して打ち消す
    3S = ( T1 − T0 ) + ( T2 − T1 ) + … + ( T20 − T19 ) = T20 − T0
  4. 答え
    3S = 20·21·22 = 9240　→　S = 3080

式変形の確認：k = 1 → 1·2·3 − 0 = 6、3·1·2 = 6。k = 2 → 2·3·4 − 1·2·3 = 18、3·2·3 = 18。小さい数で必ず試します。

検算：k(k+1) = k² + k なので、Σk² = 20·21·41/6 = 2870、Σk = 210。2870 + 210 = 3080 で一致します。

差がつく2行

  1. 公式化すると 1×2 + … + n(n+1) = n(n+1)(n+2) / 3。答えは「最後の積」だけで決まります。
  2. 「1つ長い積を作って差をとる」発想は、高校の数学B（数列）でもそのまま使う型です。

覚えるべきこと（在庫に入れる1行）

積の和は、1つ長い積の差に直して打ち消す。

類題（翌日、何も見ずに）

  1. 1×2 + 2×3 + … + 10×11
    答え

    10·11·12 / 3 = 440

  2. 1×2×3 + 2×3×4 + … + 8×9×10
    答え

    1つ長い積 k(k+1)(k+2)(k+3) の差を使って 8·9·10·11 / 4 = 1980

  3. 1 + 3 + 5 + … + 99
    答え

    (1²−0²) + (2²−1²) + … + (50²−49²) = 50² = 2500

動画の音声ナレーション

解説の全文を読む
  1. こんにちは。知多丸の落ちこぼれ救済チャンネルです。難関大学に合格して、錯覚資産を手に入れて、一流企業に入社しよう。今日は、高校受験の計算の工夫です。1 かける 2、たす、2 かける 3、たす、3 かける 4、と続いて、最後は 20 かける 21。この合計を求めなさい。項は20個あります。
  2. まず方針です。20個をまっすぐ足すと、時間がかかり、計算ミスもします。こういう和は、各項を、差の形に書きかえて、となりどうしを打ち消す。これが計算の工夫の王道です。打ち消しの形を作れるかどうかが勝負です。
  3. 道具を作ります。連続する3つの数の積、ケー かける ケー たす1 かける ケー たす2、を考えます。これを ティー ケー と呼びます。1つ前の ティー ケー マイナス1 は、ケー マイナス1 かける ケー かける ケー たす1 です。この2つの差を計算してみましょう。
  4. 差をとります。共通の ケー かける ケー たす1 でくくると、残りは、ケー たす2 ひく、ケー マイナス1。これは 3 です。したがって、ティー ケー ひく ティー ケー マイナス1 は、3 かける ケー かける ケー たす1。つまり、連続2数の積の 3倍 が、ちょうど差の形になります。
  5. 式変形に自信がないときは、必ず小さい数で確かめます。ケー イコール 1 のとき、1 かける 2 かける 3 ひく 0 は 6。3 かける 1 かける 2 も 6。合っています。ケー イコール 2 のとき、2 かける 3 かける 4 ひく 1 かける 2 かける 3 は、24 ひく 6 で 18。3 かける 2 かける 3 も 18。合っています。
  6. では全部を書き直します。求める和を エス とすると、3エス は、ティー1 ひく ティー0、たす、ティー2 ひく ティー1、と続いて、最後は ティー20 ひく ティー19。となりどうしが次々に打ち消し合い、残るのは ティー20 と ティー0 だけです。
  7. 計算します。ティー20 は、20 かける 21 かける 22 で、9240。ティー0 は 0 です。ですから、3エス は 9240。両辺を 3 で割って、エス は 3080。これが答えです。20個の足し算が、かけ算1回で終わりました。
  8. 検算です。別の方法で出してみます。ケー かける ケー たす1 は、ケーの2乗 たす ケー です。2乗の和の公式で、1から20までの2乗の和は、20 かける 21 かける 41 を 6 で割って、2870。1から20までの和は、210。たすと 3080。ぴったり一致しました。
  9. 差がつく2行。1つめ。打ち消しの問題は、答えが「最後の積」だけで決まります。今回なら 20 かける 21 かける 22 を 3 で割る。公式として、1から エヌ までなら、エヌ かける エヌ たす1 かける エヌ たす2 を 3 で割る、と覚えてかまいません。2つめ。1つ長い積を作って差をとる、という発想は、高校の数学Bの数列でも、そのまま使います。
  10. おつかれさまでした。在庫に入れる1行は、これです。積の和は、1つ長い積を作って差の形に直し、打ち消す。明日、何も見ずに、1 かける 2 から 10 かける 11 までの和をやってみてください。答えは、10 かける 11 かける 12 を 3 で割って、440 です。チャンネル登録をして、次の動画でも一緒に、要領よく積み上げていきましょう。
