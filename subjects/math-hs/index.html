高校数学

高校数学でつまずく最大の原因は「才能がない」ことではなく、型の在庫がないまま初見問題に挑むことです。ここでは例題の解法を覚え、使える型を1つずつ増やしていきます。

高校数学の進め方（知多丸式）

  1. 解説動画を見て、型の名前と手順を頭に入れる。
  2. 動画を止めながら、同じ問題を自分の手で書き写す。
  3. 翌日、類題を何も見ずに解く。詰まったら5分で解答へ。
  4. 1週間後、方針を30秒で言えるか確認する。

数学I：2次関数・2次方程式

第1回・動画あり

放物線の頂点を求める

y = x² + 8x + 5 の頂点。型は「平方完成」ひとつだけ。検算の作法までセットで覚えます。

 第2回・動画あり

2次方程式を解の公式で解く

x² − 5x + 3 = 0。因数分解を10秒で見切り、解の公式へ。検算は解と係数の関係で。

 第3回・動画あり

異なる実数解の個数を求める

x² − 6x + 10 = 0。解かずに判別式 D の符号だけで答える型。

 第8回・動画あり

平方完成（x² の係数が 1 でないとき）

y = 2x² − 12x + 5。くくり出す → 半分の2乗を引く → 外の数をかける、の3拍子。

 第9回・動画あり

定義域つきの最大・最小

y = x² − 4x + 1（0 ≦ x ≦ 3）。候補は頂点と両端の3点だけ。

 第10回・動画あり

グラフの平行移動

x → x − p、y → y − q の1行。符号が逆になることと、頂点での検算。

 第14回・動画あり

2次不等式を解く

x² − 5x + 6 > 0。境目を出して「> 0 は外側、< 0 は内側」と決めるだけ。

数学I：図形と計量

第4回・動画あり

正弦定理で辺の長さを求める

A = 45°、C = 75°、BC = 2 のとき CA。角2つ＋辺1つなら正弦定理。

 第5回・動画あり

三角形が成立する範囲

3辺が 2、x + 3、3。場合分けせずに |差| < 文字の辺 < 和 で一気に処理します。

 第11回・動画あり

余弦定理で辺の長さを求める

b = 3、c = 5、A = 60°。2辺と間の角なら余弦定理、と即断する見分け方。

 第12回・動画あり

三角形の面積（2辺と間の角）

AB = 5、AC = 6、A = 30°。高さが無くても S = ½bc sin A で出せます。

数学I：データの分析 ／ 数学A：場合の数・整数の性質

第6回・動画あり

仮平均法で平均値を求める

ズレだけを合計する時短テクニック。大きい数のたし算を避けてミスを消します。

 第7回・動画あり

組合せの計算を工夫する

₁₀₀C₉₈ と ₂₁C₁₅ + ₂₁C₁₆。nCr = nC(n−r) とパスカルの法則の2つだけで足ります。

 第13回・動画あり

公約数と公倍数を書き出す

24 と 36。素因数分解して、小さい指数で G、大きい指数で L。

 第15回・動画あり

分散と標準偏差を求める

2, 4, 6, 8, 10。分散は「2乗の平均 − 平均の2乗」で一発。k倍の性質まで。

今後の追加予定

数学I（数と式・2次関数・三角比）→ 数学A（場合の数・確率）→ 数学II（三角関数・微分積分）の順に、頻出パターンから公開していきます。
