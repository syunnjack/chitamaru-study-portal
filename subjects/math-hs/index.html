高校数学

高校数学でつまずく最大の原因は「才能がない」ことではなく、型の在庫がないまま初見問題に挑むことです。ここでは例題の解法を覚え、使える型を1つずつ増やしていきます。

高校数学の進め方（知多丸式）

  1. 解説動画を見て、型の名前と手順を頭に入れる。
  2. 動画を止めながら、同じ問題を自分の手で書き写す。
  3. 翌日、類題を何も見ずに解く。詰まったら5分で解答へ。
  4. 1週間後、方針を30秒で言えるか確認する。

科目の並び：数学I・A（高1）→ 数学II・B（高2）→ 数学III・C（高3・理系）。下の章立てもこの順です。共通テストだけなら I・A・II・B までで十分です。

数学I：2次関数・2次方程式

放物線の頂点を求める

y = x² + 8x + 5 の頂点。型は「平方完成」ひとつだけ。検算の作法までセットで覚えます。

 第2回・動画あり

2次方程式を解の公式で解く

x² − 5x + 3 = 0。因数分解を10秒で見切り、解の公式へ。検算は解と係数の関係で。

 第3回・動画あり

異なる実数解の個数を求める

x² − 6x + 10 = 0。解かずに判別式 D の符号だけで答える型。

 第8回・動画あり

平方完成（x² の係数が 1 でないとき）

y = 2x² − 12x + 5。くくり出す → 半分の2乗を引く → 外の数をかける、の3拍子。

 第9回・動画あり

定義域つきの最大・最小

y = x² − 4x + 1（0 ≦ x ≦ 3）。候補は頂点と両端の3点だけ。

 第10回・動画あり

グラフの平行移動

x → x − p、y → y − q の1行。符号が逆になることと、頂点での検算。

 第14回・動画あり

2次不等式を解く

x² − 5x + 6 > 0。境目を出して「> 0 は外側、< 0 は内側」と決めるだけ。
