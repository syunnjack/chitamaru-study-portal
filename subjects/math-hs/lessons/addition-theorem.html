第61回　加法定理は「知っている角に分ける」

sin 75° の値を求めよ。

三角定規に出てこない角も、知っている角の和に分ければ出せます（動画・音声解説つき）。

解法の型

sin(α + β) = sin α cos β + cos α sin β　（75° = 45° + 30° に分ける）

15°、75°、105° は 45° と 30° の和や差で作れます。sin は符号がそのまま、cos は符号が逆になります。

解答手順

  1. 角を分ける
    75° = 45° + 30°

    15の倍数は 45° と 30° の組み合わせで作れます。

  2. 加法定理に代入
    sin45° cos30° + cos45° sin30°
  3. 値を入れる
    (√2/2)(√3/2) + (√2/2)(1/2) = √6/4 + √2/4
  4. まとめる
    sin 75° = (√6 + √2) / 4

検算：(√6 + √2)/4 ≒ 0.966 で、sin 90° = 1 に近い値になっています。sin 75° = cos 15° の関係とも一致します。

差がつく2行

  1. cos(α + β) = cos α cos β − sin α sin β。「サインはそのまま、コサインは逆」と声に出して覚えます。
  2. α = β とすれば 2倍角の公式が作れます（sin 2α = 2 sin α cos α）。公式を忘れても加法定理から復元できます。

覚えるべきこと（在庫に入れる1行）

sin(α + β) = sinα cosβ + cosα sinβ（サインはそのまま）

類題（翌日、何も見ずに）

  1. cos 15°
    答え

    cos(45° − 30°) = (√2/2)(√3/2) + (√2/2)(1/2) = (√6 + √2)/4

  2. sin 15°
    答え

    sin(45° − 30°) = (√6 − √2)/4

  3. tan 75°
    答え

    tan(45° + 30°) = (1 + 1/√3) ÷ (1 − 1/√3) = 2 + √3
