第65回　相加相乗は「積が定数」のときに使う

x > 0 のとき、x + 4/x の最小値と、そのときの x の値を求めよ。

微分を使わなくても1行で終わります。ただし使える条件があります（動画・音声解説つき）。

解法の型

a > 0、b > 0 のとき a + b ≧ 2√(ab)　（等号は a = b のとき）

使えるのは積が定数のときだけ。x と 4/x の積は 4 で定数なので使えます。

解答手順

  1. 積を確かめる
    x × (4/x) = 4（定数）

    積が定数だから相加相乗が使えます。

  2. 不等式を書く
    x + 4/x ≧ 2√(x × 4/x) = 2√4 = 4

    x > 0 の条件も必ず書きます。

  3. 等号成立を調べる
    x = 4/x → x² = 4 → x > 0 より x = 2

    等号成立を書かないと「最小値」と言い切れません。

  4. 答えをまとめる
    x = 2 のとき最小値 4

検算：x = 2 で 4、x = 1 と x = 4 では 5。両側で大きくなるので最小値 4 で正しいです。微分 1 − 4/x² = 0 からも x = 2 が出ます。

差がつく2行

  1. 等号成立を書かないと減点されます。「4 以上」だけでは、4 になる x があると示せていません。
  2. 等号成立の値が定義域の外なら相加相乗は使えません（増減を調べる）。積が定数でない形も同様です。

覚えるべきこと（在庫に入れる1行）

積が定数なら a + b ≧ 2√(ab)、等号は a = b

類題（翌日、何も見ずに）

  1. x > 0 のとき 3x + 12/x の最小値
    答え

    積 = 36 なので 2√36 = 12。等号は 3x = 12/x → x = 2

  2. x > 0 のとき x + 1/x の最小値
    答え

    2√1 = 2、等号は x = 1

  3. a > 0、b > 0、ab = 9 のときの a + b の最小値
    答え

    2√9 = 6、等号は a = b = 3
