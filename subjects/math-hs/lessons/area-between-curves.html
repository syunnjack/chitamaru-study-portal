第74回　囲まれた面積は「上 − 下」を積分

曲線 y = √x と 直線 y = x で囲まれた部分の面積を求めよ。

まず交点、次に上下の判定、最後に積分。順番を守れば必ず解けます（動画・音声解説つき）。

解法の型

面積 = ∫(上の関数 − 下の関数) dx　（区間は交点で決める）

どちらが上かは、区間内の1点を代入して比べるのが確実です。

解答手順

  1. 交点を求める
    √x = x → x = x² → x(x - 1) = 0 → x = 0, 1

    両辺を2乗するときは x ≧ 0 の確認を。

  2. 上下を判定
    x = 1/4 で √x = 1/2、x = 1/4 → √x が上

    代入して比べるのが最も確実です。

  3. 積分を立てる
    S = ∫(0→1) (√x - x) dx
  4. 計算する
    = [ (2/3)x^(3/2) - x²/2 ] = 2/3 - 1/2 = 1/6

    √x = x^(1/2) の積分は指数を1つ上げて割るだけ。

検算：最大の高さは x = 1/4 のときの 1/4、幅は 1 なので面積は 1/4 より小さいはず（1/6 ≒ 0.167）。y で積分しても ∫(y − y²)dy = 1/6 で一致します。

差がつく2行

  1. 上下が入れ替わるなら区間を分ける。分けないと打ち消し合って答えが小さくなります（面積は必ず正）。
  2. x = の形に直しやすいときは y で積分する手もあります（両方できれば検算に使えます）。

覚えるべきこと（在庫に入れる1行）

面積 = ∫(上 - 下) dx、区間は交点

類題（翌日、何も見ずに）

  1. y = x² と y = x で囲まれた面積
    答え

    交点 0, 1。∫(x − x²)dx = 1/2 − 1/3 = 1/6

  2. y = √x と y = x で囲まれた部分を y で積分して求める
    答え

    ∫(0→1)(y − y²)dy = 1/6

  3. y = x³ と y = x で囲まれた部分（x ≧ 0）の面積
    答え

    交点 0, 1。∫(x − x³)dx = 1/2 − 1/4 = 1/4
