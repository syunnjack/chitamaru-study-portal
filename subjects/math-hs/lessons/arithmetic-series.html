第20回　等差数列の和は「初項と末項の平均 × 項数」

初項 3、公差 5 の等差数列について、初項から第20項までの和 S₂₀ を求めよ。

公式を2つ覚えるのではなく、使う方を1つに固定するのが要領です（動画・音声解説つき）。

解法の型

Sₙ = n（a₁ + aₙ）÷ 2 ＝（初項と末項の平均）×（項数）

末項さえ出せば終わりなので、まず一般項を書きます。

解答手順

  1. 一般項
    aₙ = a₁ + (n − 1)d = 3 + 5(n − 1) = 5n − 2

    公差にかけるのは n ではなく n − 1。ここが最頻出のミスです。

  2. 末項
    a₂₀ = 5(20) − 2 = 98

    3, 8, 13, 18, … と5ずつ増える20番目です。

  3. 和の公式
    S₂₀ = 20(3 + 98) / 2 = 10 × 101 = 1010

検算：もう一つの公式 Sₙ = n{2a₁ + (n − 1)d} / 2 でも 20(6 + 95) / 2 = 1010。1010 ÷ 20 = 50.5 は 3 と 98 の平均なので、値の大きさも自然です。

差がつく2行

  1. 「第10項から第20項までの和」は範囲を直接扱わず、S₂₀ − S₉ と引き算します。
  2. Sₙ は n の2次式。だから「和が最大になる n」は、項が正から負に変わるところ（＝2次関数の頂点付近）で決まります。

覚えるべきこと（在庫に入れる1行）

等差数列の和 =（初項 + 末項）÷ 2 × 項数

類題（翌日、何も見ずに）

  1. 初項 2、公差 3 の初項から第15項までの和
    答え

    a₁₅ = 2 + 3×14 = 44 → S₁₅ = 15(2 + 44)/2 = 345

  2. 1 から 100 までの整数の和
    答え

    100(1 + 100)/2 = 5050

  3. 初項 3、公差 5 の第10項から第20項までの和
    答え

    S₂₀ − S₉ = 1010 − 9(3 + 43)/2 = 1010 − 207 = 803
