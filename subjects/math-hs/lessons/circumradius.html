第47回　外接円の半径は正弦定理を「2R =」で使う

△ABC で a = 6、A = 30°、B = 45° のとき、外接円の半径 R と辺 b を求めよ。

外接円と聞いたら正弦定理。最初から「2R =」と書けば、2で割り忘れません（動画・音声解説つき）。

解法の型

a / sin A = b / sin B = c / sin C = 2R

半径を出すときは最初から「2R = a / sin A」と書くのがコツ。R と 2R の混同が一番多いミスです。

解答手順

  1. 2R の形で書く
    2R = a / sin A = 6 / sin 30°
  2. R を求める
    = 6 ÷ (1/2) = 12 → R = 6

    6 ÷ (1/2) は 6 × 2。分数で割るときは逆数をかけます。

  3. b を求める
    b = 2R sin B = 12 × sin 45° = 12 × (√2/2)
  4. 計算する
    b = 6√2

検算：b / sin B = 6√2 ÷ (√2/2) = 12 = 2R で一致。さらに ∠B > ∠A なら b > a のはずで、6√2 ≒ 8.5 > 6 と大小関係も合います。

差がつく2行

  1. この単元の最大の失点は R と 2R の混同。最初から「2R = a / sin A」と書けば起きません。
  2. S = abc ÷ (4R) を知っていると、3辺が分かっているときに R が一撃で出ます（面積はヘロンの公式や余弦定理から）。

覚えるべきこと（在庫に入れる1行）

2R = a / sin A（外接円は「2R =」で書く）

類題（翌日、何も見ずに）

  1. a = 4、A = 45° の三角形の外接円の半径
    答え

    2R = 4 ÷ (√2/2) = 4√2 → R = 2√2

  2. 上の △ABC の ∠C と 辺 c
    答え

    C = 180° − 30° − 45° = 105°、c = 2R sin105°（sin105° = (√6 + √2)/4 より c = 3√6 + 3√2）

  3. 外接円の半径が 5、a = 8 のときの sin A
    答え

    2R = 10 なので sin A = 8/10 = 4/5
