第59回　重複組合せは「仕切りを入れる」

3種類のジュースが並ぶ自販機で、合計6本を買う。同じ種類を何本買ってもよく、0本の種類があってもよいとき、買い方は何通りか。

数え上げようとすると大変ですが、置きかえると一瞬で終わります（動画・音声解説つき）。

解法の型

n 種類から重複を許して r 個 = 〇 r 個と仕切り (n − 1) 本の並べ方 = r + n − 1Cn − 1

〇〇｜〇〇〇｜〇 のように書けば、仕切りで区切られた個数がそのまま各種類の本数になります。

解答手順

  1. 仕切りに置きかえる
    〇6個 と 仕切り2本 の並べ方

    3種類なら仕切りは2本。種類の数 − 1 です。

  2. 対応を確認する
    〇〇|〇〇〇|〇 → (2, 3, 1) 本

    仕切りが端や隣どうしなら 0 本の種類ができます。

  3. 並べ方を数える
    全部で8個の場所から仕切りの2か所を選ぶ → 8C2
  4. 計算する
    8C2 = (8 × 7) ÷ 2 = 28（通り）

検算：3種類から2本なら公式は 4C2 = 6。書き出すと (2,0,0)(0,2,0)(0,0,2)(1,1,0)(1,0,1)(0,1,1) の6通りで一致します。小さい数で確かめるのが最強の検算です。

差がつく2行

  1. 「各種類1本以上」なら先に1本ずつ配る。残り3本を自由に配って 5C2 = 10 通り。
  2. これは x + y + z = 6 の 0 以上の整数解の個数と同じ問題です。式で出てきても同じ道具が使えます。

覚えるべきこと（在庫に入れる1行）

重複組合せは 〇 r 個と仕切り (n - 1) 本の並べ方

類題（翌日、何も見ずに）

  1. 4種類から重複を許して5個選ぶ
    答え

    8C3 = 56 通り

  2. 3種類のジュースを各1本以上、合計6本買う
    答え

    先に1本ずつ配り、残り3本を配って 5C2 = 10 通り

  3. x + y + z = 6 の 0 以上の整数解の個数
    答え

    8C2 = 28 個（本問と同じ）
