第31回　複素数のかけ算は「大きさはかける、角はたす」

z = 1 + √3 i を極形式で表し、z⁶ を求めよ。

大きさと角に分けてしまえば、指数の計算より簡単になります（動画・音声解説つき）。

解法の型

z = r(cosθ + i sinθ) のとき zⁿ = rⁿ (cos nθ + i sin nθ)（ド・モアブルの定理）

かけ算では大きさはかけ算、角はたし算になります。

解答手順

  1. 極形式にする
    r = √(1² + (√3)²) = 2
    cosθ = 1/2、sinθ = √3/2 → θ = 60°
    z = 2(cos60° + i sin60°)
  2. 6 乗する
    z⁶ = 2⁶ (cos360° + i sin360°) = 64 × (1 + 0i)
    答え z⁶ = 64

検算：z² = (1 + √3i)² = −2 + 2√3 i は大きさ 4・角 120°（角がちゃんと2倍）。(z²)³ = 4³(cos360° + i sin360°) = 64 で一致します。

差がつく2行

  1. i をかけることは 90° 回転。図形問題で「点を90°回す」と言われたら i をかけるだけです。
  2. 1 の n 乗根は単位円を n 等分した点。z³ = 1 の解は 120° ずつ並ぶ3点になります。

覚えるべきこと（在庫に入れる1行）

zⁿ = rⁿ(cos nθ + i sin nθ)：大きさはかける、角はたす

類題（翌日、何も見ずに）

  1. (1 + i)⁸
    答え

    r = √2、θ = 45° → (√2)⁸(cos360° + i sin360°) = 16

  2. z = √3 + i を極形式で
    答え

    r = 2、θ = 30° → 2(cos30° + i sin30°)

  3. (cos20° + i sin20°)⁹
    答え

    角が 180° → cos180° + i sin180° = −1

解説の全文を読む
  1. こんにちは。知多丸の落ちこぼれ救済チャンネルです。難関大学に合格して、錯覚資産を手に入れて、一流企業に入社しよう。今日の問題は、ゼット は 1 たす ルート3 アイ を極形式で表し、ゼット の6乗 を求めなさい。複素数のかけ算は、大きさと角に分けてしまえば、指数の計算より簡単になります。
  2. 型はこれです。極形式は、大きさ アール かける かっこ コサイン シータ たす アイ サイン シータ。かけ算では、大きさはかけ算、角はたし算になります。だから エヌ乗 は、大きさが アール の エヌ乗、角が エヌ シータ。これがド・モアブルの定理です。
  3. 手順1。大きさと角を出します。アール は ルート かっこ 1 たす 3 で 2。コサイン シータ は 2分の1、サイン シータ は 2分のルート3 なので、シータ は 60度、つまり 3分のパイ。よって ゼット は 2 かける かっこ コサイン60度 たす アイ サイン60度 です。
  4. 手順2。6乗します。大きさは 2 の6乗 で 64。角は 60度 かける 6 で 360度。コサイン360度 は 1、サイン360度 は 0 なので、ゼット の6乗 は 64 です。実数になりました。
  5. 検算です。2乗から順に確かめます。ゼット の2乗 は、かっこ 1 たす ルート3 アイ の2乗 で、1 たす 2ルート3 アイ たす 3 アイ2乗。アイ2乗 は マイナス1 なので、マイナス2 たす 2ルート3 アイ。これは大きさ4、角120度。角がちゃんと2倍になっています。3乗すると角は360度、大きさは64。合っています。
  6. 差がつく2行。1つめ。アイ をかけることは、90度の回転です。図形問題で「点を90度回す」と言われたら、アイ をかけるだけで終わります。2つめ。1 の エヌ乗根 は、単位円上を エヌ 等分した点です。ゼット の3乗 が 1 の解は、120度ずつ並ぶ3点になります。
  7. おつかれさまでした。在庫に入れる1行は、これです。複素数のかけ算は、大きさはかける、角はたす。明日、何も見ずに、かっこ 1 たす アイ の8乗 をやってみてください。答えは 16 です。チャンネル登録をして、次の動画でも一緒に、要領よく積み上げていきましょう。
