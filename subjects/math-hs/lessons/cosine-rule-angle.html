第46回　3辺が分かれば角は余弦定理の逆

△ABC で BC = 7、CA = 8、AB = 5 のとき、∠A の大きさを求めよ。

3辺が分かって角を聞かれたら、道は1本しかありません（動画・音声解説つき）。

解法の型

cos A = (b² + c² − a²) ÷ (2bc)　（a は ∠A の向かい側の辺）

3辺 → 角は余弦定理の逆。「向かい側の辺だけマイナス」と覚えます。

解答手順

  1. 辺の対応を書く
    a = BC = 7、b = CA = 8、c = AB = 5

    ∠A の向かい側が a。ここを取り違えると全部ずれます。

  2. 公式に代入
    cos A = (8² + 5² - 7²) / (2 × 8 × 5)
  3. 計算する
    = (64 + 25 - 49) / 80 = 40 / 80 = 1/2
  4. 角度を答える
    cos A = 1/2 → ∠A = 60°

    cos が 1/2、√2/2、√3/2 になる角は暗記事項です。

検算：cos A > 0 なので ∠A は鋭角。最大辺 CA = 8 の向かいにある ∠B が最大角になり、つじつまが合います。面積 (1/2)×8×5×sin 60° = 10√3 も出せます。

差がつく2行

  1. cos が負なら鈍角。三角形の鈍角は1つだけで、必ず最大辺の向かい側にあります（答えの妥当性チェックに使えます）。
  2. 使い分けは3行で覚えます：3辺→角は余弦定理の逆、2辺と間の角→辺は余弦定理、角2つ→辺は正弦定理。

覚えるべきこと（在庫に入れる1行）

cos A = (b² + c² - a²) / (2bc)（向かい側の辺だけマイナス）

類題（翌日、何も見ずに）

  1. 3辺が 3、5、7 の三角形で、7 の向かい側の角
    答え

    cos = (9 + 25 − 49) / 30 = −1/2 → 120°

  2. BC = 7、CA = 8、AB = 5 の △ABC の面積
    答え

    sin A = √3/2 なので (1/2)×8×5×(√3/2) = 10√3

  3. 3辺が 5、12、13 の三角形で最大の角
    答え

    cos = (25 + 144 − 169) / 120 = 0 → 90°（直角三角形）
