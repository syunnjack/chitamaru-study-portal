第11回　余弦定理で辺の長さを求める

三角形 ABC で b = 3、c = 5、A = 60° のとき、a の長さを求めよ。

正弦定理か余弦定理かで迷わないための見分け方も一緒に固めます（動画・音声解説つき）。

見分け方（これで迷わない）

2辺とその間の角 → 余弦定理　／　角と向かいの辺が2組 → 正弦定理

a² = b² + c² − 2bc·cos A

左辺の辺 a と、cos の中の角 A は向かい合います（三平方の定理に補正がついた形）。

解答手順

  1. 代入する
    a² = 3² + 5² − 2·3·5·cos 60°　,　cos 60° = 1/2
  2. 計算する
    a² = 34 − 15 = 19
  3. 正の平方根をとる
    a = √19 ( ≒ 4.36 )

    長さなので負は捨てます。

検算：5 − 3 < √19 < 5 + 3（2 < 4.36 < 8）で成立。さらに A < 90° なので a < √(9 + 25) = √34 ≒ 5.83 も満たします。

覚えるべきこと（在庫に入れる1行）

2辺と間の角 → a² = b² + c² − 2bc·cos A

類題（翌日、何も見ずに）

  1. b = 2、c = 3、A = 120° のとき a
    答え

    a² = 4 + 9 + 6 = 19、a = √19

  2. b = 4、c = 5、A = 45° のとき a
    答え

    a² = 16 + 25 − 20√2 = 41 − 20√2、a = √(41 − 20√2)

  3. a = 7、b = 5、c = 3 のとき cos A
    答え

    cos A = (25 + 9 − 49)/(2·5·3) = −1/2、A = 120°

解説の全文を読む
  1. こんにちは。知多丸の落ちこぼれ救済チャンネルです。難関大学に合格して、錯覚資産を手に入れて、一流企業に入社しよう。今日の問題は、こちら。三角形 エービーシー で、ビーシー を エー、シーエー を ビー、エービー を シー とします。ビー イコール 3、シー イコール 5、角エー イコール 60度 のとき、エー の長さを求めよ。ここで、正弦定理か、余弦定理か、迷わないための見分け方を身につけます。
  2. まず、見分け方です。2辺と、その間の角。この形が出たら、余弦定理。角と、その向かい合う辺が、ペアで2組そろっていたら、正弦定理。今回は、ビー と シー、そしてその間の角 エー ですから、余弦定理で決まりです。
  3. 使う式は、これです。エー2乗 イコール、ビー2乗 プラス シー2乗 マイナス、2 ビーシー コサインエー。求めたい辺を左、その向かいの角を、最後のコサインに置く。この対応だけ間違えなければ大丈夫です。
  4. 手順1。数値を入れます。ビー2乗 は 9。シー2乗 は 25。2 ビーシー は、2 かける 3 かける 5 で、30。コサイン60度 は、2分の1 です。
  5. 手順2。計算します。9 プラス 25 は 34。30 かける 2分の1 は 15。34 マイナス 15 は、19。ですから、エー2乗 イコール 19。
  6. 手順3。エー は長さですから、正の方だけをとります。エー イコール、ルート19。これが答えです。ルート19 は、およそ 4.36 くらい。この概算も、あとの検算で使います。
  7. 検算です。三角形は、2辺の差より長く、2辺の和より短い。差は、5 マイナス 3 で 2。和は 8。ルート19 は およそ 4.36 ですから、2 と 8 のあいだ。ちゃんと成り立っています。さらに、角エー が 60度、つまり直角より小さいので、エー は 直角のとき、つまり ルート34 より短いはず。4.36 は ルート34 の およそ 5.83 より小さい。これも合っています。
  8. おつかれさまでした。在庫に入れる1行は、これです。2辺と間の角なら、余弦定理。エー2乗 イコール、ビー2乗 プラス シー2乗 マイナス 2ビーシー コサインエー。明日、何も見ずに、ビー イコール 2、シー イコール 3、角エー イコール 120度 でやってみてください。答えは ルート19 になります。 チャンネル登録をして、次の動画でも一緒に、要領よく積み上げていきましょう。
