第11回　余弦定理で辺の長さを求める

三角形 ABC で b = 3、c = 5、A = 60° のとき、a の長さを求めよ。

正弦定理か余弦定理かで迷わないための見分け方も一緒に固めます（動画・音声解説つき）。

見分け方（これで迷わない）

2辺とその間の角 → 余弦定理　／　角と向かいの辺が2組 → 正弦定理

a² = b² + c² − 2bc·cos A

左辺の辺 a と、cos の中の角 A は向かい合います（三平方の定理に補正がついた形）。

解答手順

  1. 代入する
    a² = 3² + 5² − 2·3·5·cos 60°　,　cos 60° = 1/2
  2. 計算する
    a² = 34 − 15 = 19
  3. 正の平方根をとる
    a = √19 ( ≒ 4.36 )

    長さなので負は捨てます。

検算：5 − 3 < √19 < 5 + 3（2 < 4.36 < 8）で成立。さらに A < 90° なので a < √(9 + 25) = √34 ≒ 5.83 も満たします。

覚えるべきこと（在庫に入れる1行）

2辺と間の角 → a² = b² + c² − 2bc·cos A

類題（翌日、何も見ずに）

  1. b = 2、c = 3、A = 120° のとき a
    答え

    a² = 4 + 9 + 6 = 19、a = √19

  2. b = 4、c = 5、A = 45° のとき a
    答え

    a² = 16 + 25 − 20√2 = 41 − 20√2、a = √(41 − 20√2)

  3. a = 7、b = 5、c = 3 のとき cos A
    答え

    cos A = (25 + 9 − 49)/(2·5·3) = −1/2、A = 120°
