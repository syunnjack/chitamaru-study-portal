第54回　共分散は「偏差の積の平均」

4組のデータ (x, y) = (2, 5), (4, 9), (6, 8), (8, 14) について、共分散を求めよ。

表を作れば、あとは足し算だけです。暗算しようとすると符号でミスします（動画・音声解説つき）。

解法の型

共分散 = Σ(dx・dy) ÷ n　（dx、dy は平均からの偏差）

必ず偏差の表を作ります。暗算しようとすると符号のミスが出ます。

解答手順

  1. 平均を出す
    x の平均 = 20 ÷ 4 = 5、y の平均 = 36 ÷ 4 = 9
  2. 偏差の表を作る
    dx : -3, -1, 1, 3　／　dy : -4, 0, -1, 5

    dx の合計と dy の合計はどちらも 0 になります（検算に使えます）。

  3. 積を並べて足す
    dx・dy : 12, 0, -1, 15 → 合計 26
  4. n で割る
    共分散 = 26 ÷ 4 = 6.5

検算：Σdx = 0、Σdy = 0 になっていれば偏差の計算は正しいです。共分散が正なので右上がりの傾向で、データの並びと一致します。

差がつく2行

  1. 相関係数 = 共分散 ÷ (s_x × s_y)。共分散には単位が残るので、標準偏差で割って単位を消したものが相関係数です。
  2. 共分散 = (xy の平均) − (x の平均)(y の平均) も使えます。今回は 51.5 − 45 = 6.5 で一致（データが多いとこちらが速い）。

覚えるべきこと（在庫に入れる1行）

共分散 = 偏差の積の平均（Σdx・dy ÷ n）

類題（翌日、何も見ずに）

  1. (1, 3), (2, 5), (3, 4) の共分散
    答え

    平均は x = 2、y = 4。dx = −1, 0, 1、dy = −1, 1, 0 で積の和 = 1、共分散 = 1/3

  2. 上の4組データの x の標準偏差
    答え

    dx² の和 = 9 + 1 + 1 + 9 = 20、分散 = 5、標準偏差 = √5

  3. 上の4組データの相関係数
    答え

    y の分散 = (16 + 0 + 1 + 25)/4 = 10.5、r = 6.5 ÷ (√5 × √10.5) ≒ 0.90

  3. 手順1。エックス の合計は 20 で平均 5。わい の合計は 36 で平均 9 です。
