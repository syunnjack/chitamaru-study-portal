第22回　3次関数の極値は「微分してゼロ、符号を見る」

f(x) = x³ − 3x² − 9x + 5 の極大値と極小値を求めよ。

手が止まりやすい単元ですが、手順は3つに固定できます（動画・音声解説つき）。

解法の型

① f′(x) を因数分解　② f′(x) = 0 と増減表　③ もとの f(x) に代入

値を出すのは f(x) です。微分した f′(x) に代入してしまうミスが最頻出です。

解答手順

  1. 微分して因数分解
    f′(x) = 3x² − 6x − 9 = 3(x² − 2x − 3) = 3(x − 3)(x + 1)

    先に 3 でくくると因数分解が軽くなります。

  2. 増減表
    f′(x) = 0 → x = −1, 3　／　増 →（x = −1 極大）→ 減 →（x = 3 極小）→ 増

    f′ は下に凸の2次関数なので、2解の外側が正、間が負です。

  3. もとの式に代入
    f(−1) = −1 − 3 + 9 + 5 = 10　／　f(3) = 27 − 27 − 27 + 5 = −22
    極大値 10（x = −1）、極小値 −22（x = 3）

検算：3次関数は極大が左・極小が右で、極大値 > 極小値。10 > −22 なので整合します。f(0) = 5 も −1 と 3 の間（減少中）の値として自然です。

差がつく2行

  1. 3次方程式 f(x) = 0 の実数解の個数は（極大値）×（極小値）の符号で決まります。10 × (−22) < 0 なので実数解は3個。
  2. f′(x) = 0 でも符号が変わらなければ極値ではありません（例：y = x³ は x = 0 で f′ = 0 でも増加のまま）。

覚えるべきこと（在庫に入れる1行）

微分してゼロ → 符号を見る → もとの式に代入

類題（翌日、何も見ずに）

  1. y = x³ − 3x の極値
    答え

    y′ = 3(x − 1)(x + 1) → 極大値 2（x = −1）、極小値 −2（x = 1）

  2. y = x³ − 6x² + 9x の極値
    答え

    y′ = 3(x − 1)(x − 3) → 極大値 4（x = 1）、極小値 0（x = 3）

  3. x³ − 3x² − 9x + 5 = 0 の実数解の個数
    答え

    10 × (−22) < 0 なので3個

解説の全文を読む
  1. こんにちは。知多丸の落ちこぼれ救済チャンネルです。難関大学に合格して、錯覚資産を手に入れて、一流企業に入社しよう。今日の問題は、エフ エックス は エックス の3乗 ひく 3エックスの2乗 ひく 9エックス たす 5 の極値を求めなさい。3次関数の極値は、手が止まる人がいちばん多いところですが、手順は完全に固定できます。
  2. 型はこれです。手順は3つ。1、微分して エフ ダッシュ エックス を因数分解する。2、エフ ダッシュ エックス が ゼロ になる エックス を出して、増減表を書く。3、その エックス を もとの式に入れて、値を出す。微分した式に入れるのではありません。ここを間違える人が本当に多いです。
  3. 手順1。微分します。エックスの3乗 は 3エックスの2乗。ひく 3エックスの2乗 は ひく 6エックス。ひく 9エックス は ひく 9。定数の 5 は消えます。エフ ダッシュ エックス は 3エックスの2乗 ひく 6エックス ひく 9。3 でくくって、3かっこ エックスの2乗 ひく 2エックス ひく 3。さらに因数分解して、3かっこ エックス ひく 3 かっこ エックス たす 1。
  4. 手順2。エフ ダッシュ エックス が ゼロ になるのは、エックス が マイナス1 と 3。増減表を書きます。エフ ダッシュ は 上に開いた2次関数なので、外側でプラス、間でマイナス。つまり、エックス が マイナス1 より小さいところで増加、マイナス1 から 3 の間で減少、3 より大きいところで増加。だから マイナス1 で極大、3 で極小です。
  5. 手順3。もとの式に入れます。エフ マイナス1 は、マイナス1 ひく 3 たす 9 たす 5 で 10。エフ 3 は、27 ひく 27 ひく 27 たす 5 で マイナス22。したがって、極大値は 10、極小値は マイナス22 です。
  6. 検算です。3次関数のグラフは、極大が左、極小が右にきて、極大値のほうが大きい。10 は マイナス22 より大きいので、上下の関係は合っています。もう一つ。エックス が 0 のとき エフ は 5。これは 極大の 10 より小さく、極小の マイナス22 より大きいので、減っていく途中の値として自然です。
  7. 差がつく2行。1つめ。3次方程式 エフ エックス は ゼロ の実数解の個数は、極大値 かける 極小値 の符号で決まります。10 かける マイナス22 はマイナスなので、この関数は エックス 軸を3回横切り、実数解は3個です。2つめ。エフ ダッシュ エックス が ゼロ でも、符号が変わらなければ極値にはなりません。たとえば エックス の3乗 は、微分が ゼロ になっても増え続けます。
  8. おつかれさまでした。在庫に入れる1行は、これです。微分してゼロ、符号を見て、もとの式に代入。明日、何も見ずに、エックスの3乗 ひく 3エックス の極値をやってみてください。極大値は 2、極小値は マイナス2 です。チャンネル登録をして、次の動画でも一緒に、要領よく積み上げていきましょう。
