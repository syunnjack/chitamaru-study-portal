第22回　3次関数の極値は「微分してゼロ、符号を見る」

f(x) = x³ − 3x² − 9x + 5 の極大値と極小値を求めよ。

手が止まりやすい単元ですが、手順は3つに固定できます（動画・音声解説つき）。

解法の型

① f′(x) を因数分解　② f′(x) = 0 と増減表　③ もとの f(x) に代入

値を出すのは f(x) です。微分した f′(x) に代入してしまうミスが最頻出です。

解答手順

  1. 微分して因数分解
    f′(x) = 3x² − 6x − 9 = 3(x² − 2x − 3) = 3(x − 3)(x + 1)

    先に 3 でくくると因数分解が軽くなります。

  2. 増減表
    f′(x) = 0 → x = −1, 3　／　増 →（x = −1 極大）→ 減 →（x = 3 極小）→ 増

    f′ は下に凸の2次関数なので、2解の外側が正、間が負です。

  3. もとの式に代入
    f(−1) = −1 − 3 + 9 + 5 = 10　／　f(3) = 27 − 27 − 27 + 5 = −22
    極大値 10（x = −1）、極小値 −22（x = 3）

検算：3次関数は極大が左・極小が右で、極大値 > 極小値。10 > −22 なので整合します。f(0) = 5 も −1 と 3 の間（減少中）の値として自然です。

差がつく2行

  1. 3次方程式 f(x) = 0 の実数解の個数は（極大値）×（極小値）の符号で決まります。10 × (−22) < 0 なので実数解は3個。
  2. f′(x) = 0 でも符号が変わらなければ極値ではありません（例：y = x³ は x = 0 で f′ = 0 でも増加のまま）。

覚えるべきこと（在庫に入れる1行）

微分してゼロ → 符号を見る → もとの式に代入

類題（翌日、何も見ずに）

  1. y = x³ − 3x の極値
    答え

    y′ = 3(x − 1)(x + 1) → 極大値 2（x = −1）、極小値 −2（x = 1）

  2. y = x³ − 6x² + 9x の極値
    答え

    y′ = 3(x − 1)(x − 3) → 極大値 4（x = 1）、極小値 0（x = 3）

  3. x³ − 3x² − 9x + 5 = 0 の実数解の個数
    答え

    10 × (−22) < 0 なので3個
