第80回　複素数の累乗は「極形式にしてから n 乗」

(1 + i)⁸ を計算せよ。

展開して8回かけるのは現実的ではありません。極形式に直します（動画・音声解説つき）。

解法の型

r(cos θ + i sin θ) の n 乗 = rⁿ(cos nθ + i sin nθ)　（大きさは n 乗、角度は n 倍）

展開せずに、大きさと角度に分けてから累乗します。

解答手順

  1. 大きさを出す
    |1 + i| = √(1 + 1) = √2
  2. 角度を出す
    1 + i は第1象限で 実部 = 虚部 → θ = 45°（π/4）

    図を描けば一目で分かります。

  3. ド・モアブル
    (√2)⁸ (cos(8 × 45°) + i sin(8 × 45°)) = 16(cos360° + i sin360°)

    (√2)⁸ = 2⁴ = 16。角度は 360°。

  4. 答えを出す
    cos360° = 1、sin360° = 0 → 16

検算：(1+i)² = 2i、(1+i)⁴ = (2i)² = −4、(1+i)⁸ = (−4)² = 16 で一致します。指数が 2 の累乗なら2乗を繰り返すのも速い方法です。

差がつく2行

  1. 角度が 360° を超えたら 360 で割ったあまりで考えます。
  2. n 乗根も同じ定理から。角度を n で割り、360°/n ずつ増やした n 個が答えです。

覚えるべきこと（在庫に入れる1行）

大きさは n 乗、角度は n 倍（ド・モアブル）

類題（翌日、何も見ずに）

  1. (1 − i)⁴
    答え

    大きさ √2、角度 −45°。(√2)⁴ = 4、角度 −180° なので 4×(−1) = −4

  2. (1 + i)⁶
    答え

    (√2)⁶ = 8、角度 270° で cos270° = 0、sin270° = −1 なので −8i

  3. (cos30° + i sin30°)⁶
    答え

    角度 180° なので −1
