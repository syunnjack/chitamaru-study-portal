第25回　定積分で面積を出すときは「上 ひく 下」

y = x² − 2x と x 軸で囲まれた部分の面積を求めよ。

公式を思い出す前に、どちらの式が上かを決めるのが先です（動画・音声解説つき）。

解法の型

面積 = ∫（上の式 − 下の式）dx、区間は交点から交点まで

答えが負になったら、上下の取り方が逆というサインです。

解答手順

  1. 交点と上下を決める
    x² − 2x = 0 → x(x − 2) = 0 → x = 0, 2

    0 < x < 2 では放物線が x 軸より下。上は x 軸（y = 0）、下は放物線です。

  2. 積分する
    ∫₀² (2x − x²) dx = [ x² − x³/3 ]₀²
    = 4 − 8/3 = 4/3

検算：放物線と直線で囲む面積の6分の公式 |a|(β − α)³ / 6 でも 1 × 2³ / 6 = 4/3 で一致します。

差がつく2行

  1. 区間の中で上下が入れかわる点があれば区間を分ける。1本で積分すると打ち消し合って面積より小さくなります。
  2. 負の答えは計算ミスではなく上下が逆のサイン。絶対値を取れば面積です。

覚えるべきこと（在庫に入れる1行）

面積 = ∫（上 − 下）dx、区間は交点から交点

類題（翌日、何も見ずに）

  1. y = x² − 4 と x 軸で囲まれた面積
    答え

    ∫₋₂² (4 − x²) dx = 16 − 16/3 = 32/3

  2. y = x² と y = x で囲まれた面積
    答え

    6分の公式で 1 × 1³ / 6 = 1/6

  3. y = x² − 3x と y = x で囲まれた面積
    答え

    交点 x = 0, 4 → 1 × 4³ / 6 = 32/3
