第67回　階差数列は「a₁ に階差の和を足す」

数列 2, 5, 10, 17, 26, … の一般項を求めよ。

等差でも等比でもない数列は、まず差を見ます（動画・音声解説つき）。

解法の型

aₙ = a₁ + Σ(k = 1 から n − 1) bₖ　（n ≧ 2、bₖ は階差）

上端が n − 1 になる理由：a₁ から aₙ に行くまでに階差を (n − 1) 回足すからです。

解答手順

  1. 階差を書く
    3, 5, 7, 9, … → bₖ = 2k + 1

    階差が等差数列になっていれば、この型です。

  2. 公式に入れる
    aₙ = 2 + Σ(k = 1 から n - 1)(2k + 1)

    上端は n − 1。ここを n にするのが最大のミスです。

  3. Σ を計算
    = 2 + 2 × (n-1)n/2 + (n - 1) = 2 + n² - n + n - 1

    項数が n − 1 個なので、定数1の和は (n − 1) です。

  4. 整理して確認
    aₙ = n² + 1（n = 1 のとき 2 で成立）

    n = 1 の確認を書くのが答案の作法です。

検算：n = 1 から順に代入すると 2, 5, 10, 17, 26 で元の数列と完全に一致します。元の数列に戻すだけで確認できます。

差がつく2行

  1. 上端が n − 1 になるのは、a₁ から aₙ まで階差を (n − 1) 回足すから。理由が分かれば暗記より確実です。
  2. n = 1 の確認を書かないと減点。公式は n ≧ 2 でしか使えません（成り立たない問題では場合分け）。

覚えるべきこと（在庫に入れる1行）

aₙ = a₁ + Σ(k=1 から n-1) bₖ（上端は n - 1）

類題（翌日、何も見ずに）

  1. 1, 3, 7, 13, 21, … の一般項
    答え

    階差 2, 4, 6, 8 = 2k なので aₙ = 1 + (n−1)n = n² − n + 1

  2. 2, 5, 10, 17, 26, … の第10項
    答え

    n² + 1 に n = 10 を入れて 101

  3. 3, 4, 7, 16, 43, … の一般項
    答え

    階差 1, 3, 9, 27 = 3^(k−1) なので aₙ = 3 + (3^(n−1) − 1)/2
