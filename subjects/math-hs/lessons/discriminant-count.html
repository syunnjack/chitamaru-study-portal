第3回　異なる実数解の個数を求める

次の2次方程式の異なる実数解の個数を求めよ。　x² − 4x + 9 = 0

解く必要はありません。判別式 D の符号だけを見ます（動画・音声解説つき）。

覚える表（これだけ）

D = b² − 4ac
D の符号異なる実数解の個数グラフと x 軸
D > 02個2点で交わる
D = 01個（重解）接する
D < 00個交わらない

解答の手順

  1. 係数を書き出す
    a = 1 ,　b = −4 ,　c = 9
  2. D を計算する
    D = (−4)² − 4·1·9 = 16 − 36 = −20
  3. 符号から答える
    D < 0 より、異なる実数解の個数は 0 個

    答案には「D < 0 より」と根拠を1行書きます。

グラフで納得しておく

y = x² − 4x + 9 = (x − 2)² + 5　頂点 ( 2 , 5 )

下に凸で頂点が x 軸より上 → グラフは x 軸と交わらない → 実数解 0 個。「実数解の個数 = グラフと x 軸の交点の個数」と結びつけて覚えておくと、応用問題でも迷いません。

類題（翌日、何も見ずに）

  1. x² − 4x + 4 = 0
    答え

    D = 16 − 16 = 0 → 1個（重解 x = 2）

  2. x² + 2x − 5 = 0
    答え

    D = 4 + 20 = 24 > 0 → 2個

  3. 2x² − 3x + 4 = 0
    答え

    D = 9 − 32 = −23 < 0 → 0個

解説の全文を読む
  1. こんにちは。知多丸の落ちこぼれ救済チャンネルです。難関大学に合格して、錯覚資産を手に入れて、一流企業に入社しよう。今日の問題は、次の2次方程式の、異なる実数解の個数を求めよ。エックスの2乗 マイナス 4エックス プラス 9 イコール 0。解を求める必要はありません。個数だけです。
  2. まず、大事なことを言います。この問題で、解の公式を最後まで計算するのは、時間のむだです。個数を聞かれたときの型は、ただ一つ。判別式、ディー を計算して、符号を見る。それだけで終わります。
  3. 判別式は、ディー イコール、ビーの2乗 マイナス 4エーシー です。解の公式の、ルートの中身と同じものです。この符号で、3つに分かれます。ディーが プラスなら2個、ディーが 0 なら1個、これは重解です。ディーが マイナスなら0個。表で覚えてください。
  4. では、係数を書き出します。エーは1、ビーは マイナス4、シーは 9。ここでも、ビーの、マイナス を忘れないでください。ただし、ビーは2乗しますから、答えは同じになります。それでも、書くときは符号ごと書く習慣をつけましょう。
  5. 手順の2つ目。判別式を計算します。ビーの2乗は、マイナス4 の2乗で、16。4エーシー は、4 かける 1 かける 9 で、36。16 マイナス 36 は、マイナス20 です。
  6. 手順の3つ目。符号を見ます。ディー は マイナス20 ですから、ディー 小なり 0。表のいちばん下です。したがって、異なる実数解の個数は、0個。これが答えです。
  7. グラフでも確認しましょう。平方完成すると、わい イコール かっこ エックス マイナス 2 かっこの2乗 プラス 5。頂点は、2、5 で、下に凸のグラフです。いちばん低い点が、エックス軸より上にありますから、グラフはエックス軸と交わりません。だから、実数解は0個。納得できますね。
  8. 最後に、在庫に入れる1行です。個数を聞かれたら、ディー イコール ビーの2乗 マイナス 4エーシー、の符号だけ見る。類題を1つ置いておきます。エックスの2乗 マイナス 4エックス プラス 4 イコール 0 なら、ディーは 0 で、1個の重解です。翌日、何も見ずにやってみてください。おつかれさまでした。 チャンネル登録をして、次の動画でも一緒に、要領よく積み上げていきましょう。
