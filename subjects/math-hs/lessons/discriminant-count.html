第3回　異なる実数解の個数を求める

次の2次方程式の異なる実数解の個数を求めよ。　x² − 6x + 10 = 0

解く必要はありません。判別式 D の符号だけを見ます（動画・音声解説つき）。

覚える表（これだけ）

D = b² − 4ac
D の符号異なる実数解の個数グラフと x 軸
D > 02個2点で交わる
D = 01個（重解）接する
D < 00個交わらない

解答の手順

  1. 係数を書き出す
    a = 1 ,　b = −6 ,　c = 10
  2. D を計算する
    D = (−6)² − 4·1·10 = 36 − 40 = −4
  3. 符号から答える
    D < 0 より、異なる実数解の個数は 0 個

    答案には「D < 0 より」と根拠を1行書きます。

グラフで納得しておく

y = x² − 6x + 10 = (x − 3)² + 1　頂点 ( 3 , 1 )

下に凸で頂点が x 軸より上 → グラフは x 軸と交わらない → 実数解 0 個。「実数解の個数 = グラフと x 軸の交点の個数」と結びつけて覚えておくと、応用問題でも迷いません。

類題（翌日、何も見ずに）

  1. x² − 6x + 9 = 0
    答え

    D = 36 − 36 = 0 → 1個（重解 x = 3）

  2. x² + 2x − 5 = 0
    答え

    D = 4 + 20 = 24 > 0 → 2個

  3. 2x² − 3x + 4 = 0
    答え

    D = 9 − 32 = −23 < 0 → 0個
