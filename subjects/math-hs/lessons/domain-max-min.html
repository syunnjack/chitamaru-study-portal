第9回　定義域つきの最大・最小

y = x² − 4x + 1　( 0 ≦ x ≦ 3 ) の最大値・最小値を求めよ。

候補は「頂点」と「両端」の3点だけ。それ以外に答えはありません（動画・音声解説つき）。

解法の型（3ステップ）

① 平方完成して頂点を出す　② 頂点が定義域の中にあるか見る　③ 両端の値を出す

解答手順

  1. 平方完成
    y = ( x − 2 )² − 3　→　頂点 ( 2 , −3 )、下に凸
  2. 頂点は定義域の中か
    0 ≦ 2 ≦ 3 → 中にある → 最小値は頂点で確定
    最小値 −3 ( x = 2 )
  3. 両端をくらべる
    x = 0 → y = 1 ／ x = 3 → y = 9 − 12 + 1 = −2
    最大値 1 ( x = 0 )

検算：頂点 x = 2 からの距離は |0 − 2| = 2、|3 − 2| = 1。下に凸なら遠い端で最大 → x = 0 で最大、で一致します。

答案の注意：「x = ○ のとき」を必ず添える。値だけでは減点されます。

覚えるべきこと（在庫に入れる1行）

調べるのは「頂点」と「両端」の3点だけ。頂点が定義域の外なら両端だけを比べる。

類題（翌日、何も見ずに）

  1. y = x² − 4x + 1（3 ≦ x ≦ 5）
    答え

    頂点 x = 2 は定義域の外。最小 −2 (x = 3)、最大 6 (x = 5)

  2. y = −x² + 2x + 3（0 ≦ x ≦ 3）
    答え

    y = −(x − 1)² + 4。最大 4 (x = 1)、最小 0 (x = 3)

  3. y = x² + 2x（−3 ≦ x ≦ −2）
    答え

    頂点 x = −1 は外。最小 0 (x = −2)、最大 3 (x = −3)

解説の全文を読む
  1. こんにちは。知多丸の落ちこぼれ救済チャンネルです。難関大学に合格して、錯覚資産を手に入れて、一流企業に入社しよう。今日の問題は、こちら。ワイ イコール、エックス2乗 マイナス 4エックス プラス 1、ただし、0 以上 3 以下 のとき、最大値と最小値を求めよ。定義域がついた最大・最小は、入試でとてもよく出ます。しかも、型がはっきり決まっています。
  2. 型を確認します。定義域つきの最大・最小は、3つのことしか見ません。1つ、平方完成して頂点を出す。2つ、頂点が定義域の中にあるかを見る。3つ、両端の値を計算する。この3つだけです。グラフの形をぼんやり眺めるのではなく、この順番で手を動かします。
  3. 手順1。平方完成します。エックスの係数は マイナス4、その半分は マイナス2。ですから、カッコ、エックス マイナス2、の2乗、マイナス4、プラス1。まとめて、カッコ、エックス マイナス2、の2乗、マイナス3。頂点は、2、マイナス3 です。
  4. 手順2。頂点のエックス座標は 2。定義域は、0 以上 3 以下。2 は、この中に入っていますね。下に凸のグラフで、頂点が定義域の中にあるなら、最小値は頂点で決まりです。つまり、エックス イコール 2 のとき、最小値 マイナス3。
  5. 手順3。最大値は、両端のうち、頂点から遠い方です。両端を計算します。エックス イコール 0 のとき、ワイ は 1。エックス イコール 3 のとき、9 マイナス 12 プラス 1 で、マイナス2。大きいのは、1 の方。ですから、エックス イコール 0 のとき、最大値 1 です。
  6. 答えをまとめます。エックス イコール 0 のとき、最大値 1。エックス イコール 2 のとき、最小値 マイナス3。答案には、必ず、どのエックスのときか、を書きます。値だけ書くと減点されます。
  7. 検算のコツ。頂点からの距離を見ます。頂点は エックス イコール 2。左端 0 までの距離は 2、右端 3 までの距離は 1。遠いのは左端ですから、最大値は左端で起きるはず。計算結果と合っています。この見方を持っていると、計算ミスにすぐ気づけます。
  8. おつかれさまでした。在庫に入れる1行は、これです。頂点と両端、この3点だけ調べる。頂点が定義域の外にあるときは、両端だけを比べれば終わりです。明日、何も見ずに、同じ式で、3 以上 5 以下 の場合をやってみてください。頂点が外に出る練習になります。 チャンネル登録をして、次の動画でも一緒に、要領よく積み上げていきましょう。
