第9回　定義域つきの最大・最小

y = x² − 4x + 1　( 0 ≦ x ≦ 3 ) の最大値・最小値を求めよ。

候補は「頂点」と「両端」の3点だけ。それ以外に答えはありません（動画・音声解説つき）。

解法の型（3ステップ）

① 平方完成して頂点を出す　② 頂点が定義域の中にあるか見る　③ 両端の値を出す

解答手順

  1. 平方完成
    y = ( x − 2 )² − 3　→　頂点 ( 2 , −3 )、下に凸
  2. 頂点は定義域の中か
    0 ≦ 2 ≦ 3 → 中にある → 最小値は頂点で確定
    最小値 −3 ( x = 2 )
  3. 両端をくらべる
    x = 0 → y = 1 ／ x = 3 → y = 9 − 12 + 1 = −2
    最大値 1 ( x = 0 )

検算：頂点 x = 2 からの距離は |0 − 2| = 2、|3 − 2| = 1。下に凸なら遠い端で最大 → x = 0 で最大、で一致します。

答案の注意：「x = ○ のとき」を必ず添える。値だけでは減点されます。

覚えるべきこと（在庫に入れる1行）

調べるのは「頂点」と「両端」の3点だけ。頂点が定義域の外なら両端だけを比べる。

類題（翌日、何も見ずに）

  1. y = x² − 4x + 1（3 ≦ x ≦ 5）
    答え

    頂点 x = 2 は定義域の外。最小 −2 (x = 3)、最大 6 (x = 5)

  2. y = −x² + 2x + 3（0 ≦ x ≦ 3）
    答え

    y = −(x − 1)² + 4。最大 4 (x = 1)、最小 0 (x = 3)

  3. y = x² + 2x（−3 ≦ x ≦ −2）
    答え

    頂点 x = −1 は外。最小 0 (x = −2)、最大 3 (x = −3)
