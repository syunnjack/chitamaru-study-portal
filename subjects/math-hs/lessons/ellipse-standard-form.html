第39回　楕円は「大きい分母が長軸、差のルートが焦点」

x²/9 + y²/4 = 1 で表される楕円の長軸・短軸の長さと焦点の座標を求めよ。

楕円は分母を見るだけで全部わかります。焦点までの距離の和が 2a になる、という定義もセットで押さえます（動画・音声解説つき）。

解法の型

x²/a² + y²/b² = 1（a > b > 0）→ 長軸 2a、短軸 2b、焦点 (±√(a² − b²), 0)

楕円上の点から2焦点までの距離の和 = 2a

分母の大きいほうが長軸の向き。焦点は「差のルート」です。

解答手順

  1. a と b を読む
    9 = 3²、4 = 2² → a = 3、b = 2
    a > b なので長軸は x 軸方向
  2. 長軸・短軸を出す
    長軸 2a = 6、短軸 2b = 4
    頂点 (±3, 0)、(0, ±2)
  3. 焦点を出す
    c = √(9 − 4) = √5
    答え 焦点 (±√5, 0)

検算：点 (3, 0) から2焦点までの距離の和は (3 − √5) + (3 + √5) = 6 = 2a で定義と一致。√5 < 3 なので焦点は楕円の内側にあります。

差がつく2行

  1. 分母の大きいほうが軸の向き。x²/4 + y²/9 = 1 なら長軸は y 軸方向で焦点は (0, ±√5)。
  2. 双曲線は c² = a² + b²（足し算）。楕円の引き算と混ぜないこと。

覚えるべきこと（在庫に入れる1行）

楕円は c = √(a² − b²)、長軸 2a（差のルートが焦点）

類題（翌日、何も見ずに）

  1. x²/25 + y²/16 = 1 の焦点と長軸
    答え

    c = √(25 − 16) = 3 → 焦点 (±3, 0)、長軸 10

  2. x²/4 + y²/9 = 1 の焦点
    答え

    b > a 型 → 長軸は y 軸方向、c = √(9 − 4) = √5 → 焦点 (0, ±√5)

  3. x²/9 − y²/16 = 1（双曲線）の焦点
    答え

    c = √(9 + 16) = 5 → 焦点 (±5, 0)

解説の全文を読む
  1. こんにちは。知多丸の落ちこぼれ救済チャンネルです。難関大学に合格して、錯覚資産を手に入れて、一流企業に入社しよう。今日の問題は、9分の エックスの二乗 たす 4分の ワイの二乗 は 1 で表される楕円の、長軸と短軸の長さ、そして焦点の座標を求めなさい。楕円は、分母を見るだけで全部わかります。
  2. 型はこれです。エー が ビー より大きいとき、エックス 軸方向が長軸で、長軸の長さは 2エー、短軸は 2ビー。焦点は、エー の二乗 ひく ビー の二乗 のルート、これを シー として、プラスマイナス シー、0 です。焦点までの距離の和は、いつでも 2エー です。
  3. 手順1。分母を見ます。9 は 3 の二乗、4 は 2 の二乗。よって エー は 3、ビー は 2 です。エー のほうが大きいので、長軸は エックス 軸方向です。
  4. 手順2。長さを出します。長軸は 2 かける 3 で 6、短軸は 2 かける 2 で 4。頂点は、プラスマイナス3、0 と、0、プラスマイナス2 です。
  5. 手順3。焦点を出します。9 ひく 4 は 5 なので、シー は ルート5。焦点は、ルート5、0 と、マイナス ルート5、0 です。だいたい 2.24 の位置で、頂点の 3 より内側にあります。
  6. 検算です。楕円上の点 かっこ 3、0 から、2つの焦点までの距離を足します。3 ひく ルート5 と 3 たす ルート5 で、和は 6。これは 2エー と一致します。焦点の位置は、必ずこの和で確認できます。
  7. 差がつく2行。1つめ。分母の大きいほうが ワイ の側なら、長軸は ワイ 軸方向で、焦点も ワイ 軸上です。4分の エックスの二乗 たす 9分の ワイの二乗 は 1 なら、焦点は 0、プラスマイナス ルート5 です。2つめ。双曲線は符号が引き算で、シー の二乗 は エー の二乗 たす ビー の二乗。足すか引くかを、必ず見分けてください。
  8. おつかれさまでした。在庫に入れる1行は、これです。楕円は、分母の大きいほうが長軸、焦点は差のルート。明日、何も見ずに、25分の エックスの二乗 たす 16分の ワイの二乗 は 1 の焦点をやってみてください。答えは、プラスマイナス3、0 です。チャンネル登録をして、次の動画でも一緒に、要領よく積み上げていきましょう。
