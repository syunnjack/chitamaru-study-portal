第32回　分散は「2乗の平均 − 平均の2乗」で出す

さいころを1回投げて出る目を X とするとき、E(X)、V(X)、σ(X) を求めよ。

分散は定義式（偏差の2乗の平均）で計算すると必ず時間が足りません。使う式は1本だけです（動画・音声解説つき）。

解法の型

V(X) = E(X²) − {E(X)}²、σ(X) = √V(X)

E(X) = Σ x p（値 × 確率 を全部たす）

「2乗の平均 − 平均の2乗」。定義式より必ず速いので、こちらだけ覚えます。

解答手順

  1. 期待値を出す
    E(X) = (1+2+3+4+5+6) × 1/6 = 21/6 = 7/2

    1〜6 の真ん中の値なので、感覚とも一致します。

  2. 2乗の平均を出す
    E(X²) = (1+4+9+16+25+36) × 1/6 = 91/6

    「2乗してから平均」の順番を逆にしないこと。

  3. 引き算する
    V(X) = 91/6 − (7/2)² = 182/12 − 147/12 = 35/12
    σ(X) = √(35/12) = √105/6 ≒ 1.71

検算：分散は必ず 0 以上。データが 1〜6 に散らばっているので標準偏差は 1〜2 程度になるのが自然で、1.71 は妥当です。負や 5 超になったら計算ミスです。

差がつく2行

  1. E(aX + b) = aE(X) + b、V(aX + b) = a²V(X)。平行移動 b は散らばりを変えないので分散に効きません。
  2. 標準偏差は X と同じ単位、分散は2乗の単位。どちらを問われているかを必ず確認して答えます。

覚えるべきこと（在庫に入れる1行）

V(X) = E(X²) − {E(X)}²（2乗の平均 − 平均の2乗）

類題（翌日、何も見ずに）

  1. X = 1, 2, 3 を確率 1/2, 1/3, 1/6 でとるとき E(X) と V(X)
    答え

    E = 1/2 + 2/3 + 1/2 = 5/3、E(X²) = 1/2 + 4/3 + 3/2 = 10/3 → V = 10/3 − 25/9 = 5/9

  2. コインを2枚投げて表の出る枚数 X の E(X) と V(X)
    答え

    E = 0×1/4 + 1×1/2 + 2×1/4 = 1、E(X²) = 0 + 1/2 + 1 = 3/2 → V = 3/2 − 1 = 1/2

  3. さいころの目 X について Y = 2X + 3 の V(Y)
    答え

    V(Y) = 2²V(X) = 4 × 35/12 = 35/3

解説の全文を読む
  1. こんにちは。知多丸の落ちこぼれ救済チャンネルです。難関大学に合格して、錯覚資産を手に入れて、一流企業に入社しよう。今日の問題は、さいころを1回投げて出る目を エックス とするとき、エックス の期待値、分散、標準偏差を求めなさい。分散は、定義どおりに計算すると手間がかかります。使うのは1本の式だけです。
  2. 型はこれです。期待値は、値 かける 確率 を全部たす。分散は、二乗の平均 ひく 平均の二乗。標準偏差は、分散のルートです。分散の定義式は、偏差の二乗の平均ですが、計算では必ずこの形を使います。
  3. 手順1。期待値を出します。1 から 6 までの目が、それぞれ 6分の1 の確率。1 たす 2 たす 3 たす 4 たす 5 たす 6 は 21。21 を 6 で割って、2分の7。つまり 3.5 です。
  4. 手順2。二乗の平均を出します。1 たす 4 たす 9 たす 16 たす 25 たす 36 は 91。91 を 6 で割って、6分の91 です。
  5. 手順3。引き算します。6分の91 ひく、2分の7 の二乗、つまり 4分の49。分母を 12 にそろえると、12分の182 ひく 12分の147 で、12分の35。これが分散です。標準偏差は、そのルートで、6分のルート105。だいたい 1.71 です。
  6. 検算です。分散は必ず 0 以上。そして、データが 1 から 6 に散らばっているので、標準偏差が 1 から 2 くらいになるのが自然です。6分のルート105 は約 1.71 で、範囲におさまっています。負になったり、5 を超えたりしたら、どこかで計算をまちがえています。
  7. 差がつく2行。1つめ。エックス を 定数 エー 倍して ビー を足すと、期待値は エー 倍して ビー を足す。分散は エー の二乗倍で、ビー は効きません。散らばりは平行移動では変わらないからです。2つめ。標準偏差は単位が エックス と同じ、分散は単位が二乗になります。答えを書くとき、どちらを聞かれているかを必ず確認してください。
  8. おつかれさまでした。在庫に入れる1行は、これです。分散は、二乗の平均 ひく 平均の二乗。明日、何も見ずに、エックス が 1、2、3 をとり、確率が 2分の1、3分の1、6分の1 のときの期待値と分散をやってみてください。答えは、期待値が 3分の5、分散が 9分の5 です。チャンネル登録をして、次の動画でも一緒に、要領よく積み上げていきましょう。
