第64回　3次方程式は「1つの解を代入で見つける」

3次方程式 x³ − 2x² − 5x + 6 = 0 を解け。

3次方程式に解の公式は使いません。1つ見つけて割る、これだけです（動画・音声解説つき）。

解法の型

定数項の約数を代入 → f(a) = 0 なら (x − a) で割り切れる → 商の2次式を解く

試す候補は定数項 6 の約数 ±1, ±2, ±3, ±6 だけ。あてずっぽうではありません。

解答手順

  1. 候補を絞る
    定数項 6 の約数 ±1、±2、±3、±6 を試す

    最高次の係数が1なら、有理数解は定数項の約数だけです。

  2. 代入して見つける
    f(1) = 1 - 2 - 5 + 6 = 0 → x = 1 が解

    まず x = 1 を試すのが定石（係数の和が 0 かどうか）。

  3. 割り算する
    x³ - 2x² - 5x + 6 = (x - 1)(x² - x - 6)

    組立除法でも筆算でも構いません。

  4. 商を因数分解
    (x - 1)(x - 3)(x + 2) = 0 → x = 1, 3, -2

検算：3次方程式の解の和は −(x² の係数) で 2、積は −(定数項) で −6。1 + 3 − 2 = 2、1×3×(−2) = −6 でどちらも一致します。代入するより速い検算です。

差がつく2行

  1. 最高次の係数が 1 でないときの候補は (定数項の約数) ÷ (最高次の係数の約数)。
  2. 商が因数分解できないときは解の公式。判別式が負なら虚数解になります（「実数の範囲で」の指示を読むこと）。

覚えるべきこと（在庫に入れる1行）

定数項の約数を代入 → 因数定理で割る

類題（翌日、何も見ずに）

  1. x³ − 7x + 6 = 0
    答え

    f(1) = 0 なので (x−1)(x² + x − 6) = (x−1)(x+3)(x−2) → x = 1, 2, −3

  2. x³ + 3x² − 4 = 0
    答え

    f(1) = 0 なので (x−1)(x² + 4x + 4) = (x−1)(x+2)² → x = 1, −2（重解）

  3. x³ − 2x² − 5x + 6 = 0 の3解の2乗の和
    答え

    (和)² − 2(2つの積の和) = 4 − 2×(−5) = 14
