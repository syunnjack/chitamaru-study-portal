第78回　双曲線は「a² + b² が c²」

双曲線 x²/9 − y²/16 = 1 の焦点の座標と漸近線の方程式を求めよ。

楕円と1か所だけ違います。そこだけ押さえれば完璧です（動画・音声解説つき）。

解法の型

x²/a² − y²/b² = 1 → 焦点 (±c, 0)、c² = a² + b²（足す）、漸近線 y = ±(b/a)x

楕円は c² = a² − b²（引く）、双曲線は c² = a² + b²（足す）。ここだけが違いです。

解答手順

  1. a と b を読む
    a² = 9 → a = 3、b² = 16 → b = 4

    分母がそのまま2乗になっています。

  2. c を求める
    c² = 9 + 16 = 25 → c = 5

    双曲線は足す。ここが唯一の分かれ道です。

  3. 焦点を書く
    焦点は (5, 0)、(-5, 0)

    x² が正の項なので焦点は x 軸上です。

  4. 漸近線
    y = (4/3)x、y = -(4/3)x

    右辺を 0 にした式を因数分解しても出せます。

検算：頂点 (±3, 0) より焦点 (±5, 0) が外側にあり、双曲線の配置として正しい。x = 0 では解がなく、y 軸と交わらないことも確認できます。

差がつく2行

  1. 右辺が −1 なら上下に開く双曲線で、焦点は y 軸上になります。符号を最初に確認します。
  2. 漸近線は右辺を 0 にして因数分解すれば作れます。公式を忘れても復元できます。

覚えるべきこと（在庫に入れる1行）

双曲線は c² = a² + b²（楕円は引く、双曲線は足す）

類題（翌日、何も見ずに）

  1. x²/16 − y²/9 = 1 の焦点と漸近線
    答え

    c² = 25 で焦点 (±5, 0)、漸近線 y = ±(3/4)x

  2. x²/9 − y²/16 = −1 の焦点
    答え

    上下に開き c² = 25 で焦点 (0, ±5)

  3. 楕円 x²/25 + y²/9 = 1 の焦点
    答え

    c² = 25 − 9 = 16 で焦点 (±4, 0)（引く）
