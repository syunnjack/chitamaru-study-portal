第68回　数学的帰納法は「書き方の型」で覚える

すべての自然数 n について、n³ + 2n が 3 の倍数であることを数学的帰納法で証明せよ。

証明問題は、書き方の型を覚えてしまえば怖くありません（動画・音声解説つき）。

解法の型

(1) n = 1 で成立を確認　(2) n = k を仮定し、その式を使って n = k + 1 を示す

仮定を使わずに示せてしまったら、それは帰納法になっていません。「仮定を使う場所」を意識します。

解答手順

  1. n = 1 を確認
    1³ + 2×1 = 3 → 3の倍数 ○
  2. 仮定を書く
    n = k のとき k³ + 2k = 3m（m は整数）とおける

    「3の倍数」を 3m と文字で置くのがコツです。

  3. n = k + 1 を計算
    (k+1)³ + 2(k+1) = k³ + 3k² + 3k + 1 + 2k + 2 = (k³ + 2k) + 3k² + 3k + 3

    仮定の k³ + 2k がそのまま現れるように並べ替えます。

  4. 仮定を使って結論
    = 3m + 3(k² + k + 1) = 3(m + k² + k + 1) → 3の倍数

    3 でくくれた形にして「よって3の倍数」と結ぶのが答案の形です。

検算：n = 2 で 12、n = 3 で 33、n = 4 で 72。すべて3の倍数で、主張と一致します。証明問題でも具体値で確認する習慣をつけてください。

差がつく2行

  1. この問題は n(n² + 2) の形から直接も示せますが、「帰納法で」と指示されたら帰納法で書きます。
  2. 等式の証明では片方から出発してもう片方に到達します。両辺を同時に変形すると循環論法になります。

覚えるべきこと（在庫に入れる1行）

n = 1 を示す → n = k を仮定して使う → n = k + 1

類題（翌日、何も見ずに）

  1. n³ − n が 3 の倍数であることを帰納法で示す
    答え

    n = 1 で 0（3の倍数）。k³ − k = 3m と仮定し、(k+1)³ − (k+1) = (k³ − k) + 3k² + 3k = 3(m + k² + k)

  2. 1 + 2 + … + n = n(n+1)/2 を帰納法で示す
    答え

    n = 1 で両辺1。k までを仮定し、k(k+1)/2 + (k+1) = (k+1)(k+2)/2

  3. 2ⁿ > n（n ≧ 1）を帰納法で示す
    答え

    n = 1 で 2 > 1。2^k > k を仮定し 2^(k+1) = 2·2^k > 2k ≧ k + 1
