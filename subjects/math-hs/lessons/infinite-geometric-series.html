第36回　無限等比級数は「初項 ÷ (1 − 公比)」だけ

1 + 1/3 + 1/9 + 1/27 + … の和を求めよ。

無限に足しても答えが有限になる理由と、使う式1本を押さえます。収束条件の確認を飛ばすと減点されます（動画・音声解説つき）。

解法の型

|r| < 1 のとき S = a/(1 − r)、|r| ≧ 1 のときは発散

部分和 Sₙ = a(1 − rⁿ)/(1 − r) の n → ∞ が根拠

まず公比の絶対値を見る。収束するかどうかを書いてから和を出します。

解答手順

  1. 初項と公比を読む
    a = 1、r = 1/3
    |r| = 1/3 < 1 → 収束
  2. 式に入れる
    S = 1/(1 − 1/3) = 1/(2/3)
    答え S = 3/2

検算：部分和は Sₙ = (3/2){1 − (1/3)ⁿ} で 3/2 に近づきます。実際 1 + 0.333 + 0.111 + 0.037 = 1.481 で 1.5 に接近。

差がつく2行

  1. 循環小数はこの公式そのもの。0.777… は a = 7/10、r = 1/10 → 7/9。
  2. 公比が負でも |r| < 1 なら収束。2 − 1 + 1/2 − … は r = −1/2 で S = 2/(1 + 1/2) = 4/3。

覚えるべきこと（在庫に入れる1行）

|r| < 1 のとき S = a/(1 − r)（初項 ÷ 1 − 公比）

類題（翌日、何も見ずに）

  1. Σ（n = 1 から ∞）(2/3)ⁿ
    答え

    a = 2/3、r = 2/3 → S = (2/3)/(1/3) = 2

  2. 0.4545… を分数にする
    答え

    a = 45/100、r = 1/100 → S = (45/100)/(99/100) = 5/11

  3. 1 + 2 + 4 + 8 + … は収束するか
    答え

    r = 2 で |r| ≧ 1 → 発散（和は存在しない）

解説の全文を読む
  1. こんにちは。知多丸の落ちこぼれ救済チャンネルです。難関大学に合格して、錯覚資産を手に入れて、一流企業に入社しよう。今日の問題は、1 たす 3分の1 たす 9分の1 たす 27分の1 たす、と無限に続く和を求めなさい。無限に足すのに、答えが有限になる。その理由と、使う式を1つだけ覚えます。
  2. 型はこれです。公比の絶対値が 1 より小さいとき、和は、初項 わる かっこ 1 ひく 公比。絶対値が 1 以上なら、いくらでも大きくなるので発散します。まず、収束するかどうかを必ず先に確認します。
  3. 手順1。初項と公比を読み取ります。初項は 1。公比は、次の項を前の項で割って、3分の1。絶対値は 3分の1 で、1 より小さいので収束します。
  4. 手順2。式に入れます。1 わる かっこ 1 ひく 3分の1。分母は 3分の2 なので、1 わる 3分の2 は 2分の3。答えは 2分の3 です。
  5. 検算です。部分和を作ってみます。第 エヌ 項までの和は、2分の3 かける かっこ 1 ひく 3分の1 の エヌ乗。エヌ を大きくすると、3分の1 の エヌ乗 は 0 に近づくので、2分の3 に近づきます。実際、1 たす 0.333 たす 0.111 たす 0.037 は 1.481 で、1.5 に近づいています。
  6. 差がつく2行。1つめ。循環小数は無限等比級数です。0.7777 と続く数は、初項 10分の7、公比 10分の1 なので、9分の7。分数に直す作業が、そのままこの公式です。2つめ。公比が負でも、絶対値が 1 より小さければ収束します。2 ひく 1 たす 2分の1 ひく、は、公比 マイナス2分の1 で、和は 3分の4 です。
  7. おつかれさまでした。在庫に入れる1行は、これです。無限等比級数は、絶対値が 1 より小さいとき、初項 わる 1ひく公比。明日、何も見ずに、エヌ が 1 から無限までの、3分の2 の エヌ乗 の和をやってみてください。答えは 2 です。チャンネル登録をして、次の動画でも一緒に、要領よく積み上げていきましょう。
