第71回　部分積分は「微分して簡単になる方を f に」

定積分 ∫（0 から 1）x e^x dx を求めよ。

かけ算の形の積分は、部分積分の合図です。選び方に法則があります（動画・音声解説つき）。

解法の型

∫f g′ dx = f g − ∫f′ g dx　（微分して簡単になる方を f にする）

x は微分すると 1、ex は何回微分しても変わらない。だから x を f、ex を g′ にします。

解答手順

  1. 役割を決める
    f = x（微分すると 1）、g' = e^x（積分すると e^x）

    選び方を間違えると計算が複雑になるだけで、間違いにはなりません。落ち着いて選び直します。

  2. 公式に入れる
    = [x e^x] (0→1) - ∫(0→1) 1 × e^x dx
  3. 前半を計算
    [x e^x] = 1×e¹ - 0×e⁰ = e
  4. 後半を引く
    ∫(0→1) e^x dx = e - 1 → 答え e - (e - 1) = 1

検算：原始関数は (x − 1)ex。微分すると ex + (x − 1)ex = x ex で戻ります。0→1 で 0 − (−1) = 1 と一致します。微分して戻すのが積分の検算です。

差がつく2行

  1. log が入ったら log を f に（微分すると 1/x になる）。∫log x dx = x log x − x は覚えてよい形です。
  2. sin × ex 型は2回で元に戻ります。元の積分を I と置いて方程式にするのが循環型の定番です。

覚えるべきこと（在庫に入れる1行）

部分積分は、微分して簡単になる方を f に

類題（翌日、何も見ずに）

  1. ∫(0 から π) x sin x dx
    答え

    f = x、g′ = sin x。[−x cos x] + ∫cos x dx = π + 0 = π

  2. ∫(1 から e) log x dx
    答え

    x log x − x を使って (e − e) − (0 − 1) = 1

  3. ∫(0 から 1) x e^(2x) dx
    答え

    f = x、g′ = e^(2x)。[x e^(2x)/2] − ∫e^(2x)/2 dx = e²/2 − (e² − 1)/4 = (e² + 1)/4
