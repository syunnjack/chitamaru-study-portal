第28回　極限の不定形は「割るか、有理化するか」の2択

lim (n → ∞) ( √(n² + 3n) − n ) を求めよ。

∞ − ∞ はそのままでは答えが出ません。やることは1つだけです（動画・音声解説つき）。

解法の型

∞ / ∞ → 最高次で割る　／　ルートの ∞ − ∞ → 有理化する

不定形は「そのまま代入できない形」。まず変形してから代入します。

解答手順

  1. 有理化する
    分子・分母に √(n² + 3n) + n をかける
    = 3n / ( √(n² + 3n) + n )

    2乗の差でルートが消えます。

  2. n で割る
    = 3 / ( √(1 + 3/n) + 1 )
    3/n → 0 なので 分母 → 2 → 答え 3/2

検算：n = 1000 のとき √1003000 ≒ 1001.5 で、1001.5 − 1000 = 1.5 = 3/2。極限は大きい数を代入して確かめます。

差がつく2行

  1. ∞/∞ は最高次で割るだけ：(3n² − n)/(n² + 2) → 3。
  2. ルート内の最高次が同じときだけ有理化で有限値になります。次数がちがえば極限は ∞ か 0 です。

覚えるべきこと（在庫に入れる1行）

∞/∞ は最高次で割る、ルートの ∞−∞ は有理化

類題（翌日、何も見ずに）

  1. lim (n → ∞) ( √(n² + 4n) − n )
    答え

    有理化して 4n / (√(n²+4n) + n) → 4/2 = 2

  2. lim (n → ∞) (2n² + 3n) / (n² − 1)
    答え

    n² で割って 2

  3. lim (n → ∞) ( √(n + 1) − √n )
    答え

    有理化して 1 / (√(n+1) + √n) → 0

解説の全文を読む
  1. こんにちは。知多丸の落ちこぼれ救済チャンネルです。難関大学に合格して、錯覚資産を手に入れて、一流企業に入社しよう。今日の問題は、エヌ を限りなく大きくしたときの、ルート かっこ エヌ2乗 たす 3エヌ ひく エヌ の極限を求めなさい。無限 ひく 無限 の形は、そのままでは答えが出ません。やることは1つだけです。
  2. 型はこれです。不定形は2択です。無限 わる 無限 なら、最高次で割る。無限 ひく 無限 で ルート があるなら、有理化する。今回は ルート のある引き算なので、有理化です。
  3. 手順1。有理化します。分母を1と思って、ルート たす エヌ をかけて割ります。分子は、ルートの2乗 ひく エヌの2乗 なので、エヌ2乗 たす 3エヌ ひく エヌ2乗 で 3エヌ。分母は ルート かっこ エヌ2乗 たす 3エヌ たす エヌ になります。
  4. 手順2。分母と分子を エヌ で割ります。分子は 3。分母は、ルート かっこ 1 たす エヌ分の3 たす 1。エヌ を大きくすると エヌ分の3 は 0 に近づくので、分母は ルート1 たす 1 で 2。よって極限は 2分の3 です。
  5. 検算です。エヌ に 大きい数を入れて確かめます。エヌ が 1000 のとき、ルート かっこ 1000000 たす 3000 は およそ 1001.5。ここから 1000 を引くと およそ 1.5。2分の3 と一致します。極限は必ず大きい数を代入して確かめてください。
  6. 差がつく2行。1つめ。無限 わる 無限 は、最高次で割るだけです。3エヌ2乗 ひく エヌ わる エヌ2乗 たす 2 なら、分母分子を エヌ2乗 で割って 3。2つめ。ルート の中の最高次が同じときだけ、有理化で答えが有限になります。中の次数がちがえば、極限は 無限 か 0 です。
  7. おつかれさまでした。在庫に入れる1行は、これです。無限 わる 無限 は最高次で割る、ルートの 無限 ひく 無限 は有理化する。明日、何も見ずに、ルート かっこ エヌ2乗 たす 4エヌ ひく エヌ の極限をやってみてください。答えは 2 です。チャンネル登録をして、次の動画でも一緒に、要領よく積み上げていきましょう。
