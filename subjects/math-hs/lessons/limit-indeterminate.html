第28回　極限の不定形は「割るか、有理化するか」の2択

lim (n → ∞) ( √(n² + 3n) − n ) を求めよ。

∞ − ∞ はそのままでは答えが出ません。やることは1つだけです（動画・音声解説つき）。

解法の型

∞ / ∞ → 最高次で割る　／　ルートの ∞ − ∞ → 有理化する

不定形は「そのまま代入できない形」。まず変形してから代入します。

解答手順

  1. 有理化する
    分子・分母に √(n² + 3n) + n をかける
    = 3n / ( √(n² + 3n) + n )

    2乗の差でルートが消えます。

  2. n で割る
    = 3 / ( √(1 + 3/n) + 1 )
    3/n → 0 なので 分母 → 2 → 答え 3/2

検算：n = 1000 のとき √1003000 ≒ 1001.5 で、1001.5 − 1000 = 1.5 = 3/2。極限は大きい数を代入して確かめます。

差がつく2行

  1. ∞/∞ は最高次で割るだけ：(3n² − n)/(n² + 2) → 3。
  2. ルート内の最高次が同じときだけ有理化で有限値になります。次数がちがえば極限は ∞ か 0 です。

覚えるべきこと（在庫に入れる1行）

∞/∞ は最高次で割る、ルートの ∞−∞ は有理化

類題（翌日、何も見ずに）

  1. lim (n → ∞) ( √(n² + 4n) − n )
    答え

    有理化して 4n / (√(n²+4n) + n) → 4/2 = 2

  2. lim (n → ∞) (2n² + 3n) / (n² − 1)
    答え

    n² で割って 2

  3. lim (n → ∞) ( √(n + 1) − √n )
    答え

    有理化して 1 / (√(n+1) + √n) → 0
