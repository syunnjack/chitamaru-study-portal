第73回　∞ − ∞ は「有理化してから割る」

極限 lim（x → ∞）(√(x² + 3x) − x) を求めよ。

そのまま代入すると ∞ − ∞ で値が分かりません。形を変えてから代入します（動画・音声解説つき）。

解法の型

√ を含む ∞ − ∞ → 分子を有理化 → 分母分子を最高次の x で割る

不定形は必ず「形を変えてから」代入します。そのままの形で代入してはいけません。

解答手順

  1. 有理化する
    (√(x²+3x) - x) × (√(x²+3x) + x) ÷ (√(x²+3x) + x)

    分母を 1 と見て、同じものを分母分子に掛けます。

  2. 分子を計算
    分子 = (x² + 3x) - x² = 3x

    差の積で √ が消えます。

  3. x で割る
    3x / (√(x²+3x) + x) = 3 / (√(1 + 3/x) + 1)

    √ の中から x を出すときは √(x²) = x（x > 0）を使います。

  4. 極限を取る
    x → ∞ で 3/x → 0 → 3 / (1 + 1) = 3/2

検算：x = 100 で √10300 − 100 ≒ 1.489。答え 1.5 に近づいています。√(x²+3x) ≒ x + 1.5（(x+1.5)² = x²+3x+2.25）と見当をつけることもできます。

差がつく2行

  1. x → −∞ では √(x²) = |x| = −x。符号を1つ間違えると答えが変わります。
  2. ∞/∞ は最高次で割るだけ。まず「どの不定形か」を判定してから手順を選びます。

覚えるべきこと（在庫に入れる1行）

√ の ∞ - ∞ は有理化 → x で割る

類題（翌日、何も見ずに）

  1. lim (x→∞) (√(x² + 4x) − x)
    答え

    有理化して 4x ÷ (√(x²+4x) + x) → 4/2 = 2

  2. lim (x→∞) (2x² − 3x) / (x² + 1)
    答え

    x² で割って 2

  3. lim (x→∞) (√(x² + 1) − √(x² − 1))
    答え

    有理化して 2 ÷ (√(x²+1) + √(x²−1)) → 0

  3. 手順1。分子の有理化です。ルート たす エックス を分母分子にかけます。
  4. 手順2。分子は、エックスの2乗 たす 3エックス ひく エックスの2乗 で 3エックス。ルート が消えました。

  8. 差がつく2行。1つめ。エックス が マイナス の無限大 に近づくときは要注意です。ルート エックスの2乗 は エックス ではなく、エックス の絶対値、つまり マイナス エックス になります。符号を1つ間違えると答えが変わるので、必ず確認してください。2つめ。分数の 無限大 わる 無限大 の形は、有理化ではなく、最高次で割るだけで済みます。不定形の種類ごとに手順が決まっているので、まず どの不定形かを判定する、これが要領です。
