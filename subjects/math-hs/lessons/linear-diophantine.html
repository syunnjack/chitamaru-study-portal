第19回　整数解は「1組見つけて、差を引く」

3x + 5y = 1 を満たす整数 x, y をすべて求めよ。

文字2つ・式1つなので答えは無限。それを1行で書き表す型を覚えます（動画・音声解説つき）。

解法の型

① 解を1組見つける　② もとの式から引く　③ 互いに素で割って整数 k を置く

係数が小さければ代入で探し、見つからなければユークリッドの互除法を使います。

解答手順

  1. 1組を見つける
    x = 2, y = −1 → 3(2) + 5(−1) = 1 ○
  2. 引き算する
    3(x − 2) + 5(y + 1) = 0

    右辺を 0 にするのが、この引き算のねらいです。

  3. 互いに素を使う
    3(x − 2) = −5(y + 1)、3 と 5 は互いに素 → x − 2 = 5k
  4. 答えの形にする
    x = 5k + 2、y = −3k − 1　（k は整数）

検算：3(5k + 2) + 5(−3k − 1) = 15k + 6 − 15k − 5 = 1。k が消えて右辺になれば正解の形です。k = 0, 1, −1 で (2, −1), (7, −4), (−3, 2)。

差がつく2行

  1. 1組が見つからないときはユークリッドの互除法を逆にたどる（例：7x + 11y = 1 → 11 = 7 + 4, 7 = 4 + 3, 4 = 3 + 1 から復元）。
  2. 右辺が 1 でないときは、まず右辺 1 の解を作って何倍かする（3x + 5y = 7 なら (2, −1) を7倍して (14, −7)）。

覚えるべきこと（在庫に入れる1行）

1組見つける → 引く → 互いに素で割って k を置く

類題（翌日、何も見ずに）

  1. 5x + 3y = 1 の整数解
    答え

    (2, −3) が1組 → x = 3k + 2、y = −5k − 3

  2. 3x + 5y = 7 の整数解
    答え

    (14, −7) が1組 → x = 5k + 14、y = −3k − 7（k を取り直せば x = 5k + 4, y = −3k − 1 とも書ける）

  3. 4x + 6y = 1 の整数解
    答え

    左辺は必ず偶数なので、整数解は存在しない（右辺が gcd(4, 6) = 2 の倍数でない）
