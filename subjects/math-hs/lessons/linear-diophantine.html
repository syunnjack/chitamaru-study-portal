第19回　整数解は「1組見つけて、差を引く」

3x + 5y = 1 を満たす整数 x, y をすべて求めよ。

文字2つ・式1つなので答えは無限。それを1行で書き表す型を覚えます（動画・音声解説つき）。

解法の型

① 解を1組見つける　② もとの式から引く　③ 互いに素で割って整数 k を置く

係数が小さければ代入で探し、見つからなければユークリッドの互除法を使います。

解答手順

  1. 1組を見つける
    x = 2, y = −1 → 3(2) + 5(−1) = 1 ○
  2. 引き算する
    3(x − 2) + 5(y + 1) = 0

    右辺を 0 にするのが、この引き算のねらいです。

  3. 互いに素を使う
    3(x − 2) = −5(y + 1)、3 と 5 は互いに素 → x − 2 = 5k
  4. 答えの形にする
    x = 5k + 2、y = −3k − 1　（k は整数）

検算：3(5k + 2) + 5(−3k − 1) = 15k + 6 − 15k − 5 = 1。k が消えて右辺になれば正解の形です。k = 0, 1, −1 で (2, −1), (7, −4), (−3, 2)。

差がつく2行

  1. 1組が見つからないときはユークリッドの互除法を逆にたどる（例：7x + 11y = 1 → 11 = 7 + 4, 7 = 4 + 3, 4 = 3 + 1 から復元）。
  2. 右辺が 1 でないときは、まず右辺 1 の解を作って何倍かする（3x + 5y = 7 なら (2, −1) を7倍して (14, −7)）。

覚えるべきこと（在庫に入れる1行）

1組見つける → 引く → 互いに素で割って k を置く

類題（翌日、何も見ずに）

  1. 5x + 3y = 1 の整数解
    答え

    (2, −3) が1組 → x = 3k + 2、y = −5k − 3

  2. 3x + 5y = 7 の整数解
    答え

    (14, −7) が1組 → x = 5k + 14、y = −3k − 7（k を取り直せば x = 5k + 4, y = −3k − 1 とも書ける）

  3. 4x + 6y = 1 の整数解
    答え

    左辺は必ず偶数なので、整数解は存在しない（右辺が gcd(4, 6) = 2 の倍数でない）

解説の全文を読む
  1. こんにちは。知多丸の落ちこぼれ救済チャンネルです。難関大学に合格して、錯覚資産を手に入れて、一流企業に入社しよう。今日の問題は、こちら。3エックス たす 5ワイ は 1。これを満たす整数エックス、整数ワイ をすべて求めよ。文字が2つで式が1つなので、答えは1組ではなく、無限にあります。それを1行で書き表す型を覚えます。
  2. 型はこれです。手順は3つ。1、整数解を1組、目で見つける。2、もとの式から、その式を引く。3、互いに素な数で割って、整数の文字を1つ置く。この順番を固定してください。
  3. 手順1。1組を目で見つけます。エックスに 2 を入れると 6。5ワイ が マイナス5 になればよいので、ワイ は マイナス1。エックス は 2、ワイ は マイナス1 が1組です。係数が小さいときは、この探し方でじゅうぶんです。見つからないときは、ユークリッドの互除法を使います。
  4. 手順2。もとの式から、見つけた式を引きます。3エックス たす 5ワイ は 1、から、3かける2 たす 5かけるマイナス1 は 1、を引く。右辺は 1 ひく 1 で 0。左辺は、3かける エックスひく2 たす 5かける ワイたす1 は 0 になります。
  5. 手順3。移項します。3かける エックスひく2 は、マイナス5かける ワイたす1。左は3の倍数、右は5の倍数です。3と5は互いに素なので、エックスひく2 は 5の倍数でなければなりません。そこで、エックスひく2 を 5ケー とおきます。ケー は整数です。
  6. 代入して仕上げます。エックス は 2 たす 5ケー。これを式に戻すと、3かける5ケー は マイナス5かける ワイたす1 なので、ワイたす1 は マイナス3ケー、つまり ワイ は マイナス1 ひく 3ケー。これが答えです。エックス は 5ケー たす 2、ワイ は マイナス3ケー ひく 1、ケー は整数。
  7. 検算です。式に代入します。3かける 5ケーたす2 たす 5かける マイナス3ケーひく1 は、15ケー たす 6 ひく 15ケー ひく 5 で、1。ケー が消えて 1 になりました。正しい形です。ケー に 0、1、マイナス1 を入れると、2とマイナス1、7とマイナス4、マイナス3と2。どれも成り立ちます。
  8. おつかれさまでした。在庫に入れる1行は、これです。整数解は、1組見つけて引き算、互いに素で割ってケーを置く。明日、何も見ずに、5エックス たす 3ワイ は 1 をやってみてください。答えは、エックス は 3ケー たす 2、ワイ は マイナス5ケー ひく 3 です。チャンネル登録をして、次の動画でも一緒に、要領よく積み上げていきましょう。
