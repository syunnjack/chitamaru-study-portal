第63回　対数方程式は「真数条件を先に書く」

方程式 log₂(x − 1) + log₂(x + 2) = 2 を解け。

計算して出た2つの解のうち、1つは答えになりません。順番が命です（動画・音声解説つき）。

解法の型

① 真数条件を先に書く　② 和は積にまとめる　③ log₂A = 2 ⇔ A = 4

真数条件を後から確認すると、書き忘れて減点されます。解く前に書くのが要領です。

解答手順

  1. 真数条件を書く
    x - 1 > 0 かつ x + 2 > 0 → x > 1

    厳しい方が残ります。ここを先に書くのが減点されないコツ。

  2. 和を積にまとめる
    log₂{(x - 1)(x + 2)} = 2
  3. 対数をはずす
    (x - 1)(x + 2) = 2² = 4 → x² + x - 6 = 0
  4. 解いて真数条件で選ぶ
    (x + 3)(x - 2) = 0 → x = -3, 2　／　x > 1 より x = 2

    x = −3 は真数が負になるので不適。ここで捨てるのが答案の形です。

検算：x = 2 を代入すると log₂1 + log₂4 = 0 + 2 = 2 で成立。x = −3 は真数が負で定義できないので不適です。元の式に戻すのが唯一確実な検算です。

差がつく2行

  1. 対数不等式では、底が 1 より小さいと不等号の向きが逆になります（底が 1 より大きければそのまま）。
  2. 底が違うときは底の変換公式 logab = logcb ÷ logca でそろえます。

覚えるべきこと（在庫に入れる1行）

対数方程式は真数条件を先に書く

類題（翌日、何も見ずに）

  1. log₃(x + 1) + log₃(x − 1) = 1
    答え

    真数条件 x > 1。(x+1)(x−1) = 3 → x² = 4 → x = 2

  2. log₂(x − 1) + log₂(x + 2) < 2
    答え

    真数条件 x > 1 と x² + x − 6 < 0（−3 < x < 2）から 1 < x < 2

  3. log₂x = 3 のときの x
    答え

    x = 2³ = 8
