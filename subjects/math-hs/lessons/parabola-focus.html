第79回　放物線の焦点は「4分の1」で出る

放物線 y² = 8x の焦点の座標と準線の方程式を求めよ。

係数を4で割るだけです。定義で確認すれば絶対に間違えません（動画・音声解説つき）。

解法の型

y² = 4px　→　焦点 (p, 0)、準線 x = −p

焦点と準線は原点をはさんで対称。放物線上の点は「焦点までの距離 = 準線までの距離」を満たします。

解答手順

  1. 形をそろえる
    y² = 8x = 4px → 4p = 8
  2. p を出す
    p = 2

    係数を4で割る、これだけです。

  3. 焦点と準線
    焦点 (2, 0)、準線 x = -2
  4. 定義で確認
    点 (2, 4) は 焦点まで 4、準線まで 4 → 一致

    放物線の定義そのままの確認です。

検算：点 (2, 4) は焦点まで 4、準線まで 4。点 (8, 8) はどちらも 10。焦点までの距離 = 準線までの距離という定義そのままの確認です。

差がつく2行

  1. x² = 4py なら上下に開きます（2乗されていない文字の側に開く）。焦点 (0, p)、準線 y = −p。
  2. y = x² も放物線で、4p = 1 より焦点は (0, 1/4)。身近な式でも計算できます。

覚えるべきこと（在庫に入れる1行）

y² = 4px なら焦点 (p, 0)、準線 x = -p

類題（翌日、何も見ずに）

  1. y² = 12x の焦点と準線
    答え

    4p = 12 で p = 3。焦点 (3, 0)、準線 x = −3

  2. x² = 8y の焦点と準線
    答え

    4p = 8 で p = 2。焦点 (0, 2)、準線 y = −2

  3. y = x² の焦点
    答え

    x² = y で 4p = 1、p = 1/4。焦点 (0, 1/4)
