第62回　点と直線の距離は「代入して割る」

点 (1, 2) と直線 4x + 3y − 6 = 0 の距離を求めよ。また、原点とこの直線の距離も求めよ。

垂線を引いて交点を出す必要はありません。代入して割るだけです（動画・音声解説つき）。

解法の型

d = |ax₀ + by₀ + c| ÷ √(a² + b²)　（直線は = 0 の形にそろえる）

分子は「点を代入した値の絶対値」、分母は「係数の2乗和のルート」。垂線の交点を求める必要はありません。

解答手順

  1. 分子を計算
    |4×1 + 3×2 - 6| = |4 + 6 - 6| = 4

    絶対値を忘れると負の距離が出てしまいます。

  2. 分母を計算
    √(4² + 3²) = √25 = 5

    4 と 3 なら 5。三平方の数はここでも出ます。

  3. 距離を出す
    d = 4 / 5
  4. 原点の場合
    |0 + 0 - 6| ÷ 5 = 6/5

    原点なら分子は |c| だけになります。

検算：原点から x 切片 (1.5, 0)、y 切片 (0, 2) までが 1.5 と 2 なので、最短距離が 1.2 = 6/5 になるのは自然です。代入値の符号で点が直線のどちら側かも分かります。

差がつく2行

  1. 平行2直線の距離は、片方の上の点を1つ取ってこの公式を使うだけ。
  2. 円と直線は「中心との距離と半径の比較」。接する条件は判別式より距離のほうが速いです。

覚えるべきこと（在庫に入れる1行）

d = |ax₀ + by₀ + c| ÷ √(a² + b²)

類題（翌日、何も見ずに）

  1. 点 (2, −1) と直線 3x − 4y + 5 = 0 の距離
    答え

    |6 + 4 + 5| ÷ 5 = 15/5 = 3

  2. 2直線 4x + 3y − 6 = 0 と 4x + 3y + 4 = 0 の距離
    答え

    点 (0, 2) を取って |0 + 6 + 4| ÷ 5 = 2

  3. 円 x² + y² = 1 と直線 4x + 3y − 6 = 0 の位置関係
    答え

    中心 (0,0) との距離 6/5 > 1 なので交わらない

解説の全文を読む
  1. こんにちは。知多丸の落ちこぼれ救済チャンネルです。難関大学に合格して、錯覚資産を手に入れて、一流企業に入社しよう。今日の問題です。点 1、2 と 直線 4エックス たす 3わい ひく 6 イコール ゼロ の距離を求めなさい。また、原点とこの直線の距離も求めなさい。垂線を引いて交点を出す必要はありません。
  2. 型はこれです。距離 イコール、エー エックス ゼロ たす ビー ワイ ゼロ たす シー の絶対値、わる ルート、エーの2乗 たす ビーの2乗。使う前に、直線を イコール ゼロ の形にそろえること。ここを飛ばすと符号でミスします。
  3. 手順1。分子です。点 1、2 を代入して、4 たす 6 ひく 6 で 4。絶対値をつけるのを忘れないでください。
  4. 手順2。分母は、4の2乗 たす 3の2乗 の ルート で、ルート25 の 5 です。
  5. 手順3。距離は 5分の4 です。
  6. 手順4。原点なら、代入して マイナス6 の絶対値で 6、割って 5分の6。原点のときは 定数項の絶対値 わる 分母、と覚えると速いです。
  7. 検算です。この直線の エックス 切片は、わい イコール ゼロ で 4エックス イコール 6、エックス は 1.5。わい 切片は 2 です。原点から この2点までの距離は 1.5 と 2 なので、直線までの最短距離は それより短い 1.2、つまり 5分の6 になるはず。合っています。もう1つ。点 1、2 を代入した値が プラス4 だったので、点は 直線の 4エックス たす 3わい が大きい側、つまり原点と反対側にあります。図を描いても矛盾しません。
  8. 差がつく2行。1つめ。この公式は、平行な2直線の距離にも使えます。片方の直線上の点を1つ取って、もう片方との距離を測るだけです。2つめ。円と直線の位置関係は、中心と直線の距離と半径の比較で決まります。距離が半径より小さければ2点で交わる、等しければ接する、大きければ交わらない。接する条件を聞かれたら、判別式ではなく この距離を使うほうが速いです。
  9. おつかれさまでした。在庫に入れる1行は、これです。距離は、代入した値の絶対値 わる、係数の2乗和のルート。明日、何も見ずに、点 2、マイナス1 と 直線 3エックス ひく 4わい たす 5 イコール ゼロ の距離を求めてみてください。答えは 5分の15、つまり 3 です。チャンネル登録をして、次の動画でも一緒に、要領よく積み上げていきましょう。
