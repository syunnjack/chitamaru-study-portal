第62回　点と直線の距離は「代入して割る」

点 (1, 2) と直線 4x + 3y − 6 = 0 の距離を求めよ。また、原点とこの直線の距離も求めよ。

垂線を引いて交点を出す必要はありません。代入して割るだけです（動画・音声解説つき）。

解法の型

d = |ax₀ + by₀ + c| ÷ √(a² + b²)　（直線は = 0 の形にそろえる）

分子は「点を代入した値の絶対値」、分母は「係数の2乗和のルート」。垂線の交点を求める必要はありません。

解答手順

  1. 分子を計算
    |4×1 + 3×2 - 6| = |4 + 6 - 6| = 4

    絶対値を忘れると負の距離が出てしまいます。

  2. 分母を計算
    √(4² + 3²) = √25 = 5

    4 と 3 なら 5。三平方の数はここでも出ます。

  3. 距離を出す
    d = 4 / 5
  4. 原点の場合
    |0 + 0 - 6| ÷ 5 = 6/5

    原点なら分子は |c| だけになります。

検算：原点から x 切片 (1.5, 0)、y 切片 (0, 2) までが 1.5 と 2 なので、最短距離が 1.2 = 6/5 になるのは自然です。代入値の符号で点が直線のどちら側かも分かります。

差がつく2行

  1. 平行2直線の距離は、片方の上の点を1つ取ってこの公式を使うだけ。
  2. 円と直線は「中心との距離と半径の比較」。接する条件は判別式より距離のほうが速いです。

覚えるべきこと（在庫に入れる1行）

d = |ax₀ + by₀ + c| ÷ √(a² + b²)

類題（翌日、何も見ずに）

  1. 点 (2, −1) と直線 3x − 4y + 5 = 0 の距離
    答え

    |6 + 4 + 5| ÷ 5 = 15/5 = 3

  2. 2直線 4x + 3y − 6 = 0 と 4x + 3y + 4 = 0 の距離
    答え

    点 (0, 2) を取って |0 + 6 + 4| ÷ 5 = 2

  3. 円 x² + y² = 1 と直線 4x + 3y − 6 = 0 の位置関係
    答え

    中心 (0,0) との距離 6/5 > 1 なので交わらない
