第37回　内分点は「比をたすきにかけて足す」、重心は3つの平均

A(1, 1)、B(7, 4)、C(4, 7) のとき、辺 BC を 2 : 1 に内分する点 D と、△ABC の重心 G の座標を求めよ。

座標でも位置ベクトルでも、使う式はまったく同じです。比の数字が向かい側にかかる、ここだけ覚えます（動画・音声解説つき）。

解法の型

m : n の内分点 = (nA + mB)/(m + n)、重心 G = (A + B + C)/3

位置ベクトルなら g = (a + b + c)/3

比の数字がたすきにかかります。2 : 1 なら遠い側に 2 の重みです。

解答手順

  1. 内分点 D を出す
    D = (1·B + 2·C)/3
    x：(7 + 8)/3 = 5、y：(4 + 14)/3 = 6 → D(5, 6)
  2. 重心 G を出す
    G = ((1 + 7 + 4)/3, (1 + 4 + 7)/3) = G(4, 4)

    重心は足して3で割るだけです。

検算：重心は中線を 2 : 1 に内分する点でもあります。BC の中点 M(11/2, 11/2) として A + (2/3)(M − A) = (4, 4) で一致。2通りで出せます。

差がつく2行

  1. 外分は n を負にするだけ。BC を 2 : 1 に外分する点は (−B + 2C)/1 = (1, 10)。
  2. 図形の証明では位置ベクトルのまま g = (a + b + c)/3 を使うと計算が短くなります。

覚えるべきこと（在庫に入れる1行）

内分 = (nA + mB)/(m + n)、重心 = (A + B + C)/3

類題（翌日、何も見ずに）

  1. A(0, 0)、B(6, 0)、C(3, 6) の重心
    答え

    ((0 + 6 + 3)/3, (0 + 0 + 6)/3) = (3, 2)

  2. B(6, 0)、C(3, 6) について BC を 1 : 2 に内分する点
    答え

    (2B + C)/3 = ((12 + 3)/3, (0 + 6)/3) = (5, 2)

  3. A(2, 3)、B(8, 5) を 3 : 1 に内分する点
    答え

    (A + 3B)/4 = ((2 + 24)/4, (3 + 15)/4) = (13/2, 9/2)

解説の全文を読む
  1. こんにちは。知多丸の落ちこぼれ救済チャンネルです。難関大学に合格して、錯覚資産を手に入れて、一流企業に入社しよう。今日の問題は、エー かっこ 1、1、ビー かっこ 7、4、シー かっこ 4、7 のとき、辺 ビーシー を 2 たい 1 に内分する点 ディー と、三角形 エービーシー の重心 ジー の座標を求めなさい。座標でもベクトルでも、使う式は同じです。
  2. 型はこれです。エムたいエヌ の内分点は、エヌ かける 前 たす エム かける 後ろ を、エム たす エヌ で割る。比の数字が、たすきにかかるところが要点です。重心は、3つの頂点の平均、つまり 足して 3 で割るだけです。
  3. 手順1。内分点 ディー を出します。ビーシー を 2 たい 1 なので、1 かける ビー たす 2 かける シー を 3 で割ります。エックス は、7 たす 8 わる 3 で 5。ワイ は、4 たす 14 わる 3 で 6。よって ディー は かっこ 5、6 です。
  4. 手順2。重心 ジー を出します。エックス は、1 たす 7 たす 4 で 12、3 で割って 4。ワイ は、1 たす 4 たす 7 で 12、3 で割って 4。よって ジー は かっこ 4、4 です。
  5. 検算です。重心は、中線を 2 たい 1 に内分する点でもあります。ビーシー の中点 エム は かっこ 5.5、5.5。エー から エム へ、3分の2 だけ進むと、1 たす 3 で 4、1 たす 3 で 4。かっこ 4、4 に一致しました。2通りで出せるので、必ず検算できます。
  6. 差がつく2行。1つめ。外分点は、内分の式で エヌ を マイナス にするだけです。2 たい 1 の外分なら、マイナス1 かける ビー たす 2 かける シー を 1 で割ります。2つめ。重心の位置ベクトルは、3分の1 かける かっこ エーベクトル たす ビーベクトル たす シーベクトル。図形の証明では、この形のまま使うと計算が短くなります。
  7. おつかれさまでした。在庫に入れる1行は、これです。内分は、比をたすきにかけて足して、比の和で割る。重心は3つの平均。明日、何も見ずに、エー かっこ 0、0、ビー かっこ 6、0、シー かっこ 3、6 の重心をやってみてください。答えは かっこ 3、2 です。チャンネル登録をして、次の動画でも一緒に、要領よく積み上げていきましょう。
