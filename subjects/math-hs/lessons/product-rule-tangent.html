第34回　接線は「通る点と傾き＝微分係数」だけ

曲線 y = x²eˣ の x = 1 における接線の方程式を求めよ。

接線の問題は、聞かれ方が変わってもやることは2つ（点と傾き）だけです。今回は積の微分もセットで身につけます（動画・音声解説つき）。

解法の型

接線：y = f(a) + f′(a)(x − a)

積の微分：(fg)′ = f′g + fg′
(eˣ)′ = eˣ

傾きは微分係数 f′(a)。ここを迷わなければ接線の問題は全部同じです。

解答手順

  1. 通る点を出す
    f(1) = 1² × e¹ = e → 接点 (1, e)
  2. 微分して傾きを出す
    f′(x) = 2x·eˣ + x²·eˣ = (x² + 2x)eˣ
    f′(1) = 3e

    前を微分 × 後ろ ＋ 前 × 後ろを微分。eˣ は微分しても eˣ です。

  3. 接線の式に入れる
    y = e + 3e(x − 1)
    答え y = 3ex − 2e

検算：x = 1 を代入すると 3e − 2e = e で接点を通り、傾きも 3e で一致。接線は必ず「接点を代入」で確かめます。

差がつく2行

  1. 分数なら商の微分：(f/g)′ = (f′g − fg′)/g²。分子の引き算の順番だけ注意します。
  2. 曲線外の点から引く接線は、接点を t と置く。接線が通る条件から t を求めるのが型です。

覚えるべきこと（在庫に入れる1行）

接線 y = f(a) + f′(a)(x − a)（傾きは微分係数）

類題（翌日、何も見ずに）

  1. y = xeˣ の x = 0 における接線
    答え

    f(0) = 0、f′(x) = (1 + x)eˣ → f′(0) = 1 → y = x

  2. y = x³ log x の x = 1 における接線
    答え

    f(1) = 0、f′(x) = 3x² log x + x² → f′(1) = 1 → y = x − 1

  3. y = x/(x + 1) の x = 1 における接線
    答え

    f(1) = 1/2、f′(x) = 1/(x + 1)² → f′(1) = 1/4 → y = x/4 + 1/4
