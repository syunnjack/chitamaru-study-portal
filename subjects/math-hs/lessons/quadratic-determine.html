第43回　2次関数の決定は「頂点が分かれば a だけ」

頂点が (2, −3) で、点 (4, 5) を通る放物線の式を求めよ。

条件の書き方で「置く形」が決まります。ここを間違えると計算量が3倍になります（動画・音声解説つき）。

解法の型

頂点 (p, q) が分かる → y = a(x − p)² + q と置き、通る点を代入して a を出す

3点が与えられたときだけ y = ax² + bx + c と置きます。条件の形で置き方を決めるのが要領です。

解答手順

  1. 頂点の形で置く
    y = a(x - 2)² - 3

    頂点が分かっているので、この形以外は使いません。

  2. 通る点を代入
    5 = a(4 - 2)² - 3 = 4a - 3
  3. a を求める
    4a = 8 → a = 2
  4. 答えを2通りで書く
    y = 2(x - 2)² - 3 = 2x² - 8x + 5

    答えは標準形と展開形のどちらでも正解ですが、展開まで書くと検算に使えます。

検算：展開形 y = 2x² − 8x + 5 に x = 4 を代入すると 32 − 32 + 5 = 5 で通る点と一致。x = 2 では 8 − 16 + 5 = −3 で頂点の y 座標と一致します。

差がつく2行

  1. a の符号で検算できます。頂点より上を通るのに a が負、という答えは矛盾です（a > 0 で下に凸、|a| が大きいほど細い）。
  2. 軸だけ分かっている場合も同じ形で置き、q を文字のまま残して2点を代入します。3点なら y = ax² + bx + c。

覚えるべきこと（在庫に入れる1行）

頂点が分かれば y = a(x - p)² + q、あとは代入で a だけ

類題（翌日、何も見ずに）

  1. 頂点 (−1, 2) で 点 (1, 10) を通る放物線
    答え

    y = a(x + 1)² + 2 に代入して 10 = 4a + 2 → a = 2、y = 2(x + 1)² + 2

  2. 軸が x = 3 で、2点 (1, 5)、(4, 2) を通る放物線
    答え

    y = a(x − 3)² + q に代入し 4a + q = 5、a + q = 2 → a = 1、q = 1 で y = (x − 3)² + 1

  3. 3点 (0, 1)、(1, 0)、(2, 1) を通る放物線
    答え

    y = ax² + bx + c で c = 1、a + b = −1、4a + 2b = 0 → a = 1、b = −2 で y = x² − 2x + 1
