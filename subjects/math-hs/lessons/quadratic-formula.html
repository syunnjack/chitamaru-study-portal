第2回　2次方程式を解の公式で解く

次の2次方程式を解け。　x² − 5x + 3 = 0

因数分解を10秒で見切って、解の公式へ。判断の順番を固定するのがコツです（動画・音声解説つき）。

解答の手順

  1. 因数分解できるか10秒だけ考える
    かけて 3、たして −5 になる整数の組は存在しない → 見切る
  2. 係数を符号ごと書き出す
    a = 1 ,　b = −5 ,　c = 3
  3. 解の公式のルートの中を計算
    b² − 4ac = (−5)² − 4·1·3 = 25 − 12 = 13
  4. 代入して答え
    x = ( −(−5) ± √13 ) / (2·1) = ( 5 ± √13 ) / 2

20秒でできる検算（解と係数の関係）

2解の和 = 5　←　−b/a = 5
2解の積 = (25 − 13)/4 = 3　←　c/a = 3

覚えるべきこと（在庫に入れる1行）

「因数分解できない2次方程式は、a・b・c を書き出して解の公式」

x = ( −b ± √( b² − 4ac ) ) / 2a

類題（翌日、何も見ずに）

  1. x² − 3x − 1 = 0
    答え

    x = ( 3 ± √13 ) / 2

  2. 2x² + 5x + 1 = 0
    答え

    x = ( −5 ± √17 ) / 4

  3. x² − 4x + 1 = 0（ルートが簡単になります）
    答え

    x = 2 ± √3
