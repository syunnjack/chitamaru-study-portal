第2回　2次方程式を解の公式で解く

次の2次方程式を解け。　x² − 7x + 5 = 0

因数分解を10秒で見切って、解の公式へ。判断の順番を固定するのがコツです（動画・音声解説つき）。

解答の手順

  1. 因数分解できるか10秒だけ考える
    かけて 5、たして −7 になる整数の組は存在しない → 見切る
  2. 係数を符号ごと書き出す
    a = 1 ,　b = −7 ,　c = 5
  3. 解の公式のルートの中を計算
    b² − 4ac = (−7)² − 4·1·5 = 49 − 20 = 29
  4. 代入して答え
    x = ( −(−7) ± √29 ) / (2·1) = ( 7 ± √29 ) / 2

20秒でできる検算（解と係数の関係）

2解の和 = 7　←　−b/a = 7
2解の積 = (49 − 29)/4 = 5　←　c/a = 5

覚えるべきこと（在庫に入れる1行）

「因数分解できない2次方程式は、a・b・c を書き出して解の公式」

x = ( −b ± √( b² − 4ac ) ) / 2a

類題（翌日、何も見ずに）

  1. x² − 3x − 1 = 0
    答え

    x = ( 3 ± √13 ) / 2

  2. 2x² + 5x + 1 = 0
    答え

    x = ( −5 ± √17 ) / 4

  3. x² − 4x + 1 = 0（ルートが簡単になります）
    答え

    x = 2 ± √3

解説の全文を読む
  1. こんにちは。知多丸の落ちこぼれ救済チャンネルです。難関大学に合格して、錯覚資産を手に入れて、一流企業に入社しよう。今日の問題は、次の2次方程式を解け。エックスの2乗 マイナス 7エックス プラス 5 イコール 0。いっしょに、ゆっくり進めましょう。
  2. まず、方針を決めます。2次方程式を見たら、順番は決まっています。1つ目、因数分解できるか、10秒だけ考える。2つ目、できなければ、解の公式を使う。以上です。悩む場所ではありません。
  3. 今回、かけて5、たして マイナス7 になる整数の組は、ありません。ですから、因数分解はあきらめて、解の公式に進みます。あきらめる判断が早いほど、点が増えます。
  4. 解の公式は、これです。エー エックスの2乗 プラス ビー エックス プラス シー イコール 0 のとき、エックス イコール、マイナス ビー プラスマイナス ルート、ビーの2乗 マイナス 4エーシー、ぜんぶを 2エー で割る。声に出して10回、そのまま覚えてください。
  5. では、係数を書き出します。エーは1、ビーは マイナス7、シーは 5。ここで大事なのは、ビーの符号です。マイナス7 の、マイナス を、絶対に忘れないでください。ミスの半分はここで起きます。
  6. 手順の2つ目。ルートの中を計算します。ビーの2乗は、マイナス7 の2乗ですから、49。4エーシー は、4 かける 1 かける 5 で、20。49 マイナス 20 は、29。ルート29 は、これ以上、簡単になりません。
  7. 手順の3つ目。公式に入れます。マイナス ビー は、マイナス、マイナス7 ですから、プラス7。分母は、2エー で、2。したがって、エックス イコール、7 プラスマイナス ルート29、を 2 で割る。これが答えです。
  8. 検算もしておきましょう。2つの解を、たすと、7。これは、マイナス ビー わる エー と一致します。かけると、49 マイナス 29 を 4 で割って、5。これは、シー わる エー と一致します。解と係数の関係を使えば、20秒で確認できます。
  9. おつかれさまでした。今日、在庫に入れる1行は、これです。因数分解できない2次方程式は、係数を、エー、ビー、シー、と書き出して、解の公式。翌日にもう一度、何も見ずに解いてみてください。3回転で、あなたの武器になります。 チャンネル登録をして、次の動画でも一緒に、要領よく積み上げていきましょう。
