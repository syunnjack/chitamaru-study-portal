第14回　2次不等式は「グラフのどちら側」だけ

2次不等式 x² − 5x + 6 > 0 を解け。

不等号の向きで混乱しやすい問題です。境目を出して、外側か内側かを選ぶだけに単純化します（動画・音声解説つき）。

解法の型

x² の係数が正のとき　> 0 は外側　／　< 0 は内側

x² の係数が負なら、先に全体を −1 倍して不等号の向きを逆にし、正の形に直してから使います。

解答手順

  1. 因数分解する
    (x − 2)(x − 3) > 0

    かけて +6、たして −5 → −2 と −3。

  2. 境目を小さい順に出す
    x = 2 , 3
  3. 型を当てはめる（> 0 なので外側）
    x < 2 , 3 < x

    不等号に等号がないので、境目の 2 と 3 は答えに入りません。

検算：外から1点、内から1点だけ代入します。x = 0 → 6 > 0（外側は○）、x = 2.5 → −0.25 < 0（内側は×）。これで符号の勘違いが消えます。

つまずきやすい3パターン

  1. < 0 のときは内側：2 < x < 3
  2. ≦ 0 のときは境目も入る：2 ≦ x ≦ 3
  3. x² の係数が負：−x² + 5x − 6 > 0 は x² − 5x + 6 < 0 に直してから解く（答えは 2 < x < 3）。

覚えるべきこと（在庫に入れる1行）

境目を出す → > 0 は外側、< 0 は内側

類題（翌日、何も見ずに）

  1. x² − x − 6 ≦ 0
    答え

    (x + 2)(x − 3) ≦ 0、内側で等号つき → −2 ≦ x ≦ 3

  2. x² − 4x + 4 > 0
    答え

    (x − 2)² > 0。境目が重なる形なので、x = 2 以外のすべて（x ≠ 2）

  3. x² + x + 1 > 0
    答え

    D = 1 − 4 = −3 < 0 でグラフが軸と交わらず、常に上側 → すべての実数

解説の全文を読む
  1. こんにちは。知多丸の落ちこぼれ救済チャンネルです。難関大学に合格して、錯覚資産を手に入れて、一流企業に入社しよう。今日の問題は、こちら。2次不等式、xの2乗 ひく 5x たす 6 が 0より大きい、を解け。不等号の向きで混乱する人がとても多い問題です。今日で、迷いをなくします。
  2. 型はこれです。2次不等式は、まず因数分解して、グラフが0になるxを出す。そして、放物線が0より上にあるのは外側、0より下にあるのは内側。上に開いた放物線なら、大なりは外側、小なりは内側。この一言だけを覚えます。
  3. 手順1。左辺を因数分解します。かけて6、たして マイナス5 になる2つの数は、マイナス2 と マイナス3。よって、かっこ x ひく 2 かっこ x ひく 3 が 0より大きい、となります。
  4. 手順2。0になるxを書き出します。x は 2 と 3。この2つが境目です。数直線に、2 と 3 を打ってください。ここで大事なのは、この2つを大きさの順に並べることです。小さい方が2、大きい方が3ですね。
  5. 手順3。型を当てはめます。今回は0より大きい、つまり大なりなので外側。答えは、x が 2 より小さい、または、3 より大きい。これで完成です。イコールは付きません。
  6. 検算です。外側から1つ、内側から1つ、数を入れてみます。x が 0 のとき、0 ひく 0 たす 6 は 6。0より大きいので、外側は正しい。x が 2 点 5 のとき、2 点 5 の2乗は 6 点 2 5、ひく 12 点 5 たす 6 は マイナス 0 点 2 5。0より小さいので、内側は答えに入らない。合っています。
  7. つまずきやすい形も、まとめて片づけます。1つ目。0より小さいなら内側なので、答えは 2 より大きく 3 より小さい。2つ目。イコールが付いているなら、境目も答えに入れます。3つ目。xの2乗の係数が負のときは、先に全体を マイナス1 倍して、不等号の向きを逆にしてから同じ型を使います。
  8. おつかれさまでした。在庫に入れる1行は、これです。因数分解して境目を出し、上に開く放物線なら、大なりは外側、小なりは内側。明日、何も見ずに、xの2乗 ひく x ひく 6 が 0以下、をやってみてください。答えは、マイナス2 以上 3 以下 です。チャンネル登録をして、次の動画でも一緒に、要領よく積み上げていきましょう。
