第44回　共有点の個数は「判別式の符号」だけ

放物線 y = x² + 3 と直線 y = 2x + k の共有点の個数を、定数 k の値で場合分けして求めよ。

グラフを動かして悩む必要はありません。判別式に翻訳すれば計算で終わります（動画・音声解説つき）。

解法の型

連立して y を消す → 判別式 D の符号で判定（D > 0 で2個、D = 0 で1個＝接する、D < 0 で0個）

「共有点の個数」「接する」はすべて判別式の話に翻訳できます。

解答手順

  1. 連立して y を消す
    x² + 3 = 2x + k
  2. 2次方程式に整理
    x² - 2x + 3 - k = 0

    右辺を 0 にそろえるのが基本形です。

  3. 判別式を計算
    D/4 = 1 - (3 - k) = k - 2

    x の係数が偶数なら D/4 = (b/2)² − ac で計算量が半分になります。

  4. 符号で場合分け
    k > 2 のとき 2個　／　k = 2 のとき 1個（接する）　／　k < 2 のとき 0個

    境界の k = 2 は「接する」場合で、答案では必ず1個と書きます。

検算：k = 3 を代入すると x² − 2x = 0 で x = 0, 2 の2個。k = 2 なら (x − 1)² = 0 の重解で1個。境界の値を代入するのが最強の検算です。

差がつく2行

  1. 接するときは重解なので、接点の x 座標は −b / 2a。今回は x = 1、y = 4 で接点 (1, 4)。
  2. x の係数が偶数なら D/4 = (b/2)² − ac。D = b² − 4ac を毎回使うと数が大きくなり、ミスが増えます。

覚えるべきこと（在庫に入れる1行）

共有点の個数 = 連立して判別式の符号

類題（翌日、何も見ずに）

  1. y = x² と y = 4x + k が接する k
    答え

    x² − 4x − k = 0 で D/4 = 4 + k = 0 → k = −4

  2. y = x² + 3 と y = 2x + 6 の共有点の座標
    答え

    k = 6 > 2 なので2個。x² − 2x − 3 = 0 → x = −1, 3 で (−1, 4)、(3, 12)

  3. y = −x² + 1 と y = x + k が共有点をもたない k の範囲
    答え

    x² + x + k − 1 = 0 で D = 1 − 4(k − 1) < 0 → k > 5/4
