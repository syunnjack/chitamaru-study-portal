第45回　解の符号は「和と積」で決まる

2次方程式 x² − (m + 1)x + m − 2 = 0 が異符号の2つの解をもつような定数 m の範囲を求めよ。

解を求めずに、係数の条件だけで決めます。異符号なら条件は1つだけです（動画・音声解説つき）。

解法の型

異符号の2解 ⇔ （2解の積）< 0　＝ c/a < 0

積が負なら判別式は自動的に正になるので、D > 0 の条件は不要です。ここを書かずに減点されない形が最短です。

解答手順

  1. 解の積を作る
    積 = (m - 2) / 1 = m - 2

    係数がそのまま積になります（a = 1 のとき）。

  2. 異符号の条件
    m - 2 < 0
  3. 答えを出す
    m < 2
  4. 判別式が不要な理由
    積 < 0 なら D = (和)² - 4(積) > 0 が自動で成立

    「積が負 → 判別式は自動で正」は答案に一言書けば十分です。

検算：m = 0 なら x² − x − 2 = 0 で x = 2, −1 の異符号。範囲の外の m = 3 では積が 1 > 0 で同符号になり条件を満たしません。範囲の内と外の両方で試すのが確実です。

差がつく2行

  1. 2解とも正なら「D ≧ 0 かつ 和 > 0 かつ 積 > 0」の3点セット。異符号のときだけ積1つで済みます。
  2. 「2解とも 1 より大きい」のように境界がずれたらグラフで判定：D の符号、軸の位置、f(1) の符号の3つを見ます。

覚えるべきこと（在庫に入れる1行）

異符号 ⇔ 解の積 < 0（判別式は不要）

類題（翌日、何も見ずに）

  1. x² + mx + m − 3 = 0 が異符号の2解をもつ m の範囲
    答え

    積 = m − 3 < 0 → m < 3

  2. x² − 5x + m = 0 が2つとも正の解をもつ m の範囲
    答え

    D = 25 − 4m ≧ 0、和 = 5 > 0、積 = m > 0 → 0 < m ≦ 25/4

  3. x² − (m + 1)x + m − 2 = 0 の2解の和が 4 になる m
    答え

    和 = m + 1 = 4 → m = 3
