第1回　放物線の頂点を求める

次の式で表される放物線の頂点を求めよ。　y = x² + 12x + 20

使う型は平方完成ひとつだけです。まずは動画で流れをつかんでください（約4分半・音声解説つき）。

解答の手順

  1. x の係数を半分にする
    12 ÷ 2 = 6　←　かっこの中に入る数
  2. かっこを作り、増えた分を引く
    (x + 6)² = x² + 12x + 36　なので　x² + 12x = (x + 6)² − 36
  3. もとの式に戻して整理する
    y = (x + 6)² − 36 + 20 = (x + 6)² − 16
  4. y = a(x − p)² + q の形から読み取る
    頂点 ( −6 , −16 )

    かっこの中が「+6」なら x 座標は「−6」。符号の反転が最頻出ミスです。

30秒でできる検算

x = −b / 2a = −12 / 2 = −6
y = (−6)² + 12(−6) + 20 = 36 − 72 + 20 = −16

2通りで同じ答えになれば、安心して次の問題へ進めます。検算の型を1つ持っておくことが、本番の得点を守ります。

覚えるべきこと（在庫に入れる1行）

「頂点を聞かれたら平方完成。x の係数を半分にして2乗した数を引く」

類題（翌日、何も見ずに）

  1. y = x² + 6x + 1 の頂点を求めよ。
    答え

    y = (x + 3)² − 8　より　頂点 ( −3 , −8 )

  2. y = x² − 10x + 22 の頂点を求めよ。
    答え

    y = (x − 5)² − 3　より　頂点 ( 5 , −3 )

  3. y = x² + 5x の頂点を求めよ（分数が出ます）。
    答え

    y = (x + 5/2)² − 25/4　より　頂点 ( −5/2 , −25/4 )

復習の3回転：今日は書き写すだけでOK。翌日に何も見ずに1問、1週間後は「平方完成」と方針を言えるかだけ確認してください。5分考えて出てこない問題は、答えを見てよい問題です。

  2. まず、ゴールをはっきりさせます。放物線の頂点とは、グラフのいちばん下、または、いちばん上の点のことです。そして、式が、わい イコール エー かっこ エックス マイナス ピー かっこの2乗 プラス キュー、の形になっていれば、頂点は、ピー、キュー と、すぐに読み取れます。
