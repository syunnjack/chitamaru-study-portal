第1回　放物線の頂点を求める

次の式で表される放物線の頂点を求めよ。　y = x² + 8x + 5

使う型は平方完成ひとつだけです。まずは動画で流れをつかんでください（約4分半・音声解説つき）。

解答の手順

  1. x の係数を半分にする
    8 ÷ 2 = 4　←　かっこの中に入る数
  2. かっこを作り、増えた分を引く
    (x + 4)² = x² + 8x + 16　なので　x² + 8x = (x + 4)² − 16
  3. もとの式に戻して整理する
    y = (x + 4)² − 16 + 5 = (x + 4)² − 11
  4. y = a(x − p)² + q の形から読み取る
    頂点 ( −4 , −11 )

    かっこの中が「+4」なら x 座標は「−4」。符号の反転が最頻出ミスです。

30秒でできる検算

x = −b / 2a = −8 / 2 = −4
y = (−4)² + 8(−4) + 5 = 16 − 32 + 5 = −11

2通りで同じ答えになれば、安心して次の問題へ進めます。検算の型を1つ持っておくことが、本番の得点を守ります。

覚えるべきこと（在庫に入れる1行）

「頂点を聞かれたら平方完成。x の係数を半分にして2乗した数を引く」

類題（翌日、何も見ずに）

  1. y = x² + 6x + 1 の頂点を求めよ。
    答え

    y = (x + 3)² − 8　より　頂点 ( −3 , −8 )

  2. y = x² − 10x + 22 の頂点を求めよ。
    答え

    y = (x − 5)² − 3　より　頂点 ( 5 , −3 )

  3. y = x² + 5x の頂点を求めよ（分数が出ます）。
    答え

    y = (x + 5/2)² − 25/4　より　頂点 ( −5/2 , −25/4 )

復習の3回転：今日は書き写すだけでOK。翌日に何も見ずに1問、1週間後は「平方完成」と方針を言えるかだけ確認してください。5分考えて出てこない問題は、答えを見てよい問題です。
