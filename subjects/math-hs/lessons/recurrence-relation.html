第27回　漸化式 aₙ₊₁ = 2aₙ + 3 は「+3 を消して等比にする」

a₁ = 1、aₙ₊₁ = 2aₙ + 3 で定まる数列の一般項 aₙ を求めよ。

漸化式は型が5つしかありません。今日はいちばん出る「かける定数 + 定数」型です（動画・音声解説つき）。

解法の型

aₙ₊₁ = p aₙ + q は、特性方程式 x = p x + q の解を使って等比数列に直す

解が x のとき、aₙ − x が等比数列（公比 p）になります。

解答手順

  1. 特性方程式を解く
    x = 2x + 3 → x = −3

    aₙ − (−3) = aₙ + 3 を見ればよい、ということです。

  2. 等比数列に直す
    aₙ₊₁ + 3 = 2(aₙ + 3)
    初項 a₁ + 3 = 4、公比 2 → aₙ + 3 = 4 × 2ⁿ⁻¹ = 2ⁿ⁺¹
  3. もとに戻す
    aₙ = 2ⁿ⁺¹ − 3

検算：n = 1 で 2² − 3 = 1 = a₁、n = 2 で 2³ − 3 = 5 は漸化式の 2 × 1 + 3 = 5 と一致。最初の2項を必ず両方で確かめます。

差がつく2行

  1. p = 1 のときは等比にならず等差数列（aₙ₊₁ = aₙ + 3、a₁ = 1 なら aₙ = 3n − 2）。
  2. 右辺に n が入る型（aₙ₊₁ = 2aₙ + n）は、aₙ + αn + β と置いて係数比較、または階差を取ります。

覚えるべきこと（在庫に入れる1行）

aₙ₊₁ = p aₙ + q → 特性方程式の解を足して等比にする

類題（翌日、何も見ずに）

  1. a₁ = 3、aₙ₊₁ = 3aₙ − 4 の一般項
    答え

    x = 3x − 4 → x = 2 → aₙ − 2 = 1 × 3ⁿ⁻¹ → aₙ = 3ⁿ⁻¹ + 2

  2. a₁ = 2、aₙ₊₁ = aₙ + 5 の一般項
    答え

    公差 5 の等差数列 → aₙ = 5n − 3

  3. a₁ = 1、aₙ₊₁ = (1/2)aₙ + 1 の一般項
    答え

    x = x/2 + 1 → x = 2 → aₙ − 2 = −(1/2)ⁿ⁻¹ → aₙ = 2 − (1/2)ⁿ⁻¹
