第66回　Σ の計算は「ばらして公式3つ」

Σ（k = 1 から n）k(k + 2) を n の式で表せ。

かっこのままでは計算できません。展開してばらす、これが最初の一手です（動画・音声解説つき）。

解法の型

展開 → Σk = n(n+1)/2、Σk² = n(n+1)(2n+1)/6 を使う → 共通因数でくくる

くくらずに展開したままだと、検算もできず、後の計算でも使えません。必ず因数の形で答えます。

解答手順

  1. 展開する
    k(k + 2) = k² + 2k
  2. Σ をばらす
    Σk² + 2Σk

    定数倍は Σ の外に出せます。

  3. 公式を入れる
    n(n+1)(2n+1)/6 + 2 × n(n+1)/2 = n(n+1)(2n+1)/6 + n(n+1)
  4. くくってまとめる
    = n(n+1){(2n+1) + 6} / 6 = n(n+1)(2n+7) / 6

    共通因数 n(n+1)/6 でくくるのが一番速いまとめ方です。

検算：n = 3 なら公式は 3×4×13/6 = 26、直接計算も 3 + 8 + 15 = 26。n = 1 でも両方 3 で一致します。小さい n を2つ代入するのが数列の検算です。

差がつく2行

  1. 答えは必ず因数の形に。展開したままでは代入検算がしにくく、後の設問でも使えません。
  2. 上端が n − 1 なら公式の n を n − 1 に置きかえるだけ（階差数列で必ず出ます）。

覚えるべきこと（在庫に入れる1行）

Σk = n(n+1)/2、Σk² = n(n+1)(2n+1)/6、最後にくくる

類題（翌日、何も見ずに）

  1. Σ(k = 1 から n) k(k + 1)
    答え

    Σk² + Σk = n(n+1)(2n+1)/6 + n(n+1)/2 = n(n+1)(n+2)/3

  2. Σ(k = 1 から n) (2k − 1)
    答え

    2·n(n+1)/2 − n = n²（奇数の和は n²）

  3. Σ(k = 1 から n−1) k²
    答え

    公式の n を n−1 にして (n−1)n(2n−1)/6
