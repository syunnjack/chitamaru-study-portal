第4回　正弦定理で辺の長さを求める

△ABC で A = 30°、C = 105°、BC = 4 のとき、CA の長さを求めよ。

角2つ＋辺1つ → 正弦定理。辺と「向かいの角」の対応をとるのが要点です（動画・音声解説つき）。

型の見分け方

与えられたもの使う定理
角2つ＋辺1つ正弦定理
辺3つ／辺2つ＋はさむ角余弦定理

解答の手順

  1. 辺と向かいの角を対応させる
    BC は A の対辺、CA は B の対辺 → CA には角 B が必要
  2. 残りの角を出す
    B = 180° − 30° − 105° = 45°
  3. 正弦定理に代入
    BC / sin A = CA / sin B　→　4 / sin30° = CA / sin45°
  4. 計算する（わり算は逆数のかけ算）
    CA = 4 · (√2/2) ÷ (1/2) = 2√2 × 2 = 4√2

検算（大小関係）

三角形では大きい角の向かいに長い辺が来ます。B = 45° > A = 30° なので CA > BC = 4 のはず。4√2 ≒ 5.66 > 4 で矛盾なし。

覚えるべきこと（在庫に入れる1行）

「角2つ＋辺1つなら正弦定理。辺を向かいの角の sin で割る」

BC / sin A = CA / sin B = AB / sin C = 2R

類題（翌日、何も見ずに）

  1. △ABC で A = 30°、B = 105°、BC = 6 のとき CA を求めよ。
    答え

    CA は角 B の対辺。CA = BC·sin B / sin A = 6·sin105°/sin30° = 12 sin105° = 3(√6 + √2)

  2. △ABC で A = 60°、B = 45°、AB = 6 のとき BC を求めよ。
    答え

    C = 180° − 60° − 45° = 75°。BC は角 A の対辺、AB は角 C の対辺なので BC = AB·sin A / sin C = 6·(√3/2) / ((√6+√2)/4) = 12√3/(√6+√2) = 9√2 − 3√6（≒ 5.38）
