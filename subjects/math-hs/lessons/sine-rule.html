第4回　正弦定理で辺の長さを求める

△ABC で A = 30°、C = 105°、BC = 4 のとき、CA の長さを求めよ。

角2つ＋辺1つ → 正弦定理。辺と「向かいの角」の対応をとるのが要点です（動画・音声解説つき）。

型の見分け方

与えられたもの使う定理
角2つ＋辺1つ正弦定理
辺3つ／辺2つ＋はさむ角余弦定理

解答の手順

  1. 辺と向かいの角を対応させる
    BC は A の対辺、CA は B の対辺 → CA には角 B が必要
  2. 残りの角を出す
    B = 180° − 30° − 105° = 45°
  3. 正弦定理に代入
    BC / sin A = CA / sin B　→　4 / sin30° = CA / sin45°
  4. 計算する（わり算は逆数のかけ算）
    CA = 4 · (√2/2) ÷ (1/2) = 2√2 × 2 = 4√2

検算（大小関係）

三角形では大きい角の向かいに長い辺が来ます。B = 45° > A = 30° なので CA > BC = 4 のはず。4√2 ≒ 5.66 > 4 で矛盾なし。

覚えるべきこと（在庫に入れる1行）

「角2つ＋辺1つなら正弦定理。辺を向かいの角の sin で割る」

BC / sin A = CA / sin B = AB / sin C = 2R

類題（翌日、何も見ずに）

  1. △ABC で A = 30°、B = 105°、BC = 6 のとき CA を求めよ。
    答え

    CA は角 B の対辺。CA = BC·sin B / sin A = 6·sin105°/sin30° = 12 sin105° = 3(√6 + √2)

  2. △ABC で A = 60°、B = 45°、AB = 6 のとき BC を求めよ。
    答え

    C = 180° − 60° − 45° = 75°。BC は角 A の対辺、AB は角 C の対辺なので BC = AB·sin A / sin C = 6·(√3/2) / ((√6+√2)/4) = 12√3/(√6+√2) = 9√2 − 3√6（≒ 5.38）

動画の音声ナレーション

解説の全文を読む
  1. こんにちは。知多丸の落ちこぼれ救済チャンネルです。難関大学に合格して、錯覚資産を手に入れて、一流企業に入社しよう。今日の問題は、三角形エービーシーについて。エー イコール 30度、シー イコール 105度、ビーシー イコール 4 のとき、シーエー の長さを求めよ。図をかきながら、いっしょに進めましょう。
  2. まず、型を思い出します。角が2つ、辺が1つ、そして知りたいのは、別の辺。このパターンは、正弦定理です。角と辺が交ざっている問題は、正弦定理か余弦定理の2択。今回は、角2つと辺1つなので、正弦定理です。
  3. 次に、辺と角の対応を確認します。とても大事なところです。ビーシー は、角エー の向かい側にある辺。シーエー は、角ビー の向かい側にある辺。つまり、シーエー を求めるには、角ビー が必要になります。
  4. では、角ビー を出します。三角形の内角の和は、180度。180度 マイナス 30度 マイナス 105度 は、45度。角ビー は、45度 です。ここまでで、準備が終わりました。
  5. 正弦定理は、これです。ビーシー を サイン エー で割ったものと、シーエー を サイン ビー で割ったものが、等しい。辺を、その向かいの角の サイン で割る。どの組でも同じ値になる、というのが正弦定理です。
  6. 代入します。4 わる サイン30度 イコール、シーエー わる サイン45度。したがって、シーエー イコール、4 かける サイン45度 わる サイン30度。ここで、サイン45度 は、ルート2 わる 2。サイン30度 は、2分の1 です。
  7. 計算します。分子は、4 かける ルート2 わる 2 で、2 ルート2。これを、2分の1 で割るので、2 をかけて、4 ルート2。シーエー イコール 4 ルート2。これが答えです。わり算は、逆数のかけ算にすると、ミスが減ります。
  8. 答えの確かめ方も覚えましょう。三角形では、大きい角の向かいに、長い辺が来ます。角ビー は 45度 で、角エー の 30度 より大きい。ですから、シーエー は、ビーシー の 4 より長いはず。4 ルート2 は、およそ 5.66。ちゃんと 4 より大きいので、つじつまが合っています。
  9. おつかれさまでした。在庫に入れる1行は、角2つと辺1つなら正弦定理、辺を向かいの角のサインで割る。翌日、何も見ずに、もう一度解いてみてください。3回転すれば、確実にあなたの武器になります。次の問題でも、お待ちしています。 チャンネル登録をして、次の動画でも一緒に、要領よく積み上げていきましょう。
