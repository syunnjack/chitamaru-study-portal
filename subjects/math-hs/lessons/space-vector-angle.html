第38回　空間ベクトルも「内積 ÷ 大きさの積」で角が出る

a = (1, 1, 0)、b = (0, 1, 1) のなす角 θ を求めよ。

空間になっても平面とまったく同じ式です。成分が1つ増えるだけなので、新しく覚えることはありません（動画・音声解説つき）。

解法の型

cosθ = (a·b)/(|a||b|)

a·b = x₁x₂ + y₁y₂ + z₁z₂
|a| = √(x² + y² + z²)

内積には「成分でかけて足す」と「大きさの積 × cosθ」の2つの顔があります。それを結ぶだけです。

解答手順

  1. 内積を出す
    a·b = 1×0 + 1×1 + 0×1 = 1
  2. 大きさを出す
    |a| = √2、|b| = √2 → |a||b| = 2
  3. 角を出す
    cosθ = 1/2
    0° ≦ θ ≦ 180° より 答え θ = 60°

検算：内積が正なので鋭角。60° は条件を満たします。内積 0 なら 90°、負なら鈍角で、符号だけで答えの位置が確認できます。

差がつく2行

  1. 垂直 ⇔ 内積 0。(1, 2, 3) と (2, −1, k) が垂直なら 2 − 2 + 3k = 0 → k = 0。
  2. 和の大きさは2乗して展開：|a + b|² = |a|² + 2a·b + |b|²。今回は 2 + 2 + 2 = 6 → |a + b| = √6。

覚えるべきこと（在庫に入れる1行）

cosθ = (a·b)/(|a||b|)（空間でも同じ）

類題（翌日、何も見ずに）

  1. (2, −1, 2) と (1, 2, 2) のなす角の cos
    答え

    内積 = 2 − 2 + 4 = 4、|a| = |b| = 3 → cosθ = 4/9

  2. (1, 2, 3) と (2, −1, k) が垂直となる k
    答え

    2 − 2 + 3k = 0 → k = 0

  3. a = (1, 1, 0)、b = (0, 1, 1) のとき |a − b|
    答え

    |a − b|² = 2 − 2×1 + 2 = 2 → |a − b| = √2
