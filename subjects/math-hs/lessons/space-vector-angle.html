第38回　空間ベクトルも「内積 ÷ 大きさの積」で角が出る

a = (1, 1, 0)、b = (0, 1, 1) のなす角 θ を求めよ。

空間になっても平面とまったく同じ式です。成分が1つ増えるだけなので、新しく覚えることはありません（動画・音声解説つき）。

解法の型

cosθ = (a·b)/(|a||b|)

a·b = x₁x₂ + y₁y₂ + z₁z₂
|a| = √(x² + y² + z²)

内積には「成分でかけて足す」と「大きさの積 × cosθ」の2つの顔があります。それを結ぶだけです。

解答手順

  1. 内積を出す
    a·b = 1×0 + 1×1 + 0×1 = 1
  2. 大きさを出す
    |a| = √2、|b| = √2 → |a||b| = 2
  3. 角を出す
    cosθ = 1/2
    0° ≦ θ ≦ 180° より 答え θ = 60°

検算：内積が正なので鋭角。60° は条件を満たします。内積 0 なら 90°、負なら鈍角で、符号だけで答えの位置が確認できます。

差がつく2行

  1. 垂直 ⇔ 内積 0。(1, 2, 3) と (2, −1, k) が垂直なら 2 − 2 + 3k = 0 → k = 0。
  2. 和の大きさは2乗して展開：|a + b|² = |a|² + 2a·b + |b|²。今回は 2 + 2 + 2 = 6 → |a + b| = √6。

覚えるべきこと（在庫に入れる1行）

cosθ = (a·b)/(|a||b|)（空間でも同じ）

類題（翌日、何も見ずに）

  1. (2, −1, 2) と (1, 2, 2) のなす角の cos
    答え

    内積 = 2 − 2 + 4 = 4、|a| = |b| = 3 → cosθ = 4/9

  2. (1, 2, 3) と (2, −1, k) が垂直となる k
    答え

    2 − 2 + 3k = 0 → k = 0

  3. a = (1, 1, 0)、b = (0, 1, 1) のとき |a − b|
    答え

    |a − b|² = 2 − 2×1 + 2 = 2 → |a − b| = √2

  2. 型はこれです。内積は、成分をそれぞれかけて足す。同時に、大きさの積 かける コサイン シータ でもある。この2つを結んで、コサイン シータ は 内積 わる 大きさの積 です。
  3. 手順1。内積を出します。1 かける 0 は 0、1 かける 1 は 1、0 かける 1 は 0。足して 1 です。
  4. 手順2。大きさを出します。エーベクトル の大きさは、1 たす 1 たす 0 のルートで ルート2。ビーベクトル も、0 たす 1 たす 1 のルートで ルート2。積は 2 です。
  5. 手順3。コサイン シータ は、1 わる 2 で 2分の1。0 度から 180 度の範囲で、コサインが 2分の1 になるのは 60 度。答えは 60 度です。

  7. 差がつく2行。1つめ。垂直は内積 0。たとえば エーベクトル かっこ 1、2、3 と かっこ 2、マイナス1、ケー が垂直なら、2 ひく 2 たす 3ケー は 0 で、ケー は 0 です。2つめ。和の大きさは、二乗して展開します。エー たす ビー の大きさの二乗は、エー の二乗 たす 2 かける 内積 たす ビー の二乗。今回なら 2 たす 2 たす 2 で 6、大きさは ルート6 です。
