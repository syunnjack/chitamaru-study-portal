第29回　置換積分は「かたまりを t にする」

∫₀¹ x √(x² + 1) dx を求めよ。

どこを t にするかを見抜くだけの作業です（動画・音声解説つき）。

解法の型

中身を微分した形が外にかかっている → 置換積分

t = x² + 1 とおくと dt = 2x dx、つまり x dx = dt / 2 と読みかえます。

解答手順

  1. 区間も置きかえる
    x = 0 → t = 1、x = 1 → t = 2
    ∫₀¹ x √(x² + 1) dx = (1/2) ∫₁² √t dt

    区間の置きかえ忘れが最頻ミスです。

  2. 計算する
    (1/2)[ (2/3) t^(3/2) ]₁² = (1/3)[ t^(3/2) ]₁²
    = (2√2 − 1) / 3

検算：(2√2 − 1)/3 ≒ 0.61。被積分関数は x = 1 で √2 ≒ 1.41 まで増える関数なので、面積 0.6 程度は妥当です。

差がつく2行

  1. かたまりの微分が外にないときは部分積分を疑う（多項式 × 三角関数・指数関数）。
  2. 置換したら必ず dx を dt に直す。x が残ったら置換の選び方が誤りです。

覚えるべきこと（在庫に入れる1行）

中身の微分が外 → t で置換、区間も置きかえる

類題（翌日、何も見ずに）

  1. ∫₀¹ x (x² + 1)³ dx
    答え

    t = x² + 1 → (1/2)∫₁² t³ dt = 15/8

  2. ∫ 2x / (x² + 1) dx
    答え

    t = x² + 1 → log|x² + 1| + C

  3. ∫₀^(π/2) sinx cosx dx
    答え

    t = sinx → ∫₀¹ t dt = 1/2

解説の全文を読む
  1. こんにちは。知多丸の落ちこぼれ救済チャンネルです。難関大学に合格して、錯覚資産を手に入れて、一流企業に入社しよう。今日の問題は、0 から 1 まで、エックス かける ルート かっこ エックス2乗 たす 1 を エックス で積分しなさい。置換積分は、どこを ティー にするかを見抜くだけの作業です。
  2. 型はこれです。かたまりの中身を微分した形が、外にかかっているときは置換積分。今回は エックス2乗 たす 1 を微分すると 2エックス で、外に エックス があります。だから エックス2乗 たす 1 を ティー と置きます。
  3. 手順1。積分区間も ティー に直します。ここが最大のミスどころです。エックス が 0 のとき ティー は 1、エックス が 1 のとき ティー は 2。よって、1 から 2 までの積分になります。
  4. 手順2。計算します。ルート ティー は ティー の 2分の1乗 なので、原始関数は 3分の2 かける ティー の 2分の3乗。2分の1 をかけて、3分の1 かける ティー の 2分の3乗。ティー に 2 を入れて 2ルート2、1 を入れて 1。よって 3分の1 かける かっこ 2ルート2 ひく 1 です。
  5. 検算です。おおよその値で確かめます。ルート2 は およそ 1.414 なので、2ルート2 は およそ 2.83。2.83 ひく 1 は 1.83、3 で割って およそ 0.61。積分する関数は 0 から 1 で だいたい 0 から 1.41 まで増える関数なので、面積が 0.6 くらいというのは自然です。
  6. 差がつく2行。1つめ。かたまりの微分が外にないときは、部分積分を疑います。エックス かける コサイン エックス のように、多項式 かける 三角関数 や 指数関数 は部分積分です。2つめ。置換したら、必ず ディー エックス を ディー ティー に直す。エックス の式が残っていたら、置換の選び方がまちがっています。
  7. おつかれさまでした。在庫に入れる1行は、これです。かたまりの微分が外にあれば置換積分、区間も一緒に置きかえる。明日、何も見ずに、0 から 1 まで、エックス かける かっこ エックス2乗 たす 1 の3乗 を積分してみてください。答えは 8分の15 です。チャンネル登録をして、次の動画でも一緒に、要領よく積み上げていきましょう。
