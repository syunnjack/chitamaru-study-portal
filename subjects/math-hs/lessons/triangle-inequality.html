第5回　三角形が成立するための範囲

三角形の3辺の長さがそれぞれ 2、x + 3、3 のとき、三角形が成立する x の値の範囲を求めよ。

場合分けは不要です。文字の入った辺を真ん中にはさむ形を使います（動画・音声解説つき）。

使う型

| b − c | < a < b + c　（a に文字の入った辺を置く）

「いちばん長い辺 < 他の2辺の和」を、場合分けせずに1本で処理できる形です。

解答の手順

  1. 不等式を作る
    | 3 − 2 | = 1、2 + 3 = 5　→　1 < x + 3 < 5
  2. 各辺から 3 を引く
    1 − 3 < x < 5 − 3　→　−2 < x < 2
  3. 辺の長さが正であることを確認
    −2 < x のとき x + 3 > 1 > 0　→　追加条件なし

答え：−2 < x < 2　等号は入りません。x = 2 だと 3辺が 2, 5, 3 となり 2 + 3 = 5 でつぶれてしまいます。

検算（境界を代入）

  • x = 0 → 3辺は 2, 3, 3 … 三角形になる ○
  • x = 2 → 3辺は 2, 5, 3 … 2 + 3 = 5 で平らにつぶれる ×

覚えるべきこと（在庫に入れる1行）

「三角形の成立条件は、文字の辺を真ん中に置いて |差| < 文字の辺 < 和」

類題（翌日、何も見ずに）

  1. 3辺が 4、x、7 のとき x の範囲。
    答え

    | 7 − 4 | < x < 7 + 4 より 3 < x < 11

  2. 3辺が 5、x + 1、6 のとき x の範囲。
    答え

    1 < x + 1 < 11 より 0 < x < 10

  3. 3辺が x、x + 2、x + 4 のとき x の範囲。
    答え

    最長は x + 4。x + 4 < x + (x + 2) より x > 2
