第17回　sinθ + cosθ が出たら「2乗する」

sinθ + cosθ = 1/2 のとき、sinθ cosθ の値を求めよ。

θ そのものを求めようとすると詰まります。式のまま処理するのが要領です（動画・音声解説つき）。

解法の型

和が与えられたら両辺を2乗し、sin²θ + cos²θ = 1 を代入する。

θ の値は求めません。和と積だけで処理します。

解答手順

  1. 両辺を2乗
    (sinθ + cosθ)² = (1/2)² → sin²θ + 2 sinθcosθ + cos²θ = 1/4
  2. 相互関係を代入
    1 + 2 sinθcosθ = 1/4

    sin²θ + cos²θ が 1 に変わるのが、この型の要点です。

  3. 解く
    2 sinθcosθ = 1/4 − 1 = −3/4 → sinθ cosθ = −3/8

検算：積が負なので sinθ と cosθ の符号が逆、つまり θ は鈍角。和が 1/2 と小さいことと合います。sinθ, cosθ は t² − (1/2)t − 3/8 = 0 の2解で、判別式 1/4 + 3/2 > 0 なので実際に存在します。

差がつく2行

  1. 和と積が出たら、対称式は全部作れる。sin³θ + cos³θ =（和）³ − 3（積）（和）= 1/8 + 9/16 = 11/16。
  2. 差を聞かれても同じ。(sinθ − cosθ)² = 1 − 2 sinθcosθ = 1 + 3/4 = 7/4。

覚えるべきこと（在庫に入れる1行）

sinθ + cosθ が来たら2乗 → sin²θ + cos²θ = 1

類題（翌日、何も見ずに）

  1. sinθ + cosθ = 1/5 のとき sinθ cosθ
    答え

    1 + 2sinθcosθ = 1/25 → sinθcosθ = −12/25

  2. sinθ cosθ = 1/4 のとき (sinθ + cosθ)²
    答え

    1 + 2(1/4) = 3/2

  3. sinθ + cosθ = 1/2 のとき (sinθ − cosθ)²
    答え

    1 − 2(−3/8) = 7/4

解説の全文を読む
  1. こんにちは。知多丸の落ちこぼれ救済チャンネルです。難関大学に合格して、錯覚資産を手に入れて、一流企業に入社しよう。今日の問題は、こちら。サイン シータ たす コサイン シータ が 2分の1 のとき、サイン シータ かける コサイン シータ の値を求めよ。角シータそのものを求めようとすると詰まります。やることは1つだけです。
  2. 型はこれです。サインとコサインの和が与えられたら、両辺を2乗する。そして、サインの2乗 たす コサインの2乗 は 1、という相互関係を使う。この2行がセットです。角シータを求める必要は、まったくありません。
  3. 手順1。両辺を2乗します。左辺は、和の2乗の展開です。サインの2乗 たす 2 サイン コサイン たす コサインの2乗。右辺は、2分の1の2乗で 4分の1。
  4. 手順2。相互関係を代入します。サインの2乗 たす コサインの2乗 は 1。だから左辺は、1 たす 2 サイン コサイン。式は、1 たす 2 サイン コサイン は 4分の1 になります。
  5. 手順3。方程式として解きます。2 サイン コサイン は、4分の1 ひく 1 で、マイナス4分の3。両辺を2で割って、サイン コサイン は マイナス8分の3。これが答えです。
  6. 検算です。マイナスになりましたが、これはおかしくありません。積が負ということは、サインとコサインの符号が逆、つまりシータは90度より大きい、鈍角だということです。和が 2分の1 と小さいことと、つじつまが合っています。実際、サインとコサインは、2次方程式 tの2乗 ひく 2分の1 t マイナス 8分の3 は 0 の2つの解で、判別式は正なので、ちゃんと存在します。
  7. この型は、もう1段だけ伸ばせます。3乗の和を聞かれても同じです。サインの3乗 たす コサインの3乗 は、和の3乗 ひく 3 かける積 かける和。代入すると、8分の1 たす 16分の9 で、16分の11。和と積さえ分かれば、あとは公式に入れるだけです。
  8. おつかれさまでした。在庫に入れる1行は、これです。サインとコサインの和が来たら、2乗して 1 に変える。明日、何も見ずに、サイン たす コサイン が 5分の1 のときの積をやってみてください。答えは、マイナス25分の12 です。チャンネル登録をして、次の動画でも一緒に、要領よく積み上げていきましょう。
