第75回　sin² の積分は「半角で次数を下げる」

定積分 ∫（0 から π/2）sin²x dx を求めよ。

2乗のままでは積分できません。半角で次数を下げるのが唯一の道です（動画・音声解説つき）。

解法の型

sin²x = (1 − cos 2x)/2　／　cos²x = (1 + cos 2x)/2

2乗のままでは積分できません。半角で「1次」に落とすのが唯一の道です（sin はマイナス、cos はプラス）。

解答手順

  1. 半角で次数を下げる
    sin²x = (1 - cos2x) / 2
  2. 積分を分ける
    ∫(0→π/2) (1/2) dx - ∫(0→π/2) (cos2x)/2 dx
  3. 前半を計算
    (1/2) × (π/2) = π/4
  4. 後半を計算
    [ sin2x / 4 ] (0→π/2) = (sinπ)/4 - 0 = 0 → 答え π/4

    cos2x の積分は sin2x ÷ 2。中身の 2 で割るのを忘れないこと。

検算：区間の幅 π/2 に平均 1/2 をかけると π/4。同じ区間の ∫cos²x dx も π/4 で、足すと ∫1 dx = π/2 になり、つじつまが合います。

差がつく2行

  1. cos(ax) の積分は a で割る。微分の逆だと理解すれば忘れません。
  2. 偶数乗は半角、奇数乗は置換。sin³x なら sin²x = 1 − cos²x に直して cos x = t と置きます。

覚えるべきこと（在庫に入れる1行）

sin²x = (1 - cos2x)/2 で次数を下げる

類題（翌日、何も見ずに）

  1. ∫(0 から π) sin²x dx
    答え

    (1 − cos2x)/2 を積分して π/2

  2. ∫(0 から π/2) cos²x dx
    答え

    (1 + cos2x)/2 を積分して π/4

  3. ∫(0 から π/2) sin x cos x dx
    答え

    sin x cos x = (sin2x)/2 なので [−cos2x/4] = 1/2
