第24回　三角関数の合成は「1つの sin にまとめる」

y = sinθ + √3 cosθ（0 ≦ θ < 2π）の最大値・最小値と、そのときの θ を求めよ。

サインとコサインが混ざった式は、合成して1つのサインにするだけで終わります（動画・音声解説つき）。

解法の型

a sinθ + b cosθ = √(a² + b²) sin(θ + α)

振幅は √(a² + b²)、α は cosα = a / 振幅、sinα = b / 振幅 になる角（点 (a, b) の角）です。

解答手順

  1. 合成する
    √(1² + (√3)²) = 2
    cosα = 1/2、sinα = √3/2 → α = π/3
    y = 2 sin(θ + π/3)
  2. 中身の範囲を調べる
    π/3 ≦ θ + π/3 < 7π/3

    この範囲で sin は −1 から 1 まで取れるので、最大 2、最小 −2。

  3. θ を求める
    最大：θ + π/3 = π/2 → θ = π/6
    最小：θ + π/3 = 3π/2 → θ = 7π/6

検算：θ = π/6 を代入すると 1/2 + √3 × √3/2 = 1/2 + 3/2 = 2 で最大値と一致します。

差がつく2行

  1. 合成の角 α は点 (a, b) の角。今回は (1, √3) なので 60°。図で確認すれば符号をまちがえません。
  2. cos でまとめる形（cos(θ − α)）もありますが、入試では sin に統一するのが標準です。

覚えるべきこと（在庫に入れる1行）

混ざったら √(a² + b²) sin(θ + α) にまとめる

類題（翌日、何も見ずに）

  1. y = √3 sinθ + cosθ の最大値と、そのときの θ
    答え

    2 sin(θ + π/6) → 最大 2（θ = π/3）

  2. y = sinθ − cosθ の最大値
    答え

    √2 sin(θ − π/4) → 最大 √2

  3. y = 3 sinθ + 4 cosθ の最大値
    答え

    √(9 + 16) = 5 → 最大 5

解説の全文を読む
  1. こんにちは。知多丸の落ちこぼれ救済チャンネルです。難関大学に合格して、錯覚資産を手に入れて、一流企業に入社しよう。今日の問題は、ワイ は サイン シータ たす ルート3 コサイン シータ、シータ は 0 以上 2パイ 未満 のときの最大値と最小値、そのときの シータ を求めなさい。サインとコサインが混ざった式は、1つのサインにまとめるだけで終わります。
  2. 型はこれです。エー サイン シータ たす ビー コサイン シータ は、ルート エー2乗たすビー2乗 かける サイン かっこ シータ たす アルファ の形にまとめられます。振幅は ルート エー2乗たすビー2乗。アルファ は、コサイン アルファ が エー わる 振幅、サイン アルファ が ビー わる 振幅 になる角です。
  3. 手順1。振幅を出します。エー は 1、ビー は ルート3 なので、ルート かっこ 1 たす 3 は 2。よって ワイ は 2 かける サイン かっこ シータ たす アルファ。コサイン アルファ は 2分の1、サイン アルファ は 2分のルート3 なので、アルファ は 3分のパイ、つまり60度です。
  4. 手順2。中身の範囲を出します。シータ が 0 以上 2パイ 未満 なので、シータ たす 3分のパイ は、3分のパイ 以上 3分の7パイ 未満。この範囲でサインは、プラス1 から マイナス1 まですべて取れます。よって最大値は 2、最小値は マイナス2 です。
  5. 手順3。そのときの シータ を出します。サインが1になるのは、シータ たす 3分のパイ が 2分のパイ のとき。シータ は 2分のパイ ひく 3分のパイ で 6分のパイ。サインが マイナス1 になるのは、シータ たす 3分のパイ が 2分の3パイ のとき。シータ は 6分の7パイ です。
  6. 検算です。シータ が 6分のパイ のとき、サイン30度 は 2分の1、コサイン30度 は 2分のルート3。ワイ は 2分の1 たす ルート3 かける 2分のルート3 で、2分の1 たす 2分の3 は 2。最大値と一致しました。代入して確かめるのがいちばん速い検算です。
  7. 差がつく2行。1つめ。合成の角 アルファ は、点 かっこ エー、ビー を座標に取ったときの角です。今回は 点 かっこ 1、ルート3 なので60度。図で確認すれば符号をまちがえません。2つめ。コサインでまとめたいときは、コサイン かっこ シータ ひく アルファ の形にもできます。入試ではサインでまとめる形が標準です。
  8. おつかれさまでした。在庫に入れる1行は、これです。サインとコサインが混ざったら、ルート エー2乗たすビー2乗 でくくって1つのサインにする。明日、何も見ずに、ワイ は ルート3 サイン シータ たす コサイン シータ の最大値をやってみてください。答えは 2 です。チャンネル登録をして、次の動画でも一緒に、要領よく積み上げていきましょう。
