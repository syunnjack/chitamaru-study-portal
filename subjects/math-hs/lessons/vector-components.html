第76回　垂直と平行は「内積0」と「たすきがけ0」

a = (3, −1)、b = (t, 2) について、(1) 垂直になる t　(2) 平行になる t を求めよ。

条件はそれぞれ式1本で書けます。「垂直は足す、平行は引く」です（動画・音声解説つき）。

解法の型

垂直 ⇔ 内積 x₁x₂ + y₁y₂ = 0　／　平行 ⇔ x₁y₂ − x₂y₁ = 0

「垂直は足す、平行は引く」。平行は「一方が他方の実数倍」からも導けます。

解答手順

  1. (1) 内積を作る
    3 × t + (-1) × 2 = 3t - 2
  2. (1) の答え
    3t - 2 = 0 → t = 2/3
  3. (2) たすきがけ
    3 × 2 - t × (-1) = 6 + t

    斜めにかけて引く。順番を固定して覚えます。

  4. (2) の答え
    6 + t = 0 → t = -6

検算：t = 2/3 なら内積は 2 − 2 = 0 で垂直。t = −6 なら b = (−6, 2) = −2a となり、実数倍なので平行です。

差がつく2行

  1. 内積には「成分の積の和」と「|a||b|cos θ」の2つの顔があります。与えられた情報で使い分けます。
  2. 平行は b = ka と置いて成分を比べても解けます。たすきがけを忘れても導けます。

覚えるべきこと（在庫に入れる1行）

垂直は内積0（足す）、平行はたすきがけ0（引く）

類題（翌日、何も見ずに）

  1. a = (2, 3)、b = (t, −4) が垂直になる t
    答え

    2t − 12 = 0 → t = 6

  2. a = (2, 3)、b = (t, −4) が平行になる t
    答え

    2×(−4) − 3t = 0 → t = −8/3

  3. a = (3, −1) の大きさと、a に垂直な単位ベクトル
    答え

    |a| = √10。垂直なベクトルは (1, 3) なので (1/√10, 3/√10) と その逆向き
