第30回　ベクトルのなす角は「内積 ÷ 大きさの積」

a = (2, 1)、b = (1, 3) のなす角 θ を求めよ。

内積の2つの顔（成分と図形）をつなぐだけです（動画・音声解説つき）。

解法の型

成分：a・b = x₁x₂ + y₁y₂　／　図形：a・b = |a||b| cosθ

この2つを等号でつなぐと cosθ = (a・b) / (|a||b|)。

解答手順

  1. 内積と大きさ
    a・b = 2 × 1 + 1 × 3 = 5
    |a| = √5、|b| = √10
  2. cosθ を計算
    cosθ = 5 / √50 = 5 / (5√2) = 1/√2
    θ = 45°

検算：a の向きは約 26.6°、b の向きは約 71.6°。差が 45° で一致します。

差がつく2行

  1. 内積 = 0 なら垂直。(2, 1) と (−1, 2) は内積 0 なので垂直です。
  2. 内積が負なら鈍角、正なら鋭角。符号だけで 90° より大きいか小さいかが分かります。

覚えるべきこと（在庫に入れる1行）

cosθ = (a・b) / (|a||b|)

類題（翌日、何も見ずに）

  1. (1, 1) と (0, 2) のなす角
    答え

    内積 2、大きさ √2 と 2 → cosθ = 1/√2 → 45°

  2. (1, 2) と (−2, 1) のなす角
    答え

    内積 0 → 90°（垂直）

  3. (1, 0) と (−1, √3) のなす角
    答え

    内積 −1、大きさ 1 と 2 → cosθ = −1/2 → 120°
