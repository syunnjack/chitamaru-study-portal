第30回　ベクトルのなす角は「内積 ÷ 大きさの積」

a = (2, 1)、b = (1, 3) のなす角 θ を求めよ。

内積の2つの顔（成分と図形）をつなぐだけです（動画・音声解説つき）。

解法の型

成分：a・b = x₁x₂ + y₁y₂　／　図形：a・b = |a||b| cosθ

この2つを等号でつなぐと cosθ = (a・b) / (|a||b|)。

解答手順

  1. 内積と大きさ
    a・b = 2 × 1 + 1 × 3 = 5
    |a| = √5、|b| = √10
  2. cosθ を計算
    cosθ = 5 / √50 = 5 / (5√2) = 1/√2
    θ = 45°

検算：a の向きは約 26.6°、b の向きは約 71.6°。差が 45° で一致します。

差がつく2行

  1. 内積 = 0 なら垂直。(2, 1) と (−1, 2) は内積 0 なので垂直です。
  2. 内積が負なら鈍角、正なら鋭角。符号だけで 90° より大きいか小さいかが分かります。

覚えるべきこと（在庫に入れる1行）

cosθ = (a・b) / (|a||b|)

類題（翌日、何も見ずに）

  1. (1, 1) と (0, 2) のなす角
    答え

    内積 2、大きさ √2 と 2 → cosθ = 1/√2 → 45°

  2. (1, 2) と (−2, 1) のなす角
    答え

    内積 0 → 90°（垂直）

  3. (1, 0) と (−1, √3) のなす角
    答え

    内積 −1、大きさ 1 と 2 → cosθ = −1/2 → 120°

解説の全文を読む
  1. こんにちは。知多丸の落ちこぼれ救済チャンネルです。難関大学に合格して、錯覚資産を手に入れて、一流企業に入社しよう。今日の問題は、ベクトル エー が かっこ 2、1、ベクトル ビー が かっこ 1、3 のとき、2つのベクトルのなす角を求めなさい。ベクトルの角度は、成分で内積を出して、大きさで割るだけです。
  2. 型はこれです。内積には2つの顔があります。成分では、エックス成分の積 たす ワイ成分の積。図形では、大きさ かける 大きさ かける コサイン シータ。この2つを等号でつなぐと、コサイン シータ は 内積 わる 大きさの積 になります。
  3. 手順1。内積と大きさを出します。内積は、2 かける 1 たす 1 かける 3 で 5。エー の大きさは ルート かっこ 4 たす 1 で ルート5。ビー の大きさは ルート かっこ 1 たす 9 で ルート10。
  4. 手順2。コサイン シータ を計算します。5 わる かっこ ルート5 かける ルート10。分母は ルート50 で、これは 5ルート2。よって コサイン シータ は 5 わる 5ルート2 で ルート2分の1。これは 45度 です。
  5. 検算です。図で確かめます。ベクトル エー は 傾き 2分の1 の向き、ベクトル ビー は 傾き 3 の向き。角度はそれぞれ およそ 26.6度 と およそ 71.6度。差は 45度。一致しました。ベクトルの角度は、傾きの角の差でも確認できます。
  6. 差がつく2行。1つめ。内積が 0 なら垂直、これは最強の道具です。かっこ 2、1 と かっこ マイナス1、2 は内積 0 なので垂直です。2つめ。内積が負なら、なす角は鈍角。符号を見るだけで、90度より大きいか小さいかが分かります。
  7. おつかれさまでした。在庫に入れる1行は、これです。なす角は、内積を大きさの積で割る。明日、何も見ずに、かっこ 1、1 と かっこ 0、2 のなす角をやってみてください。答えは 45度 です。チャンネル登録をして、次の動画でも一緒に、要領よく積み上げていきましょう。
