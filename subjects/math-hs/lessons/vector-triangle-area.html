第77回　面積はベクトルなら「公式1本」

OA = (3, 1)、OB = (1, 4) のとき、△OAB の面積を求めよ。

角度を出す必要はありません。公式1本で終わります（動画・音声解説つき）。

解法の型

S = (1/2)√(|a|²|b|² − (a・b)²)　／　成分なら S = (1/2)|x₁y₂ − x₂y₁|

成分が分かっているなら「たすきがけの絶対値の半分」が最速。上の公式は大きさと内積しか分からないときに使います。

解答手順

  1. 必要な値を出す
    |a|² = 9 + 1 = 10、|b|² = 1 + 16 = 17、a・b = 3 + 4 = 7
  2. 公式に入れる
    S = (1/2)√(10 × 17 - 7²) = (1/2)√(170 - 49)
  3. ルートを外す
    = (1/2)√121 = (1/2) × 11 = 11/2

    121 = 11²。きれいな数になるよう作られています。

  4. 成分の公式で確認
    (1/2)|3×4 - 1×1| = (1/2)|11| = 11/2

    こちらのほうが速いので、実戦ではこれを使います。

検算：11/2 = 5.5 で、3点を囲む大きさとして妥当。内積が正なので鋭角、面積は (1/2)|a||b| ≒ 6.5 より小さいという条件も満たします。

差がつく2行

  1. 原点が頂点でなくても同じ。AB と AC の成分を作ってたすきがけするだけです。
  2. たすきがけの符号は3点の回り方（反時計回りなら正）。面積では絶対値をつけます。

覚えるべきこと（在庫に入れる1行）

S = (1/2)|x₁y₂ - x₂y₁|（たすきがけの半分）

類題（翌日、何も見ずに）

  1. OA = (2, 5)、OB = (4, 1) のときの △OAB の面積
    答え

    (1/2)|2×1 − 4×5| = (1/2)×18 = 9

  2. A(1, 1)、B(4, 2)、C(2, 5) の △ABC の面積
    答え

    AB = (3, 1)、AC = (1, 4) なので (1/2)|12 − 1| = 11/2

  3. |a| = 2、|b| = 3、a・b = 3 のときの三角形の面積
    答え

    (1/2)√(4×9 − 9) = (1/2)√27 = (3√3)/2
