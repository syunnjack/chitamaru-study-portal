中学数学

高校数学が分からない原因は、たいてい中学範囲の小さな穴です。全範囲をやり直す必要はありません。高校数学で毎回使うところだけを、先に埋めます。

この科目の攻略方針

  1. 穴の特定を先に。正負の計算・移項・分数の処理でミスが出るなら、そこだけ戻ります。
  2. 計算は速度より正確さ。1日10問を毎日、同じ形式で反復します。
  3. 関数は「グラフを描く」を必ずセットに。式だけで処理すると高校で詰まります。

正負の数の計算

(−3)² × (−2) + (−4)² ÷ (−8)。符号を先に決めて、数はあとで計算する型。

一次方程式の文章題

90円と60円を合わせて12個で840円。聞かれたものを x、もう一方を x で表す。

 第3回・動画あり

連立方程式（加減法）

2x + 3y = 12、3x − 2y = 5。そろえて、同符号なら引く・異符号なら足す。

2点 (1, 3) と (4, 9) を通る直線。傾きを出してから切片で y = 2x + 1。

三平方の定理

AB = 5、BC = 12 で AC = 13。斜辺は直角の向かい側、垂線は面積2通り。

 第6回・動画あり

y = ax² の変化の割合

y = 2x² で x が 1 から 4。変化の割合は a(p + q) で一撃、答えは 10。

 第7回・動画あり

円周角の定理

∠BOC = 116°、AB は直径。中心角の半分で 58°、直径なら 90°。

確率の数え上げ

2つのさいころで和が5の倍数。先に 36通り、答えは 7/36。

中を小さくしてから同じものだけ足す。√18 + √50 − √8 = 6√2、有理化まで。
