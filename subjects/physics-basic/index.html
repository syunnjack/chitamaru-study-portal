物理基礎

物理基礎は範囲が狭く、使う式も10本ほどしかありません。公式集を眺めるより、「この問い方ならこの式」の対応を動画で固定してしまうのが最短です。第1〜10回で力学・熱・波・電気の基本の型を、第11〜20回でグラフの読み取り・仕事・ばね・圧力と浮力・潜熱・回路・気柱・送電・半減期まで広げています。

この科目の攻略方針

  1. 力学は式3本＋つり合い。等加速度3本、力の分解、運動方程式、この3つで力学の大半が解けます。
  2. 熱・電気は式1本ずつ。熱は Q = mcΔt、電気は V = RI と P = VI。増やさないことが得点になります。
  3. 単位変換を先に済ませる。分→時間、g→kg、W→kW。計算に入る前に直す習慣で失点が消えます。

力学の型（第1〜5回）

第1回・動画あり

等加速度直線運動（式は3本で足りる）

速さ・距離・時間なしの3本を役割で使い分けます。a = 1.5 m/s²、x = 12 m。

 第2回・動画あり

斜面上の力のつり合い（分解は2方向だけ）

重力だけを mg sinθ と mg cosθ に分解。T = 9.8 N、N ≒ 17 N。

 第3回・動画あり

2物体の運動方程式（全体→片方）

全体で加速度、片方で張力。a = 2.0 m/s²、T = 4.0 N。

 第4回・動画あり

摩擦力（静止と動摩擦の切り替え）

f_max = μN と比べて判定。15 N では動かず、25 N なら a = 3.0 m/s²。

 第5回・動画あり

力学的エネルギー保存（高さと速さの交換）

v = √(2gΔh) で質量は消えます。5.9 m/s と 4.4 m/s。

もらった熱＝失った熱で t = 40 ℃。加重平均で検算できます。

 第7回・動画あり

音の速さと反射（やまびこの型）

反射は往復。距離408 m、波長0.80 m。音速は気温で決まります。

エネルギーの変換と効率（発電の計算）

効率＝出÷入で40 %、捨てられる熱は6.0×10^9 J。

熱・波・電気の応用（第16〜20回）

第16回・動画あり

状態変化と潜熱（区間で分ける）

融解 mL で1.68×10⁴ J、加熱 mcΔt で4.2×10³ J、合計2.1×10⁴ J。

 第17回・動画あり

直列と並列の合成抵抗（まとめる順番）

 第19回・動画あり

 第20回・動画あり

N = N₀(1/2)ⁿ。24日後は1/8、1/16になるのは32日後。
