第18回　気柱の共鳴（開管と閉管の違い）

音の速さを340 m/sとする。長さ0.50 mの開管が基本振動で共鳴するときの振動数を求めよ。また同じ長さの閉管（片側が閉じた管）が基本振動で共鳴するときの振動数を求めよ。

覚えるのは波長との関係2つだけ。あとは波の基本式に入れます。

解法の型

  1. 端の条件を図で確認。閉じた端は節、開いた端は腹。ここから波長が決まります。
  2. 基本振動の関係。開管は λ = 2L、閉管は λ = 4L。閉管の方が波長が長い＝音が低くなります。
  3. v = fλ で最後に変換。音速は管の長さや振動数では変わりません（気温で決まる）。

解答手順

  1. 開管の波長
    λ = 2L = 2 × 0.50 = 1.0 m

    両端が腹。

  2. 開管の振動数
    f = v/λ = 340/1.0 = 340 Hz

    v = fλ を f について解く。

  3. 閉管の波長と振動数
    λ = 4L = 2.0 m、f = 340/2.0 = 170 Hz

    閉じた端は節。

  4. 答えをまとめる
    開管 340 Hz、閉管 170 Hz（ちょうど半分）

    閉管は1オクターブ低い。

検算：閉管の波長は2倍なので振動数は半分。340 ÷ 2 = 170 Hz と整合します。

差がつく2行

  1. 管を短くすると波長が短くなり、振動数が上がります。笛の音程が変わるのはこの効果です。
  2. 音速は気温で決まります（V = 331.5 + 0.6t）。気温が上がると同じ管でも音が高くなります。

覚えるべきこと（在庫に入れる1行）

開管は λ = 2L、閉管は λ = 4L。あとは v = fλ。

類題（翌日、何も見ずに）

  1. 長さ0.25 mの閉管の基本振動の振動数を求めよ（v = 340 m/s）。
    答え

    λ = 1.0 m、f = 340 Hz

  2. 長さ1.0 mの開管の2倍振動の振動数を求めよ（v = 340 m/s）。
    答え

    λ = 1.0 m、f = 340 Hz

動画の音声ナレーション

解説の全文を読む
  1. こんにちは。知多丸の落ちこぼれ救済チャンネルです。難関大学に合格して、錯覚資産を手に入れて、一流企業に入社しよう。今日の問題です。音の速さを毎秒340メートルとします。長さ0.50メートルの開管が基本振動で共鳴するときの振動数を求めてください。また、同じ長さの閉管、つまり片側が閉じた管が基本振動で共鳴するときの振動数も求めてください。
  2. 型はこうです。気柱の問題は、管の長さと波長の関係を先に決めます。開管の基本振動は、管の長さが波長の2分の1。閉管の基本振動は、管の長さが波長の4分の1です。波長が決まったら、あとは波の基本式 ブイ イコール エフ ラムダ で振動数に直すだけ。図をかいて、閉じた端が動かない節、開いた端が大きく揺れる腹、と確認すれば迷いません。
  3. まず開管です。両端が腹になるので、管の長さは波長の2分の1。波長は1.0メートルです。
  4. 振動数は、340を1.0で割って340ヘルツです。
  5. 次に閉管です。閉じた端が節、開いた端が腹になるので、管の長さは波長の4分の1。波長は2.0メートルで、振動数は170ヘルツです。
  6. 答えは、開管が340ヘルツ、閉管が170ヘルツです。閉管は開管のちょうど半分の振動数、つまり1オクターブ低い音になります。
  7. 検算です。同じ長さなら、閉管の波長は開管の2倍。振動数は波長の逆数に比例するので、ちょうど半分になるはずです。340の半分は170。答えの関係と一致します。
  8. 差がつく2行です。ひとつ目、管を短くすると音は高くなります。波長が短くなり振動数が上がるからで、笛の穴を押さえる位置で音が変わるのはこの理由です。ふたつ目、気温が上がると音速が上がるので、同じ管でも振動数が上がります。管楽器が暖まると音が高くなるのは、これが原因です。
  9. 在庫に入れる1行です。開管は ラムダ イコール 2 エル、閉管は ラムダ イコール 4 エル。あとは ブイ イコール エフ ラムダ。チャンネル登録をして、次の動画でも一緒に、要領よく積み上げていきましょう。
