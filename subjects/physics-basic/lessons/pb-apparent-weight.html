第12回　エレベーターの中の体重計（見かけの重さ）

質量50 kgの人が体重計に乗ってエレベーターに乗っている。エレベーターが上向きに1.2 m/s²で加速しているとき、体重計の示す力を求めよ。また下向きに1.2 m/s²で加速しているときはどうなるか（g = 9.8 m/s²）。

体重計は重力を測っていません。押し返す力を測っています。ここを直すだけで解けます。

解法の型

  1. 体重計は垂直抗力を表示する。「重さ」ではなく N を求める問題だと読み替えます。
  2. 注目するのは人だけ。人に働く力は重力 mg（下）と垂直抗力 N（上）の2つです。
  3. N − mg = ma を1本。a の符号を入れれば、加速・減速・等速すべてこの1本で足ります。

解答手順

  1. 静止時の値を出す
    mg = 50 × 9.8 = 490 N

    基準の値を先に持つ。

  2. 上向き加速のとき
    N − 490 = 50 × 1.2 → N = 550 N

    重力より大きくなる。

  3. 下向き加速のとき
    N − 490 = 50 × (−1.2) → N = 430 N

    a に負の符号を入れるだけ。

  4. 答えをまとめる
    上向き加速：550 N、下向き加速：430 N

    差はどちらも 60 N。

検算：ずれは ma = 60 N。490 ± 60 で 550 N と 430 N。上下で対称にずれることを確認します。

差がつく2行

  1. 上昇中はずっと重い、ではありません。等速で上がっている間は静止時と同じ 490 N です。
  2. a = −g のとき N = 0。宇宙ステーションの無重力も、同じ「自由落下している」状態です。

覚えるべきこと（在庫に入れる1行）

体重計は N を示す。N − mg = ma の1本で、上向き加速なら重く、下向き加速なら軽い。

類題（翌日、何も見ずに）

  1. 質量40 kgの人が上向きに2.0 m/s²で加速するエレベーターに乗るときの体重計の値を求めよ（g = 9.8）。
    答え

    N = 40×(9.8 + 2.0) = 472 N

  2. 等速で下降するエレベーターの中で体重計の値はどうなるか。
    答え

    a = 0 なので N = mg（静止時と同じ）
