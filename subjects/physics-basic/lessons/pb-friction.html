第4回　摩擦力（静止と動摩擦の切り替え）

質量5.0 kgの物体が水平な床の上にある。静止摩擦係数0.40、動摩擦係数0.20、g = 9.8 m/s²とする。水平に15 Nの力を加えたとき物体は動くか。動く場合、その加速度を求めよ。

摩擦の失点はほぼ全部、静止摩擦と動摩擦の取り違えです。判定を先に置きます。

解法の型

  1. 判定が先。最大摩擦力 f_max = μN を出し、加えた力 F と比べます。F ≤ f_max なら静止、F > f_max なら動きます。
  2. 静止しているときの摩擦力は μN ではない。加えた力とつり合う値（F と同じ大きさ）です。μN はあくまで上限です。
  3. 動き出したら動摩擦 μ'N に切り替える。動摩擦は速さによらず一定です。

解答手順

  1. 垂直抗力を出す
    N = mg = 5.0 × 9.8 = 49 N

    水平面なので N = mg。

  2. 最大摩擦力と比べる
    f_max = 0.40 × 49 = 19.6 N > 15 N

    加えた力の方が小さい。

  3. 動くかどうか答える
    15 N < 19.6 N なので物体は動かない（静止）

    このときの摩擦力は15 N。

  4. 動かすにはいくら必要か
    F > 19.6 N。例えば25 N なら a = (25 − 0.20×49)/5.0 = 3.0 m/s²

    動いたら動摩擦に切替。

検算：静止時の上限19.6 N が動摩擦9.8 N より大きい、という順序を確認します。逆になったら係数の取り違えです。

差がつく2行

  1. 静止摩擦力は「μN」ではなく、加えた力とつり合う大きさです。μN は動き出す直前の上限値だけを表します。
  2. 斜め上向きに引くと N = mg − F sinθ になり、摩擦も小さくなります。Nを先に求める習慣をつけます。

覚えるべきこと（在庫に入れる1行）

摩擦は「判定 → 切り替え」。f_max = μN と比べ、動いたら μ'N。

類題（翌日、何も見ずに）

  1. 質量2.0 kg、静止摩擦係数0.50の物体に水平に8.0 Nを加えたとき動くか（g = 9.8）。
    答え

    f_max = 9.8 N > 8.0 N なので動かない

  2. 質量4.0 kgの物体が動摩擦係数0.25の床を滑るときの減速の加速度を求めよ（g = 9.8）。
    答え

    a = −0.25×9.8 = −2.5 m/s²
