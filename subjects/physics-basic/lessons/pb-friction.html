第4回　摩擦力（静止と動摩擦の切り替え）

質量5.0 kgの物体が水平な床の上にある。静止摩擦係数0.40、動摩擦係数0.20、g = 9.8 m/s²とする。水平に15 Nの力を加えたとき物体は動くか。動く場合、その加速度を求めよ。

摩擦の失点はほぼ全部、静止摩擦と動摩擦の取り違えです。判定を先に置きます。

解法の型

  1. 判定が先。最大摩擦力 f_max = μN を出し、加えた力 F と比べます。F ≤ f_max なら静止、F > f_max なら動きます。
  2. 静止しているときの摩擦力は μN ではない。加えた力とつり合う値（F と同じ大きさ）です。μN はあくまで上限です。
  3. 動き出したら動摩擦 μ'N に切り替える。動摩擦は速さによらず一定です。

解答手順

  1. 垂直抗力を出す
    N = mg = 5.0 × 9.8 = 49 N

    水平面なので N = mg。

  2. 最大摩擦力と比べる
    f_max = 0.40 × 49 = 19.6 N > 15 N

    加えた力の方が小さい。

  3. 動くかどうか答える
    15 N < 19.6 N なので物体は動かない（静止）

    このときの摩擦力は15 N。

  4. 動かすにはいくら必要か
    F > 19.6 N。例えば25 N なら a = (25 − 0.20×49)/5.0 = 3.0 m/s²

    動いたら動摩擦に切替。

検算：静止時の上限19.6 N が動摩擦9.8 N より大きい、という順序を確認します。逆になったら係数の取り違えです。

差がつく2行

  1. 静止摩擦力は「μN」ではなく、加えた力とつり合う大きさです。μN は動き出す直前の上限値だけを表します。
  2. 斜め上向きに引くと N = mg − F sinθ になり、摩擦も小さくなります。Nを先に求める習慣をつけます。

覚えるべきこと（在庫に入れる1行）

摩擦は「判定 → 切り替え」。f_max = μN と比べ、動いたら μ'N。

類題（翌日、何も見ずに）

  1. 質量2.0 kg、静止摩擦係数0.50の物体に水平に8.0 Nを加えたとき動くか（g = 9.8）。
    答え

    f_max = 9.8 N > 8.0 N なので動かない

  2. 質量4.0 kgの物体が動摩擦係数0.25の床を滑るときの減速の加速度を求めよ（g = 9.8）。
    答え

    a = −0.25×9.8 = −2.5 m/s²

解説の全文を読む
  1. こんにちは。知多丸の落ちこぼれ救済チャンネルです。難関大学に合格して、錯覚資産を手に入れて、一流企業に入社しよう。今日の問題です。質量5.0キログラムの物体が水平な床の上にあります。静止摩擦係数は0.40、動摩擦係数は0.20、重力加速度は毎秒毎秒9.8メートルです。水平に15ニュートンの力を加えたとき、物体は動くでしょうか。動く場合は、その加速度も求めてください。
  2. 型はこうです。摩擦の問題は、必ず判定から始めます。まず最大摩擦力、ミュー かける 垂直抗力 を計算します。次に加えた力と比べて、加えた力が大きければ動きます。動いた瞬間から摩擦は動摩擦に切り替わり、ミュープライム かける 垂直抗力 になります。判定を飛ばして計算に入ると、必ずどちらかの摩擦を間違えます。
  3. まず垂直抗力です。水平な床なので重力と等しく、5.0かける9.8で49ニュートンです。
  4. 次に最大摩擦力です。0.40かける49で19.6ニュートン。加えた15ニュートンより大きいので、この力では動きません。
  5. したがって物体は動きません。このとき働いている摩擦力は、最大値の19.6ニュートンではなく、加えた力とつり合う15ニュートンです。
  6. もし19.6ニュートンを超える力、たとえば25ニュートンを加えると動き出します。そのときの摩擦は動摩擦で、0.20かける49の9.8ニュートン。運動方程式から、25ひく9.8を5.0で割って、加速度は毎秒毎秒3.0メートルです。
  7. 検算です。静止摩擦係数の方が動摩擦係数より大きいので、動き出す前が19.6ニュートン、動き出した後が9.8ニュートン。動き始めると急に軽くなるという体感どおりの順序になっています。数値の大小関係が逆なら、係数を取り違えています。
  8. 差がつく2行です。ひとつ目、静止しているときの摩擦力はミューエヌではありません。ミューエヌは上限で、実際の値は加えた力と同じです。ふたつ目、垂直抗力は必ず先に求めます。斜めに引く問題では垂直抗力自体が変わるので、ここを固定すると失点します。
  9. 在庫に入れる1行です。摩擦は判定してから切り替え。最大摩擦力 ミューエヌ と比べて、動いたら ミュープライム エヌ。チャンネル登録をして、次の動画でも一緒に、要領よく積み上げていきましょう。
