第6回　熱量の保存（比熱と熱平衡の1本）

20 ℃の水200 gに、80 ℃の水100 gを混ぜた。外部との熱のやりとりがないとき、混合後の温度を求めよ。

熱の問題は式が1本しかありません。何を t とおくかだけを決めます。

解法の型

  1. Q = mcΔt。Δt は必ず「大きい方 − 小さい方」で正にして扱います。
  2. もらった熱 = 失った熱。混合後の温度を t とおき、両辺に t を含む式を1本書きます。
  3. 同じ物質どうしなら比熱は消える。水と水の混合では c が両辺にあるので約分できます。

解答手順

  1. 求める温度を文字でおく
    混合後の温度を t（20 < t < 80）

    範囲を先に書いておく。

  2. もらった熱と失った熱
    200c(t − 20) = 100c(80 − t)

    比熱cは両辺で消える。

  3. 式を解く
    2(t − 20) = 80 − t → 3t = 120 → t = 40 ℃

    係数は質量の比だけ。

  4. 答えをまとめる
    混合後の温度は 40 ℃

    20 < 40 < 80 を満たす。

検算：加重平均 (200×20 + 100×80)/300 = 40 ℃ と一致。質量の多い20 ℃側に近づくのも正しい傾向です。

差がつく2行

  1. 混合後の温度は単純平均ではありません。質量の加重平均になり、重い方の温度に引き寄せられます。
  2. 熱容量 C = mc は「その物体全体を1 K上げる熱量」。比熱は1 gあたりの値で、別物です。

覚えるべきこと（在庫に入れる1行）

熱は Q = mcΔt。混合は「もらった熱 = 失った熱」の1本。

類題（翌日、何も見ずに）

  1. 10 ℃の水300 gと70 ℃の水100 gを混ぜたときの温度を求めよ。
    答え

    (300×10 + 100×70)/400 = 25 ℃

  2. 比熱0.45 J/(g·K)の鉄200 gを20 ℃上げるのに必要な熱量を求めよ。
    答え

    Q = 200×0.45×20 = 1800 J
