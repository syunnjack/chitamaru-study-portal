第2回　斜面上の力のつり合い（分解は2方向だけ）

質量2.0 kgの物体が、水平面と30°をなすなめらかな斜面上で、斜面に平行な糸で静止している。糸の張力と、斜面が物体を押す垂直抗力を求めよ（g = 9.8 m/s²）。

斜面がこわいのは、座標を水平・鉛直でとっているからです。座標を斜面に合わせます。

解法の型

  1. 座標は斜面に合わせる。「斜面に平行」と「斜面に垂直」の2方向にとると、分解するのは重力だけになります。
  2. sin と cos の判別。斜面に平行な成分は mg sinθ、垂直な成分は mg cosθ。θが小さいほど滑りにくい＝sin側が小さいと確認します。
  3. 各方向で合計 = 0。静止＝つり合い。方向ごとに1本ずつ式を書きます。

解答手順

  1. 重力を分解する
    斜面方向：mg sin30° ／ 垂直方向：mg cos30°

    mg = 2.0 × 9.8 = 19.6 N。

  2. 斜面方向のつり合い
    T = mg sin30° = 19.6 × 0.50 = 9.8 N

    糸は斜面方向のみを支える。

  3. 垂直方向のつり合い
    N = mg cos30° = 19.6 × 0.87 ≒ 17 N

    cos30° = √3/2 ≒ 0.87。

  4. 答えをまとめる
    T = 9.8 N、N ≒ 17 N

    2方向で1本ずつ、計2本。

検算：sin30° = 1/2 なので T は mg の半分の 9.8 N。また N は必ず mg より小さくなり、17 N < 19.6 N を満たします。

差がつく2行

  1. 垂直抗力は「重力と同じ」ではありません。斜面では N = mg cosθ で、必ず mg より小さくなります。
  2. sinかcosか迷ったら θ = 0（平ら）を代入。斜面方向の力は0になるはずなので、そちらがsinです。

覚えるべきこと（在庫に入れる1行）

斜面は斜面方向 mg sinθ、垂直方向 mg cosθ。座標を斜面に合わせる。

類題（翌日、何も見ずに）

  1. 質量3.0 kgの物体を60°のなめらかな斜面で斜面に平行な糸で支えるとき、張力を求めよ（g = 9.8）。
    答え

    T = 3.0×9.8×sin60° ≒ 25 N

  2. 30°の斜面上で質量2.0 kgの物体を静止させるのに必要な水平方向の力を求めよ（g = 9.8）。
    答え

    F = mg tan30° ≒ 11 N

解説の全文を読む
  1. こんにちは。知多丸の落ちこぼれ救済チャンネルです。難関大学に合格して、錯覚資産を手に入れて、一流企業に入社しよう。今日の問題です。質量2.0キログラムの物体が、水平面と30度をなす、なめらかな斜面の上で、斜面に平行な糸で静止しています。糸の張力と、斜面が物体を押す垂直抗力を求めてください。重力加速度は毎秒毎秒9.8メートルとします。
  2. 型はこうです。斜面の問題は、水平と鉛直ではなく、斜面に平行な方向と斜面に垂直な方向の2方向に分けます。分解するのは重力だけで、斜面方向が エムジー サイン シータ、垂直方向が エムジー コサイン シータ。あとは各方向でつり合いの式、合計ゼロを書くだけです。
  3. まず重力を分解します。重力の大きさは2.0かける9.8で19.6ニュートン。斜面方向の成分が19.6かけるサイン30度、斜面に垂直な成分が19.6かけるコサイン30度です。
  4. 斜面方向のつり合いです。糸の張力が重力の斜面方向成分とつり合うので、ティー イコール 19.6かける0.50で9.8ニュートンです。
  5. 斜面に垂直な方向のつり合いです。垂直抗力が重力の垂直成分とつり合うので、19.6かけるコサイン30度、およそ17ニュートンです。
  6. 答えは、張力が9.8ニュートン、垂直抗力がおよそ17ニュートンです。
  7. 検算です。斜面が30度なので、斜面方向の成分は重力のちょうど半分になるはずです。19.6の半分は9.8。張力の答えと一致しています。また垂直抗力は重力より小さく、19.6ニュートンを超えていないので、大きさの感覚も合っています。
  8. 差がつく2行です。ひとつ目、垂直抗力は重力と等しいと思い込みがちですが、斜面では必ず重力より小さくなります。ふたつ目、サインとコサインの見分けは、角度をゼロにして考えます。斜面が平らなら滑らないので、斜面方向の成分はゼロになるはず。サインゼロがゼロなので、斜面方向はサインだと決まります。
  9. 在庫に入れる1行です。斜面は座標を斜面に合わせて、斜面方向が エムジー サイン シータ、垂直方向が エムジー コサイン シータ。チャンネル登録をして、次の動画でも一緒に、要領よく積み上げていきましょう。
