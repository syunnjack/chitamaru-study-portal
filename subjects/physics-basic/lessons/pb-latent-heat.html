第16回　状態変化と潜熱（温度が上がらない区間）

0 ℃の氷50 gをすべて0 ℃の水にするのに必要な熱量を求めよ。さらにその水を20 ℃まで上げるのに必要な熱量を求め、合計を答えよ（氷の融解熱336 J/g、水の比熱4.2 J/(g·K)）。

加熱曲線の水平な部分だけ、式が違います。区間で分けて足します。

解法の型

  1. 区間で分ける。温度変化の区間と状態変化の区間を分け、それぞれの熱量を足します。
  2. 状態変化中は温度一定。グラフの水平部分では Q = mL を使い、Δt は使いません。
  3. 単位をそろえる。融解熱は J/g、比熱は J/(g·K)。質量はgのままでよいか確認します。

解答手順

  1. 融解の熱量
    Q₁ = mL = 50 × 336 = 16800 J

    温度は0 ℃のまま。

  2. 加熱の熱量
    Q₂ = mcΔt = 50 × 4.2 × 20 = 4200 J

    水になってから温度が上がる。

  3. 合計を出す
    Q = 16800 + 4200 = 21000 J = 2.1×10⁴ J

    区間ごとに足すだけ。

  4. 答えをまとめる
    Q₁ = 1.68×10⁴ J、Q₂ = 4.2×10³ J、合計 2.1×10⁴ J

    潜熱の方が大きい。

検算：融解熱336 J/g は水を80 ℃上げる分に相当。今回は20 ℃なので融解が4倍大きく、16800 = 4200 × 4 と整合します。

差がつく2行

  1. −10 ℃の氷からなら、氷の比熱で0 ℃まで上げる区間が最初に加わります。区間の数を先に数えます。
  2. 潜熱の区間で温度が上がらないのは、熱が結合を切る仕事に使われるためです。エネルギーは保存しています。

覚えるべきこと（在庫に入れる1行）

温度変化は mcΔt、状態変化は mL。区間で分けて足す。

類題（翌日、何も見ずに）

  1. 100 ℃の水30 gをすべて水蒸気にする熱量を求めよ（蒸発熱2260 J/g）。
    答え

    Q = 30×2260 = 67800 J

  2. 氷の比熱2.1 J/(g·K)のとき、−20 ℃の氷100 gを0 ℃にする熱量を求めよ。
    答え

    Q = 100×2.1×20 = 4200 J
