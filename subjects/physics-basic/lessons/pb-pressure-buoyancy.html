第15回　圧力と浮力（深さと押しのけた体積）

水の密度を1.0×10³ kg/m³、g = 9.8 m/s²、大気圧を1.0×10⁵ Paとする。水面から2.0 mの深さでの圧力を求めよ。また体積5.0×10⁻⁴ m³の物体を完全に水に沈めたときの浮力を求めよ。

圧力は深さだけ、浮力は体積だけ。見るところを1つに絞ります。

解法の型

  1. 圧力は深さだけ。p = p₀ + ρgh。同じ深さなら、細い管でも広い池でも同じ圧力です。
  2. 浮力は押しのけた液体の重さ。F = ρVg の V は「水中にある部分の体積」です。
  3. 単位をmとkgに直す。cmやgのままだと桁が必ず狂います。

解答手順

  1. 水柱の圧力を出す
    ρgh = 1.0×10³ × 9.8 × 2.0 = 1.96×10⁴ Pa

    深さ2.0 m分の圧力。

  2. 大気圧を足す
    p = 1.0×10⁵ + 1.96×10⁴ ≒ 1.2×10⁵ Pa

    水面でも大気圧がかかる。

  3. 浮力を出す
    F = ρVg = 1.0×10³ × 5.0×10⁻⁴ × 9.8 = 4.9 N

    押しのけた水の重さ。

  4. 答えをまとめる
    p ≒ 1.2×10⁵ Pa、F = 4.9 N

    圧力はPa、浮力はN。

検算：押しのけた水は0.50 kg、その重さは4.9 N。浮力と一致します（アルキメデスの原理）。

差がつく2行

  1. 浮力は物体の重さによりません。同じ体積の鉄と木は同じ浮力を受け、沈むかどうかは重力との比較で決まります。
  2. 圧力 p = p₀ + ρgh に体積は入りません。深さが同じなら容器の形や水量に関係なく同じ値です。

覚えるべきこと（在庫に入れる1行）

圧力 p = p₀ + ρgh（深さのみ）、浮力 F = ρVg（水中部分の体積）。

類題（翌日、何も見ずに）

  1. 水面から5.0 mの深さでの水による圧力を求めよ（ρ = 1.0×10³、g = 9.8）。
    答え

    4.9×10⁴ Pa（大気圧を除く）

  2. 体積2.0×10⁻³ m³の物体を半分だけ水に沈めたときの浮力を求めよ。
    答え

    F = 1.0×10³ × 1.0×10⁻³ × 9.8 = 9.8 N

解説の全文を読む
  1. こんにちは。知多丸の落ちこぼれ救済チャンネルです。難関大学に合格して、錯覚資産を手に入れて、一流企業に入社しよう。今日の問題です。水の密度を、立方メートルあたり1.0かける10の3乗キログラム、重力加速度を毎秒毎秒9.8メートル、大気圧を1.0かける10の5乗パスカルとします。水面から2.0メートルの深さでの圧力を求めてください。また、体積5.0かける10のマイナス4乗立方メートルの物体を完全に水に沈めたときの浮力も求めてください。
  2. 型はこうです。水中の圧力は、大気圧に ロー ジー エイチ を足すだけ。深さだけで決まり、容器の形や水の量には関係しません。浮力は、押しのけた液体の重さ、つまり ロー ブイ ジー です。ブイは物体の体積ではなく、水に入っている部分の体積。完全に沈めたときだけ、両者が一致します。
  3. まず水の分の圧力です。密度かける重力加速度かける深さで、1.96かける10の4乗パスカルです。
  4. 水面には大気圧がかかっているので、これを足します。合計はおよそ1.2かける10の5乗パスカルです。
  5. 浮力は、押しのけた水の重さです。密度かける体積かける重力加速度で、4.9ニュートンです。
  6. 答えは、深さ2.0メートルでの圧力がおよそ1.2かける10の5乗パスカル、浮力が4.9ニュートンです。
  7. 検算です。押しのけた水の質量は、密度かける体積で0.50キログラム。その重さは0.50かける9.8で4.9ニュートン。浮力の答えと一致します。浮力とは押しのけた水の重さそのものだ、という意味も確認できます。
  8. 差がつく2行です。ひとつ目、浮力は物体の重さや材質には関係ありません。同じ体積なら、鉄でも木でも浮力は同じです。浮くか沈むかは、浮力と重力の大小で決まります。ふたつ目、圧力は水の量ではなく深さで決まります。同じ深さなら、バケツの水でもプールの水でも同じ圧力です。
