第20回　放射線と半減期（原子力と被ばくの見方）

ある放射性同位体の半減期は8.0日である。はじめの原子核の数を N₀ とするとき、24日後に残っている原子核の数を求めよ。またはじめの1/16になるのは何日後か。

半減期の計算は、割り算1回と「半分を何回」だけです。

解法の型

  1. 回数を数える。n = 経過時間 ÷ 半減期。まずこの整数を出します。
  2. N = N₀(1/2)ⁿ。1/2、1/4、1/8、1/16 …と半分ずつ減ります。
  3. 放射線の正体。α線＝ヘリウム原子核、β線＝電子、γ線＝電磁波。透過力は α < β < γ。

解答手順

  1. 回数を数える
    n = 24 ÷ 8.0 = 3（回）

    経過時間 ÷ 半減期。

  2. 残る数を出す
    N = N₀ × (1/2)³ = N₀/8

    半分を3回。

  3. 1/16になる時間
    (1/2)⁴ = 1/16 なので n = 4 → 8.0 × 4 = 32日後

    回数から時間へ。

  4. 答えをまとめる
    24日後：N₀/8、1/16になるのは32日後

    半分ずつ減るだけ。

検算：8日ごとに 1/2 → 1/4 → 1/8 → 1/16。24日で1/8、32日で1/16 と一致します。

差がつく2行

  1. 半減期を2回過ぎても全部なくなりません。1/4が残り、以後も半分ずつ減っていきます。
  2. 放射能＝放射線を出す能力（Bq）、放射線＝出てくるもの、被ばくの影響の量はシーベルト（Sv）で表します。

覚えるべきこと（在庫に入れる1行）

半減期は N = N₀(1/2)ⁿ、n = 経過時間 ÷ 半減期。α＝He核、β＝電子、γ＝電磁波。

類題（翌日、何も見ずに）

  1. 半減期5.0年の物質が1/8になるのは何年後か。
    答え

    n = 3 なので15年後

  2. 半減期2.0時間の物質が6.0時間後に残る割合を求めよ。
    答え

    (1/2)³ = 1/8

解説の全文を読む
  1. こんにちは。知多丸の落ちこぼれ救済チャンネルです。難関大学に合格して、錯覚資産を手に入れて、一流企業に入社しよう。今日の問題です。ある放射性同位体の半減期は8.0日です。はじめの原子核の数をエヌゼロとするとき、24日後に残っている原子核の数を求めてください。また、はじめの16分の1になるのは何日後かも求めてください。
  2. 型はこうです。半減期の計算は、まず半減期が何回分たったかを数えます。エヌ イコール エヌゼロ かける 2分の1 の エヌ乗。この エヌ は、経過時間を半減期で割った回数です。逆に、何分の1になるかから エヌ を読み取ることもできます。放射線の種類は、アルファ線がヘリウムの原子核、ベータ線が電子、ガンマ線が電磁波。この3行だけ持っておけば足ります。
  3. まず半減期が何回分かを数えます。24日を8.0日で割って3回です。
  4. 残っている数は、エヌゼロかける2分の1の3乗で、8分の1エヌゼロです。
  5. 16分の1は2分の1の4乗なので、回数は4回。8.0日かける4で、32日後です。
  6. 答えは、24日後に8分の1、16分の1になるのは32日後です。
  7. 検算です。8日ごとに順に書き出してみます。8日で2分の1、16日で4分の1、24日で8分の1、32日で16分の1。表にすると、どちらの答えも一致していることが確認できます。
  8. 差がつく2行です。ひとつ目、半減期は「全部なくなる時間の半分」ではありません。半分に減る時間で、これを繰り返してもゼロにはなりません。ふたつ目、放射能と放射線と放射性物質は別の言葉です。放射線を出す能力が放射能、出てくるものが放射線、それを含む物質が放射性物質。用語を区別する設問がよく出ます。
  9. 在庫に入れる1行です。半減期は エヌ イコール エヌゼロ かける 2分の1 の エヌ乗、エヌ は 経過時間 割る 半減期。アルファはヘリウム核、ベータは電子、ガンマは電磁波。チャンネル登録をして、次の動画でも一緒に、要領よく積み上げていきましょう。
