第17回　直列と並列の合成抵抗（電流の分かれ方）

6.0 Ωと3.0 Ωの抵抗を並列につなぎ、その組み合わせに4.0 Ωの抵抗を直列につないで12 Vの電池につないだ。全体の合成抵抗と、電池を流れる電流を求めよ。

複雑な回路も、内側の並列からまとめれば3行で終わります。

解法の型

  1. 内側の並列から。並列部分を1本の抵抗にまとめて回路を書き直します。
  2. 2本の並列は積÷和。R = R₁R₂/(R₁+R₂) で、必ず小さい方の抵抗より小さくなります。
  3. 最後に直列を足して V = RI。全体の電流はここで1回だけ求めます。

解答手順

  1. 並列部分をまとめる
    R₁₂ = (6.0 × 3.0)/(6.0 + 3.0) = 18/9 = 2.0 Ω

    積÷和が速い。

  2. 直列で足す
    R = 2.0 + 4.0 = 6.0 Ω

    並列をまとめてから足す。

  3. 電流を出す
    I = V/R = 12/6.0 = 2.0 A

    全体でオームの法則。

  4. 分かれた電流も見る
    並列部分の電圧 = 2.0 × 2.0 = 4.0 V → 6.0 Ω に0.67 A、3.0 Ω に1.33 A

    抵抗が小さい方に多く流れる。

検算：分かれた電流の和が2.0 A、電圧の和が8.0 + 4.0 = 12 V。どちらも電池の値と一致します。

差がつく2行

  1. 並列の答えが最小の抵抗より大きくなったら計算違いです。逆数の足し算を見直します。
  2. 並列は電圧が共通、直列は電流が共通。これを言えるようになれば、回路の設問は半分終わりです。

覚えるべきこと（在庫に入れる1行）

直列は足す、並列は積÷和。並列は電圧共通、直列は電流共通。

類題（翌日、何も見ずに）

  1. 4.0 Ωと4.0 Ωを並列にしたときの合成抵抗を求めよ。
    答え

    R = 16/8 = 2.0 Ω

  2. 2.0 Ωと3.0 Ωを直列にして10 Vをかけたときの電流と2.0 Ωの電圧を求めよ。
    答え

    I = 2.0 A、V = 4.0 V
