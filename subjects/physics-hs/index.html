高校物理

物理は公式を覚えても点になりません。「この状況ならこの式を立てる」という手順を固定化すると、急に安定します。

この科目の攻略方針

  1. まず図。力を書き込む順番（重力→垂直抗力→摩擦→張力）を毎回同じにします。
  2. 立式は保存則から考える。運動方程式で解くか、エネルギー・運動量保存で解くかの判断基準を持ちます。
  3. 単位で検算。式の次元が合うかを最後に必ず確認します。

力学の型（第1〜5回）

第1回・動画あり

斜面上のつり合い（力の書き込み順）

重力→垂直抗力→摩擦→張力の順に書き、軸を斜面に合わせて重力だけ分解。

 第2回・動画あり

運動方程式（2物体と糸の張力）

全体で加速度を出し、1物体を切り出して張力。内力は全体の式に出ません。

 第3回・動画あり

鉛直投げ上げ（等加速度の3公式）

上向き正で a = −g、最高点は v = 0。時間なしの公式で検算します。

 第4回・動画あり

力学的エネルギー保存（なめらかな曲面）

なめらかなら mgh = mv²/2。質量は消えて v = √(2gh) です。

 第5回・動画あり

運動量保存と非弾性衝突

運動量は保存、一体化ならエネルギーは減少。差が熱になります。

円運動・熱・電気の型（第6〜10回）

第6回・動画あり

等速円運動（向心力の立式）

a = v²/r、F = mv²/r。向心力は実在する力の合力です。

 第7回・動画あり

ばね振り子の単振動（周期と最大速さ）

ω = √(k/m) を先に。T = 2π/ω、v = Aω、a = Aω²。

 第8回・動画あり

熱量の計算（比熱と電力）

Q = mcΔT、電熱器なら Pt = mcΔT。単位をそろえて代入します。

 第9回・動画あり

直流回路（合成抵抗と電圧の分配）

並列を先に合成、全電流を出して RI で各部分に戻します。

 第10回・動画あり

電磁誘導（導体棒に生じる起電力）

V = BLv → I = V/R → F = BIL。向きは運動を妨げる向きです。

波の型（第11〜15回）

第11回・動画あり

波の基本式（v = fλ の使い分け）

v = fλ と T = 1/f の2本だけ。f は波源、v は媒質が決めます。

 第12回・動画あり

弦の固有振動（基本振動から数える）

λ₁ = 2L → f₁ = v/λ₁ → n倍。図から波長を出せば崩れません。

 第13回・動画あり

ドップラー効果（音源が近づく場合）

分子は観測者・分母は音源。最後に「高い／低い」で必ず検算します。

 第14回・動画あり

屈折の法則と全反射（臨界角）

n₁sinθ₁ = n₂sinθ₂ の1本。全反射は密→疎のときだけ起こります。

 第15回・動画あり

ヤングの実験（明線の間隔）

Δx = Lλ/d。代入前に単位をmへ。答えは数mmになるのが普通です。

電気・原子の型（第16〜20回）

第16回・動画あり

クーロンの法則と電場（力と電場の橋渡し）

力は2電荷の積、電場は1電荷だけ。F = qE でつなげば混ざりません。

 第17回・動画あり

コンデンサーの直列接続（電気量が共通）

直列はQが共通。1/C = 1/C₁ + 1/C₂ → Q = CV → V = Q/C の順。

 第18回・動画あり

変圧器と実効値（電力が保存する）

電圧は巻数比、電流はオーム、一次電流は電力保存。3手で終わります。

 第19回・動画あり

光電効果（限界波長とエネルギー）

E = hc/λ から W を引くだけ。限界波長は λ₀ = hc/W。

 第20回・動画あり

放射性崩壊と半減期（回数で数える）

n = 時間 ÷ 半減期、残る割合は (1/2)ⁿ。逆問題は指数を読むだけ。
