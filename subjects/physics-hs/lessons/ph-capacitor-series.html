第17回　コンデンサーの直列接続（電気量が共通）

2.0 μFと3.0 μFのコンデンサーを直列につなぎ、全体に100 Vを加えた。合成容量、各コンデンサーの電圧、蓄えられる静電エネルギーを求めよ。

抵抗とコンデンサーで公式が逆になる混乱は、「共通なものは何か」で消えます。

解法の型

  1. 共通なものを言う。直列は電気量Qが共通、並列は電圧Vが共通です。
  2. 合成→Qの順。1/C = 1/C₁ + 1/C₂ を出してから Q = CV。
  3. 各電圧に戻す。V₁ = Q/C₁、V₂ = Q/C₂。和が全体の電圧になります。

解答手順

  1. 合成容量を出す
    1/C = 1/2.0 + 1/3.0 = 5/6 → C = 1.2 μF

    小さい方より小さくなる。

  2. 共通の電気量
    Q = CV = 1.2 × 10⁻⁶ × 100 = 1.2 × 10⁻⁴ C

    両方に同じQ。

  3. 各電圧に戻す
    V₁ = Q/C₁ = 60 V、V₂ = Q/C₂ = 40 V

    和は100 Vで合う。

  4. 静電エネルギー
    U = ½CV² = ½ × 1.2 × 10⁻⁶ × 100² = 6.0 × 10⁻³ J

    全体の値で計算。

検算：V₁ + V₂ = 100 Vで全体の電圧に一致。容量が小さい2.0 μF側に大きい60 Vがかかる点も V = Q/C と整合します。

差がつく2行

  1. 抵抗の直列は R₁ + R₂、コンデンサーの直列は逆数の和。入れ替わるので「共通なものは何か」で判断します。
  2. 静電エネルギーは各コンデンサーで ½QV を出して足しても同じ値になります。

覚えるべきこと（在庫に入れる1行）

コンデンサーの直列は Q が共通、並列は V が共通。

類題（翌日、何も見ずに）

  1. 2.0 μFと3.0 μFを並列にして100 Vを加えたときの全電気量を求めよ。
    答え

    C = 5.0 μF、Q = 5.0 × 10⁻⁴ C

  2. 直列のとき2.0 μFに蓄えられる静電エネルギーを求めよ。
    答え

    U₁ = ½QV₁ = ½ × 1.2 × 10⁻⁴ × 60 = 3.6 × 10⁻³ J

解説の全文を読む
  1. こんにちは。知多丸の落ちこぼれ救済チャンネルです。難関大学に合格して、錯覚資産を手に入れて、一流企業に入社しよう。今日の問題です。2.0マイクロファラドと3.0マイクロファラドのコンデンサーを直列につなぎ、全体に100ボルトを加えました。合成容量、各コンデンサーの電圧、そして蓄えられる静電エネルギーを求めてください。
  2. 型はこうです。直列のコンデンサーは、まず電気量が共通、と押さえます。合成容量は逆数の和で出し、キュー イコール シー ブイ で共通の電気量を求めます。あとは各コンデンサーに ブイ イコール キュー 割る シー で戻すだけです。抵抗と逆になるので、共通なのは何か、を毎回口に出します。
  3. まず合成容量です。1割る2.0たす1割る3.0は6分の5。逆数をとって1.2マイクロファラドです。直列では、いちばん小さい容量よりさらに小さくなります。
  4. 次に共通の電気量です。キュー イコール シー ブイ で、1.2かける10のマイナス6乗かける100。1.2かける10のマイナス4乗クーロンです。
  5. 各電圧に戻します。2.0マイクロファラド側は60ボルト、3.0マイクロファラド側は40ボルトです。和はちょうど100ボルトです。
  6. 静電エネルギーは、2分の1 シー ブイ2乗。0.5かける1.2かける10のマイナス6乗かける100の2乗で、6.0かける10のマイナス3乗ジュールです。
  7. 検算です。各電圧の和が全体の電圧100ボルトになっているか。60たす40で100ボルト。合っています。また容量が小さいほうに大きい電圧がかかっているので、ブイ イコール キュー 割る シー の関係とも矛盾しません。
  8. 差がつく2行です。まず、抵抗とコンデンサーでは直列と並列の公式が入れ替わります。抵抗の直列は足し算、コンデンサーの直列は逆数の和です。それから、静電エネルギーは各コンデンサーごとに計算して足しても同じ値になります。確認したいときは両方で出してみてください。
