第6回　等速円運動（向心力の立式）

質量0.20 kgの小球が、半径0.50 mの円周上を速さ2.0 m/sで等速円運動している。向心加速度と向心力の大きさを求めよ。

円運動は「中心向きに ma を用意する」と考えると、立式が一本化されます。

解法の型

  1. 向心加速度 a = v²/r。向きは常に円の中心向きです。
  2. 向心力 F = mv²/r。実際にはたらく力（張力・摩擦・重力）の合力です。
  3. 周期は T = 2πr/v。速さと半径から出せます。

解答手順

  1. 向心加速度を出す
    a = v²/r = 2.0² / 0.50 = 8.0 m/s²

    向きは中心向き。

  2. 向心力を出す
    F = ma = 0.20 × 8.0 = 1.6 N

    F = mv²/r でも同じ。

  3. 周期を確認する
    T = 2πr/v = 2π × 0.50 / 2.0 ≒ 1.6 s

    1周の時間。

  4. 答えをまとめる
    a = 8.0 m/s²、F = 1.6 N

    向きはどちらも中心向き。

検算：ω = v/r = 4.0 rad/s、a = rω² = 8.0 m/s²。2通りで一致すれば正解です。

差がつく2行

  1. 速さが一定でも向きが変わるので加速度は0ではありません。
  2. 遠心力は回転する観測者の立場で導入する見かけの力。地上から見る式には書きません。

覚えるべきこと（在庫に入れる1行）

向心加速度は v²/r（= rω²）、向心力 F = mv²/r は実在する力の合力。

類題（翌日、何も見ずに）

  1. 同じ小球が速さ4.0 m/sで同じ円を回るときの向心力を求めよ。
    答え

    F = 0.20 × 4.0²/0.50 = 6.4 N（速さ2倍で4倍）

  2. 半径を2倍の1.0 mにして速さ2.0 m/sのままにしたときの向心力を求めよ。
    答え

    F = 0.20 × 4.0/1.0 = 0.80 N
