第9回　直流回路（合成抵抗と電圧の分配）

起電力12 Vの電池に4.0 Ωの抵抗を直列につなぎ、その先に6.0 Ωと3.0 Ωを並列につないだ。回路を流れる電流と、並列部分にかかる電圧を求めよ（内部抵抗は無視）。

回路は計算の順番を固定すれば、枝の数が増えても崩れません。

解法の型

  1. 並列を先にまとめる。1/R = 1/R₁ + 1/R₂。積/和でも計算できます。
  2. 全電流 I = V / R全。
  3. 各部分に戻す。直列部分は同じ電流、並列部分は同じ電圧。

解答手順

  1. 並列を合成する
    1/R = 1/6.0 + 1/3.0 = 1/2.0 → R = 2.0 Ω

    積/和 = 18/9 = 2.0

  2. 全体の合成抵抗
    R全 = 4.0 + 2.0 = 6.0 Ω

    直列は足すだけ。

  3. 全電流を出す
    I = 12 / 6.0 = 2.0 A

    オームの法則。

  4. 並列部分の電圧
    V = 2.0 × 2.0 = 4.0 V

    答え：I = 2.0 A、V = 4.0 V

検算：直列部分8.0 V＋並列部分4.0 V＝12 V、枝の電流0.67 A＋1.33 A＝2.0 Aで一致します。

差がつく2行

  1. 並列では電流が抵抗の逆比（6.0 Ω と 3.0 Ω なら 1 : 2）。
  2. 消費電力は P = VI = I²R = V²/R。どれを使うかは与えられた量で決めます。

覚えるべきこと（在庫に入れる1行）

並列を先にまとめ、全体の合成抵抗で全電流、あとは RI で各部分に戻す。

類題（翌日、何も見ずに）

  1. 6.0 Ωの枝と3.0 Ωの枝に流れる電流をそれぞれ求めよ。
    答え

    6.0 Ω：0.67 A、3.0 Ω：1.3 A

  2. 4.0 Ωの抵抗で消費される電力を求めよ。
    答え

    P = I²R = 2.0² × 4.0 = 16 W

解説の全文を読む
  1. こんにちは。知多丸の落ちこぼれ救済チャンネルです。難関大学に合格して、錯覚資産を手に入れて、一流企業に入社しよう。今日の問題です。起電力12ボルトの電池に、4.0オームの抵抗を直列につなぎ、その先に6.0オームと3.0オームを並列につなぎます。回路を流れる電流と、並列部分にかかる電圧を求めてください。電池の内部抵抗は無視します。
  2. 型は3手順です。並列部分を先に1つの抵抗にまとめる。次に全体の合成抵抗から全電流を出す。最後に アールアイ で各部分の電圧に戻します。
  3. 並列部分をまとめます。6分の1たす3分の1は2分の1なので、2.0オーム。積割る和でも、18割る9で2.0オームです。
  4. 全体は直列なので足します。4.0たす2.0で6.0オームです。
  5. 全電流は 12割る6.0 で2.0アンペアです。
  6. 並列部分の電圧は、合成抵抗2.0オームかける2.0アンペアで4.0ボルトです。答えは、電流2.0アンペア、電圧4.0ボルトです。
  7. 検算です。電圧の合計を見ます。4.0オームにかかる電圧は 4.0かける2.0の8.0ボルト。並列部分は4.0ボルト。合計12ボルトで、起電力と一致します。さらに、並列の枝の電流は 4.0割る6.0 のおよそ0.67アンペアと、4.0割る3.0 のおよそ1.3アンペアで、合計2.0アンペアです。
  8. 差がつく2行です。並列部分では、抵抗が小さい枝に大きい電流が流れます。電流は抵抗の逆比になります。それから、消費電力は ピー イコール ブイアイ、または アイ2乗アール で計算できます。
  9. 在庫に入れる1行です。並列を先にまとめ、全体の合成抵抗で全電流、あとは アールアイ で各部分に戻す。チャンネル登録をして、次の動画でも一緒に、要領よく積み上げていきましょう。
