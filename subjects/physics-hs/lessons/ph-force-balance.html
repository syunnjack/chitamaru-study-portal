第1回　斜面上のつり合い（力の書き込み順）

傾き30°のあらい斜面上に質量2.0 kgの物体が静止している。垂直抗力Nと静止摩擦力fを求めよ（g = 9.8 m/s²）。

物理が苦手な人の9割は、図に力を書き込む順番が決まっていません。まずここを固定します。

解法の型

  1. 力を書く順を固定する。重力 → 垂直抗力 → 摩擦力 → 張力。書き忘れが消えます。
  2. 軸を斜面に合わせる。斜面に平行な方向と垂直な方向でつり合いの式を立てます。
  3. 分解するのは重力だけ。斜面方向 mg sinθ、垂直方向 mg cosθ。

解答手順

  1. 重力を分解する
    mg = 2.0 × 9.8 = 19.6 N

    斜面方向と垂直方向に分ける。

  2. 垂直方向のつり合い
    N = mg cos30° = 19.6 × 0.866 ≒ 17 N

    cos30° = √3/2

  3. 斜面方向のつり合い
    f = mg sin30° = 19.6 × 0.50 = 9.8 N

    静止しているので合力ゼロ。

  4. 答えをまとめる
    N ≒ 17 N、f = 9.8 N

    摩擦力は斜面を上向き。

検算：f / N = tan30° ≒ 0.58。sinとcosを入れ違えるとこの比が1.7になるので、比で検算できます。

差がつく2行

  1. 静止摩擦は f ≦ μN。f = μN と書けるのは滑り出す直前だけです。
  2. θが大きくなるほど mg sinθ は増え、N = mg cosθ は減ります。滑りやすくなる理由です。

覚えるべきこと（在庫に入れる1行）

斜面では軸を斜面に合わせ、重力だけを mg sinθ と mg cosθ に分解する。

類題（翌日、何も見ずに）

  1. 傾き60°の斜面上で質量2.0 kgの物体が静止しているとき、静止摩擦力の大きさを求めよ。
    答え

    f = 19.6 × sin60° ≒ 17 N

  2. 同じ斜面（30°）で物体が滑り出す直前、動摩擦係数の値の目安を答えよ。
    答え

    μ = tan30° ≒ 0.58
