第2回　運動方程式（2物体と糸の張力）

なめらかな水平面上で、質量3.0 kgの物体Aと質量2.0 kgの物体Bを糸でつなぎ、Aを10 Nの力で水平に引く。加速度aと糸の張力Tを求めよ。

連結物体は「全体→1つ」の順で式を立てると、張力が必ず出ます。

解法の型

  1. 全体で加速度。(m₁ + m₂)a = F。糸の張力は内力なので式に出てきません。
  2. 1物体を切り出して張力。引かれる側のBについて m₂a = T。
  3. 正の向きを決めてから式を書く。加速する向きを正にそろえます。

解答手順

  1. 全体で運動方程式
    (3.0 + 2.0) a = 10

    2物体は同じ加速度で動く。

  2. 加速度を求める
    a = 10 / 5.0 = 2.0 m/s²

    向きは引く向き。

  3. Bだけを切り出す
    2.0 × 2.0 = T

    Bにはたらく水平方向の力は張力だけ。

  4. 張力を求める
    T = 4.0 N

    答え：a = 2.0 m/s²、T = 4.0 N

検算：Aを切り出して 10 − 4.0 = 3.0 × 2.0 が成り立つか確認します。一致すれば正解です。

差がつく2行

  1. T = F × m₂/(m₁ + m₂)。後ろの物体の質量比で決まります。
  2. Bの側を引くと T = F × 3.0/5.0 = 6.0 N。前後を入れかえたら計算し直します。

覚えるべきこと（在庫に入れる1行）

全体で加速度、1物体を切り出して張力。内力は全体の式に出てこない。

類題（翌日、何も見ずに）

  1. 同じ2物体をBの側から10 Nで引いたときの張力を求めよ。
    答え

    T = 10 × 3.0/5.0 = 6.0 N

  2. Aを20 Nで引いたときの加速度と張力を求めよ。
    答え

    a = 4.0 m/s²、T = 8.0 N

  2. 型は2手順です。まず2物体をまとめて1つの物体と見て加速度を出します。糸の張力は内力なので消えます。次に片方だけを切り出して、その物体の運動方程式から張力を出します。
  3. まず全体で考えます。3.0たす2.0の5.0キログラムに10ニュートン。2物体は糸でつながっているので同じ加速度です。
  4. エー は 10割る5.0で、2.0メートル毎秒毎秒です。向きは引いた向きです。
  5. 次にビーだけを切り出します。ビーにはたらく水平方向の力は糸の張力だけなので、2.0かける2.0イコール ティー です。
  6. ティー は4.0ニュートンです。答えは、加速度2.0メートル毎秒毎秒、張力4.0ニュートンです。
