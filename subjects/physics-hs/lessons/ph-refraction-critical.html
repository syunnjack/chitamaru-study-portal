第14回　屈折の法則と全反射（臨界角）

屈折率1.5のガラスに、空気中から45°で光を入射させる。ガラス中の屈折角を求めよ。また、ガラスから空気へ出るときの臨界角を求めよ。

屈折で迷うのは、どちらで割るかだけ。「密な側は角が小さい」で毎回確認します。

解法の型

  1. 式は1本。n₁ sinθ₁ = n₂ sinθ₂。空気は n = 1.0 とします。
  2. 向きを確認。屈折率が大きい媒質の中では角度が小さい。答えの妥当性はこれで判定します。
  3. 全反射は密→疎だけ。sinθc = n₂ / n₁。疎から密では起こりません。

解答手順

  1. 屈折の式を立てる
    1.0 × sin45° = 1.5 × sinθ₂

    空気は n = 1.0。

  2. 屈折角を求める
    sinθ₂ = 0.71 / 1.5 ≒ 0.47 → θ₂ ≒ 28°

    ガラス中では角が小さい。

  3. 臨界角の式
    sinθc = n₂ / n₁ = 1.0 / 1.5 ≒ 0.67

    ガラス→空気なので密→疎。

  4. 臨界角を求める
    θc ≒ 42°

    42°より大きい入射角では全反射。

検算：ガラス中の28°は入射角45°より小さい。密な媒質ほど角が小さいので向きは正しいです。逆にすると sinθ > 1 になり計算できません。

差がつく2行

  1. 屈折しても振動数は変わりません。媒質中では λ と v が 1/n 倍になります。
  2. 全反射は密から疎へ進むときだけ。空気→ガラスでは絶対に起こりません。

覚えるべきこと（在庫に入れる1行）

屈折は n₁sinθ₁ = n₂sinθ₂、全反射は sinθc = n₂/n₁（密→疎のみ）。

類題（翌日、何も見ずに）

  1. 屈折率1.5のガラス中での光の速さを求めよ（真空中は3.0 × 10⁸ m/s）。
    答え

    v = 3.0 × 10⁸ / 1.5 = 2.0 × 10⁸ m/s

  2. 屈折率1.33の水から空気へ出るときの臨界角のsinの値を求めよ。
    答え

    sinθc = 1.0 / 1.33 ≒ 0.75（θc ≒ 49°）
