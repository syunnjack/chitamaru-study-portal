第12回　弦の固有振動（基本振動から数える）

長さ0.60 mの弦の両端を固定し、弦を伝わる波の速さが120 m/sであるとき、基本振動の振動数と3倍振動の振動数を求めよ。

弦の公式を丸暗記すると、閉管の問題で必ず崩れます。図から波長を出す手順に変えます。

解法の型

  1. まず λ₁ = 2L。両端固定の基本振動は、弦の長さが半波長ぶんです。
  2. f₁ = v / λ₁。基本振動数だけ数値で出します。
  3. あとは倍にする。n倍振動は fₙ = n f₁。波長は λₙ = 2L / n。

解答手順

  1. 基本振動の波長
    λ₁ = 2L = 2 × 0.60 = 1.2 m

    腹1個ぶんの図をかく。

  2. 基本振動数
    f₁ = v / λ₁ = 120 / 1.2 = 100 Hz

    ここまでで型は終わり。

  3. 3倍振動
    f₃ = 3 f₁ = 3 × 100 = 300 Hz

    波長は λ₃ = 1.2 / 3 = 0.40 m

  4. 答えをまとめる
    f₁ = 100 Hz、f₃ = 300 Hz

    腹の数は n 個。

検算：λ₃ = 0.40 mの半波長は0.20 m。これが3個で0.60 m＝弦の長さと一致します。

差がつく2行

  1. 弦を伝わる速さvは張力と線密度で決まります。振動数を上げても v は変わらず λ が短くなります。
  2. 両端固定なら λ₁ = 2L、片方が自由端（閉管など）なら λ₁ = 4L。図をかけば取り違えません。

覚えるべきこと（在庫に入れる1行）

弦は「まず λ₁ = 2L → f₁ = v/λ₁ → n 倍」の順に出す。

類題（翌日、何も見ずに）

  1. 長さ0.50 m、波の速さ200 m/sの両端固定の弦の基本振動数を求めよ。
    答え

    f₁ = 200 / 1.0 = 200 Hz

  2. 上の弦の2倍振動の波長を求めよ。
    答え

    λ₂ = 2L / 2 = 0.50 m
