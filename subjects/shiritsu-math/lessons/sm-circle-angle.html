第4回　円と角（円周角・接弦定理・内接四角形）

円 O の周上に4点 A, B, C, D がこの順にある。∠BAC = 34°, ∠ACD = 56° のとき、(1) ∠BDC の大きさ、(2) ∠ABD + ∠ADB の値を求めよ。また (3) 円に内接する四角形の対角の和を答えよ。

円の角度は3つの定理しか使いません。どの弧かを毎回言うことです。

解法の型

  1. どの弧に対する角かを言う。弧 BC の円周角、と口に出します。
  2. 同じ弧の円周角は等しい。離れた角どうしがつながります。
  3. 内接四角形は対角の和 180°。四角形が見えたら必ず使います。

解答手順

  1. (1) 同じ弧をとらえる
    ∠BAC と ∠BDC はどちらも弧 BC の円周角

    だから等しい。

  2. (1) 答えを出す
    ∠BDC = ∠BAC = 34°

    34度。

  3. (2) 三角形の内角の和
    △ABD で ∠ABD + ∠ADB = 180° − ∠BAD

    ∠BAD = ∠BAC + ∠CAD。

  4. (2) ∠BAD を求める
    ∠CAD = ∠ACD に対応する弧から 56° の関係を使い、∠BAD = 34° + 56° = 90°、よって和は 90°

    答え90度。

  5. (3) 内接四角形
    対角の和は 180°（∠A + ∠C = 180°, ∠B + ∠D = 180°）

    定理。

検算：求めた角を図に書き込み、各三角形の内角の和が 180°になるかを確認します。

差がつく2行

  1. 接弦定理：接線と弦のつくる角は、その弦に対する円周角と等しくなります。
  2. 方べきの定理：2 弦が P で交わるとき PA·PC = PB·PD。長さの問題で最速です。

覚えるべきこと（在庫に入れる1行）

同じ弧の円周角は等しい。内接四角形の対角の和は180°。中心角は2倍。

類題（翌日、何も見ずに）

  1. 弧 AB に対する中心角が 100°のとき、円周角を求めよ。
    答え

    50°

  2. 円に内接する四角形で ∠A = 105°のとき ∠C を求めよ。
    答え

    75°

解説の全文を読む
  1. こんにちは。知多丸の落ちこぼれ救済チャンネルです。難関大学に合格して、錯覚資産を手に入れて、一流企業に入社しよう。今日の問題です。円オーの周上に4点エー、ビー、シー、ディーがこの順にあります。角ビーエーシーが34度、角エーシーディーが56度のとき、1、角ビーディーシーの大きさ。2、角エービーディーたす角エーディービーの値。3、円に内接する四角形の対角の和を求めます。
  2. 型はこうです。円の角度問題は3つの定理しか使いません。同じ弧に対する円周角は等しい。内接四角形の対角の和は180度。中心角は円周角の2倍で、直径に対する円周角は90度。図に弧を書き込んで、どの弧に対する角なのかを毎回口で言う。これだけで角度は追えます。
  3. 1です。角ビーエーシーと角ビーディーシーは、どちらも弧ビーシーに対する円周角です。だから等しくなります。
  4. よって角ビーディーシーは34度です。角エーシーディーの56度はここでは使いません。使わない条件があるのは普通のことです。
  5. 2です。三角形エービーディーの内角の和は180度なので、角エービーディーたす角エーディービーは180度ひく角ビーエーディーです。
  6. 角エーシーディーは弧エーディーの円周角で、角エービーディーと等しくなります。図の関係から角ビーエーディーは34度たす56度の90度。よって残りの2角の和は180度ひく90度で90度です。
  7. 3です。円に内接する四角形は、向かい合う角の和が180度。これは中心角が1周で360度であることから導けます。
  8. 検算です。角度を全部足して確かめます。三角形の内角の和は180度、四角形は360度、内接四角形の対角の和は180度。求めた角を図に書き込んで、どの三角形でも合計が180度になっているかを確認します。1か所でも合わなければ、弧の取りちがえです。
  9. 差がつく2行です。ひとつ目、接弦定理です。接線と弦のつくる角は、その弦に対する円周角に等しい。接点が出てきたら必ずこれを疑います。ふたつ目、方べきの定理です。2つの弦がピーで交わるとき、ピーエーかけるピーシーはピービーかけるピーディー。長さの問題ではこれが最速です。
  10. 在庫に入れる1行です。同じ弧の円周角は等しい。内接四角形の対角の和は180度。中心角は円周角の2倍。チャンネル登録をして、次の動画でも一緒に、要領よく積み上げていきましょう。
