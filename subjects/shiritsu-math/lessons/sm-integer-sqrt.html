第7回　整数（積の形にして約数を当てる）

√(n² + 45) が整数となる自然数 n をすべて求めよ。

整数問題の9割は「積の形にして約数を当てる」だけです。

解法の型

  1. = m² とおく。整数になるという条件を式にします。
  2. 積の形にする。m² − n² = (m−n)(m+n) = 45。
  3. 約数の組を全部書く。45 = 1×45, 3×15, 5×9。

解答手順

  1. 式にする
    n² + 45 = m²（m は自然数）→ m² − n² = 45

    移項する。

  2. 積の形にする
    (m − n)(m + n) = 45

    2乗の差の因数分解。

  3. 約数の組を書く
    (m−n, m+n) = (1,45), (3,15), (5,9)

    m−n < m+n。

  4. n を求める
    n = (差)/2 → 22, 6, 2

    答え n = 2, 6, 22。

検算：n = 2 → 49 = 7²、n = 6 → 81 = 9²、n = 22 → 529 = 23²。すべて確認できます。

差がつく2行

  1. m − n と m + n は偶奇が一致します。積が偶数のときは両方偶数の組だけを調べます。
  2. 積の形にできない整数問題は、不等式で候補を数個に絞ってから調べます。

覚えるべきこと（在庫に入れる1行）

整数問題は積の形にして約数を当てる。偶奇の一致を確認する。

類題（翌日、何も見ずに）

  1. √(n² + 16) が整数となる自然数 n を求めよ。
    答え

    n = 3（25 = 5²）

  2. (m−n)(m+n) = 21 のとき考えられる組を書け。
    答え

    (1,21), (3,7)

解説の全文を読む
  1. こんにちは。知多丸の落ちこぼれ救済チャンネルです。難関大学に合格して、錯覚資産を手に入れて、一流企業に入社しよう。今日の問題です。ルートエヌの2乗たす45が整数となる自然数エヌをすべて求めます。
  2. 型はこうです。整数問題の9割は、積の形にして約数を当てる作業です。整数になるという条件をエムの2乗とおき、移項するとエムの2乗ひくエヌの2乗イコール45。左辺は因数分解できてエムひくエヌかけるエムたすエヌ。積が45なので、約数の組を全部書き出す。ここまでが型です。
  3. ルートの中が平方数になればよいので、エヌの2乗たす45イコールエムの2乗とおきます。移項してエムの2乗ひくエヌの2乗イコール45です。
  4. 左辺は2乗の差なので、エムひくエヌかけるエムたすエヌ。これが45です。
  5. 45の約数の組は、1と45、3と15、5と9。エムひくエヌの方が小さいので、この3組です。
  6. エヌは2つの数の差の半分です。45ひく1の半分で22、15ひく3の半分で6、9ひく5の半分で2。よってエヌは2、6、22の3つです。
  7. 検算です。それぞれ代入します。2の2乗たす45は49で7の2乗。6の2乗たす45は81で9の2乗。22の2乗たす45は484たす45で529、これは23の2乗です。3つとも整数になりました。
  8. 差がつく2行です。ひとつ目、偶奇の確認です。エムひくエヌとエムたすエヌは必ず偶奇が一致します。だから積が45のように奇数なら両方奇数、積が偶数なら両方偶数の組しか使えません。ここを見落とすと、存在しない解を書いてしまいます。ふたつ目、整数問題のもう1つの型は範囲の絞り込み。エックスワイイコール定数の形にできないときは、不等式で候補を数個に絞ってから調べます。
