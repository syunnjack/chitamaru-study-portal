第5回　Part5 語彙とコロケーション（相性で覚える）

We would like to ------- an order for 200 units of the new keyboard.　(A) place (B) make (C) take (D) do

語彙問題は単語の意味ではなく、組み合わせの暗記量で決まります。

解法の型

  1. 空所の相手の名詞を見る。order / reservation / appointment など。
  2. セットで暗記した組み合わせを当てる。意味の近さでは決められません。
  3. ビジネス頻出10組を先に固める。下の「差がつく」を参照。

解答手順

  1. 相手の名詞を確認
    an order

    「注文」を〜する。

  2. 決まった組み合わせを思い出す
    place an order = 注文する

    make an order は一般的でない。

  3. ほかを消す
    take an order は「注文を受ける」

    立場が逆になる。

  4. 答えを選ぶ
    (A) place

    We would like to place an order …

検算：注文する側はplace an order、受ける側はtake an order。立場で確認します。

差がつく2行

  1. make a reservation（予約する）、attend a meeting（出席する）、meet a deadline（締め切りを守る）。
  2. submit the form to the office、register for the seminar のように前置詞ごと覚えます。

覚えるべきこと（在庫に入れる1行）

語彙問題は意味ではなく相性。place an order のように動詞＋名詞をセットで覚える。

類題（翌日、何も見ずに）

  1. I would like to ( make / do ) a reservation for two nights. を選べ。
    答え

    make a reservation

  2. Please ( submit / submit to ) the report to the head office by Friday. を選べ。
    答え

    submit（submit A to B の形）

解説の全文を読む
  1. こんにちは。知多丸の落ちこぼれ救済チャンネルです。難関大学に合格して、錯覚資産を手に入れて、一流企業に入社しよう。今日の問題です。Part5の問題です。ウィー ウッド ライク トゥー、空所、アン オーダー フォー 200 ユニッツ オブ ザ ニュー キーボード。選択肢は、エー プレイス、ビー メイク、シー テイク、ディー ドゥー。
  2. 型はこうです。語彙問題は意味の近さではなく、決まった組み合わせで決まります。動詞と名詞をセットで覚えるのが要領です。注文は プレイス アン オーダー です。
  3. 空所の相手は アン オーダー、注文です。
  4. 注文する、は プレイス アン オーダー です。メイク アン オーダー は自然な組み合わせではありません。
  5. テイク アン オーダー は、店側が注文を受ける、という意味になり、立場が逆です。
  6. 答えはエー、プレイス。ウィー ウッド ライク トゥー プレイス アン オーダー フォー 200 ユニッツ。
  7. 検算です。注文する側か受ける側かを確認します。ウィー ウッド ライク トゥー とあるので、注文する側です。プレイス アン オーダー が正しく、テイク アン オーダー では意味が反転します。
  8. 差がつく2行です。頻出の組み合わせを挙げます。メイク ア リザベーション、予約する。アテンド ア ミーティング、会議に出席する。ミート ア デッドライン、締め切りに間に合わせる。それから、サブミット と レジスター は前置詞のとり方が狙われます。
  9. 在庫に入れる1行です。語彙問題は意味ではなく相性。プレイス アン オーダー のように動詞と名詞をセットで覚える。チャンネル登録をして、次の動画でも一緒に、要領よく積み上げていきましょう。
