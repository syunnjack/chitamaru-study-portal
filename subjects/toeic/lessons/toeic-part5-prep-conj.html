第3回　Part5 前置詞と接続詞（後ろの形で決める）

------- the heavy rain last night, all morning deliveries arrived on schedule.　(A) Although (B) Despite (C) Because (D) However

Part5の頻出パターン。意味で迷う前に、後ろの形を見れば2択になります。

解法の型

  1. 後ろの形を見る。名詞だけなら前置詞、主語＋動詞なら接続詞。
  2. 意味は最後。形で2つに絞ってから、逆接か理由かを決めます。
  3. 副詞は接続できない。however / therefore は文と文をつなげません。

解答手順

  1. 後ろの形を見る
    the heavy rain last night → 名詞のかたまり

    主語＋動詞ではない。

  2. 接続詞を消す
    Although / Because は接続詞 → 不可

    後ろに文が必要。

  3. 副詞を消す
    However は副詞 → つなげない

    コンマだけでは文をつなげない。

  4. 答えを選ぶ
    (B) Despite

    「〜にもかかわらず」＋名詞

検算：後ろが名詞ならDespite、主語＋動詞ならAlthough。形と答えが1対1で対応します。

差がつく2行

  1. because of / due to / owing to は後ろに名詞。because は後ろに文です。
  2. during the meeting（前置詞）／while we were meeting（接続詞）。セットで覚えます。

覚えるべきこと（在庫に入れる1行）

後ろが名詞なら前置詞、主語＋動詞なら接続詞。however は文をつなげない。

類題（翌日、何も見ずに）

  1. ( During / While ) the presentation, please turn off your phones. を選べ。
    答え

    During（後ろが名詞）

  2. The event was canceled ( because / because of ) the typhoon. を選べ。
    答え

    because of（後ろが名詞）

動画の音声ナレーション

解説の全文を読む
  1. こんにちは。知多丸の落ちこぼれ救済チャンネルです。難関大学に合格して、錯覚資産を手に入れて、一流企業に入社しよう。今日の問題です。Part5の問題です。空所、ザ ヘビー レイン ラスト ナイト、オール モーニング デリバリーズ アライブド オン スケジュール。選択肢は、エー オールゾウ、ビー ディスパイト、シー ビコーズ、ディー ハウエバー。
  2. 型はこうです。空所の後ろが名詞だけなら前置詞。主語と動詞が続くなら接続詞。ハウエバー のような副詞は、2つの文をつなぐことはできません。
  3. 空所の後ろは ザ ヘビー レイン ラスト ナイト。名詞のかたまりです。主語と動詞ではありません。
  4. オールゾウ と ビコーズ は接続詞なので、後ろに主語と動詞が必要です。ここでは使えません。
  5. ハウエバー は副詞なので、名詞を伴って文の要素になることはできません。
  6. 答えはビー、ディスパイト。大雨にもかかわらず、配達は時間どおりに届いた、という意味になります。
  7. 検算です。もし後ろが イット レインド ヘビリー のように主語と動詞なら、答えは オールゾウ になります。後ろの形を変えると答えも変わる、という関係を確認しておけば、この型は忘れません。
  8. 差がつく2行です。ビコーズ オブ と デュー トゥー は前置詞のはたらきをします。それから、デュアリング は前置詞で、ホワイル は接続詞です。この2組は必ず狙われます。
  9. 在庫に入れる1行です。後ろが名詞なら前置詞、主語プラス動詞なら接続詞。ハウエバー は文をつなげない。チャンネル登録をして、次の動画でも一緒に、要領よく積み上げていきましょう。
