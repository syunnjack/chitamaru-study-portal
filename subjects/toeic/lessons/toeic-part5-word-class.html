第1回　Part5 品詞問題（選択肢を見る前に骨格）

All refund requests must be submitted ------- to the accounting team.　(A) direct (B) directly (C) direction (D) directs

Part5は30問を10分で抜けたい大問です。品詞問題は意味を読まずに形で解きます。

解法の型

  1. 選択肢の語尾で判定。-ly／-tion／-s が並んだら品詞問題。意味を考える前に形で解きます。
  2. 空所を隠す。文の骨格（S＋V）が完成しているかを見ます。
  3. 完成していれば副詞。足りないのが名詞なら名詞、名詞の前なら形容詞です。

解答手順

  1. 問題の種類を決める
    direct / directly / direction / directs

    語尾が違うだけ → 品詞問題

  2. 空所を隠す
    All refund requests must be submitted to the accounting team.

    これで文が完成している。

  3. 入るのは修飾語
    完成した文に足すのは副詞

    動詞 submitted を修飾する。

  4. 答えを選ぶ
    (B) directly

    「直接提出する」の意味。

検算：他の選択肢を入れて成立しないことを確認します。品詞問題は「消せる理由」を言えるかが勝負です。

差がつく2行

  1. 前置詞の直後は必ず名詞（of the direction）。動名詞も名詞扱いです。
  2. has recently announced、was quickly approved のように、助動詞と過去分詞の間には副詞が入ります。

覚えるべきこと（在庫に入れる1行）

選択肢の語尾がそろっていたら品詞問題。空所を隠して骨格が完成していれば副詞。

類題（翌日、何も見ずに）

  1. The manager reviewed the proposal ( careful / carefully ) before the meeting. を選べ。
    答え

    carefully（文が完成しているので副詞）

  2. We need your ( approve / approval ) before Friday. を選べ。
    答え

    approval（your の後ろは名詞）
