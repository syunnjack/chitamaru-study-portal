高校数学I・A｜暗記数学で解法の型をそろえる

【高校数学I】放物線の頂点は平方完成だけ／y = x² + 12x + 20

「頂点を求めよ」と言われたら平方完成。ほかの方法を探さないのが要領です。

【高校数学I】2次方程式は10秒で因数分解を見切る／x² − 7x + 5 = 0

因数分解を探す時間は10秒まで。出なければ即、解の公式に切り替えます。

【高校数学I】実数解の個数は解かずに判別式だけ／x² − 4x + 9 = 0

「個数を求めよ」は解いてはいけません。判別式の符号だけ見ます。

【高校数学I】正弦定理で辺を出す／A = 30°, C = 105°, BC = 4

角が2つ分かれば残り1つは引き算。あとは正弦定理に入れるだけです。

【高校数学I】三角形の成立条件は場合分け不要／3辺が 5, x+2, 8

3つの不等式を書く必要はありません。「差 < 残り < 和」の1行で終わります。

【高校数学I】仮平均法でズレだけ足す平均の出し方

3桁の足し算はしません。基準からのズレだけを足します。

【高校数学A】組合せは2つの道具で一瞬／₈₀C₇₇ と ₁₅C₉ + ₁₅C₁₀

Cの下が大きいときは、小さい方に置き換える。これだけで計算量が激減します。

【高校数学I】x²の係数が1でない平方完成は3拍子／y = 2x² − 12x + 5

まず係数でくくる。中でだけ平方完成する。最後にくくった数を戻す。

【高校数学I】定義域つき最大・最小は3点だけ調べる／0 ≦ x ≦ 3

グラフ全体を考えると迷います。見るのは「頂点・左端・右端」だけです。

【高校数学I】平行移動は「符号が逆」だけ覚える／検算は頂点

xの移動は符号が逆、yの移動はそのまま。迷ったら頂点で検算します。

【高校数学I】余弦定理か正弦定理かの見分け方／b=3, c=5, A=60°

「2辺とその間の角」なら余弦定理、「辺と向かい合う角が2組」なら正弦定理。

【高校数学I】高さが無くても面積は出る／S = ½bc sin A

高さを探して止まるのが失点の原因。2辺とはさむ角があれば面積は出ます。

【高校数学A】公約数・公倍数は素因数分解の指数で決まる／40 と 60

書き出しません。素因数分解して、指数の小さい方・大きい方を取るだけです。

【高校数学I・2次不等式】x² − 5x + 6 > 0／「＞0は外側、＜0は内側」だけ

不等号の向きで迷うのは、グラフのどちら側かを決めていないからです。

【高校数学I・データの分析】分散は「2乗の平均 − 平均の2乗」／2,4,6,8,10 の標準偏差

偏差を1つずつ書き出す前に、公式1本で終わらせます。

【高校数学A】「少なくとも1回」は余事象で引き算／さいころ2回で6が出る確率

「少なくとも」と書いてあったら、数え上げをやめて引き算に切り替えます。

【高校数学I】sinθ + cosθ が出たら2乗する／sinθcosθ の値

θ を求めようとすると詰まります。和が来たら、迷わず両辺を2乗。

【高校数学A】「隣り合う」はひとかたまり／6人でAとBが隣り合う並び方

数え上げようとすると死にます。「隣り合う」は縛ってひとかたまりにするだけ。

【高校数学A】不定方程式の整数解／3x + 5y = 1 をすべて求める

答えが無限にある方程式。でも書き方は3手順で1行に決まります。

【高校数学B】等差数列の和は平均 × 項数／初項3・公差5の第20項までの和

和の公式は2つ覚えなくていい。使う方を1つに固定するのが要領です。

【高校数学II】円の接線は置きかえるだけ／x² + y² = 25 上の点(3, 4)

接線は5秒で終わります。x² を x₁x、y² を y₁y に置きかえるだけ。

【高校数学II】3次関数の極値は微分してゼロ／x³ − 3x² − 9x + 5

極値でつまずく原因は1つ。値を出すのは f(x)、微分した式ではありません。

【高校数学II】対数は1つのログにまとめるだけ／log₂ 6 + log₂ 12 − log₂ 9

対数は公式を思い出す科目ではありません。真数を1つの数にする作業です。

【高校数学II】三角関数の合成は1つの sin にまとめるだけ／最大2・最小−2

サインとコサインが混ざったら、合成して1つのサインにするだけです。

【高校数学II】定積分で面積を出すコツは「上 − 下」／y = x² − 2x と x 軸で 4/3

面積は公式より前に、どちらが上かを決めるのが先です。

【高校数学B】等比数列の和は「公比をかけて引く」／初項3・公比2で S₈ = 765

公式の作り方を1回だけ手で確認すれば、二度と忘れません。

【高校数学B】漸化式 aₙ₊₁ = 2aₙ + 3 の一般項／特性方程式で等比にする

漸化式は型が5つだけ。今日はいちばん出る「かける定数＋定数」型です。

【高校数学III】極限の不定形は2択／√(n² + 3n) − n = 3/2

∞ − ∞ はそのままでは出ません。やることは1つだけです。

【高校数学III】置換積分は「かたまりを t にする」／∫₀¹ x√(x²+1) dx

どこを t にするかを見抜くだけの作業です。

【高校数学C】ベクトルのなす角は内積 ÷ 大きさの積／(2,1) と (1,3) で45°

内積の2つの顔（成分と図形）をつなぐだけです。

【高校数学C】複素数のかけ算は「大きさはかける、角はたす」／(1 + √3i)⁶ = 64

大きさと角に分けてしまえば、指数の計算より簡単になります。

【高校数学B】期待値と分散／さいころの目で V(X) = E(X²) − {E(X)}² = 35/12

分散は定義式で計算すると必ず時間が足りません。使う式は1本だけです。

【高校数学B】群数列は群末 n(n+1)/2 で挟む／100 は第14群の9番目

群数列でやることは1つだけ。群の終わりが通算で何番目かを出すだけです。

【高校数学III】積の微分と接線／y = x²eˣ の x = 1 で y = 3ex − 2e

接線は「通る点」と「傾き＝微分係数」だけ。聞かれ方が変わっても同じです。

【高校数学III】回転体の体積／y = √x を x 軸まわりに回して 8π

切り口は半径 y の円。その面積 πy² を足し集めるだけです。

【高校数学III】無限等比級数／1 + 1/3 + 1/9 + … = 3/2

無限に足しても答えが有限になる理由と、使う式1本を押さえます。

【高校数学C】内分点と重心／BC を 2:1 に内分は D(5,6)、重心は G(4,4)

内分は比をたすきにかけて足す。重心は3点の平均、それだけです。

【高校数学C】空間ベクトルのなす角／(1,1,0) と (0,1,1) で 60°

空間になっても平面と同じ式。成分が1つ増えるだけです。

【高校数学C】楕円の標準形／x²/9 + y²/4 = 1 は長軸6・焦点 (±√5, 0)

楕円は分母を見るだけで、長軸・短軸・焦点が全部決まります。

【高校数学I】四分位数は中央値→半分ずつの中央値／Q1=10、Q3=21、四分位範囲11

データの分析は手順を固定すれば取りこぼしません。

【高校数学I】相関係数は偏差の表で3つの合計だけ／答え r = 0.9

公式は長いですが、やることは偏差の表を1つ作るだけです。

【高校数学A】条件付き確率は分母を取り替えるだけ／赤5白3で 4/7、5/14、5/8

「もどさずに」と書いてあれば、残りの玉を数え直すだけです。

【高校数学I】2次関数の決定は頂点の形で置くだけ／頂点 (2, −3)、点 (4, 5) を通る

条件の書き方で、置く形が決まります。

【高校数学I】共有点の個数は判別式の符号だけ／y = x² + 3 と y = 2x + k

「共有点の個数」「接する」は、すべて判別式の話に翻訳できます。

【高校数学I】異符号の2解は「積 < 0」だけ／判別式を書かなくてよい理由

解を求めずに、係数の条件だけで決めます。

【高校数学I】3辺が分かれば角は余弦定理の逆／7, 8, 5 で ∠A = 60°

3辺が分かって角を聞かれたら、道は1本です。

【高校数学I】外接円の半径は「2R =」で書く／a = 6、A = 30° で R = 6

外接円と聞いたら正弦定理。書き方ひとつでミスが消えます。

【高校数学I】3辺だけならヘロンの公式／13, 14, 15 の面積は 84

3辺だけ与えられたときの最短ルートです。

【高校数学I】内接円の半径は S = rs だけ／5, 12, 13 で r = 2、R = 13/2

内接円は、面積を2通りで表すだけで出ます。

【高校数学I】鈍角の三角比は符号を先に決める／cos θ = −3/5 で sin θ = 4/5

符号を先に決めてしまえば、あとは相互関係の計算だけです。

【高校数学I】度数分布表の平均は階級値×度数／答え 22

元のデータが分からなくても、平均は出せます。

【高校数学I】外れ値があるときの代表値は中央値／平均が引っ張られる仕組み

数値を出すだけでなく、どれが適切かまで答えます。

【高校数学I】変量の変換は「平均は同じ式、標準偏差は割った数だけ」

データを全部計算し直す必要はありません。

【高校数学I】共分散は偏差の積の平均／4組のデータで 6.5

表を作れば、あとは足し算だけです。

【高校数学I】外れ値は四分位範囲の1.5倍で決める／32 は外れ値か

外れ値は、目で見て決めるのではなく基準で決めます。

【高校数学I】偏差値は「標準偏差いくつ分」／点差15と8でも同じ偏差値60

平均との差だけでは、科目をまたいで比べられません。

【高校数学A】反復試行は nCk × p^k／さいころ5回で3の倍数2回は 80/243

何回目に出るかを全部考える必要はありません。

【高校数学A】円順列は1人を固定するだけ／7人で720通り、隣り合うのは240通り

回転して同じ並びを重複して数えない工夫が1つだけあります。

【高校数学A】重複組合せは仕切りを入れるだけ／3種類から6本で28通り

数え上げようとすると大変ですが、置きかえると一瞬です。

【高校数学A】互除法は割ってあまりに置きかえるだけ／1071 と 1029 の最大公約数 21

素因数分解で手が止まる数でも、割り算の繰り返しなら確実です。

【高校数学II】加法定理は知っている角に分ける／sin 75° = (√6 + √2)/4

三角定規に出てこない角も、知っている角に分ければ出せます。

【高校数学II】点と直線の距離は代入して割るだけ／4/5 と 6/5

垂線を引いて交点を出す必要はありません。

【高校数学II】対数方程式は真数条件を先に書く／x = 2 だけが答え

出てきた2つの解のうち、1つは答えになりません。

【高校数学II】3次方程式は1つの解を代入で見つける／x = 1, 3, −2

3次方程式に解の公式は使いません。1つ見つけて割るだけです。

【高校数学II】相加相乗は積が定数のときだけ／x + 4/x の最小値は 4

微分を使わなくても1行で終わります。ただし使える条件があります。

【高校数学B】Σ はばらして公式／Σk(k+2) = n(n+1)(2n+7)/6

かっこのままでは計算できません。まず展開します。

【高校数学B】階差数列は a₁ に階差の和／2, 5, 10, 17 の一般項は n² + 1

等差でも等比でもない数列は、まず差を見ます。

【高校数学B】数学的帰納法は型で覚える／n³ + 2n が3の倍数の証明

証明問題は、書き方の型を覚えてしまえば怖くありません。

【高校数学B】二項分布は np と np(1−p) だけ／さいころ180回で平均30、標準偏差5

1回ずつ計算する必要はありません。公式2つで終わります。

【高校数学B】信頼区間は標本平均 ± 1.96 × σ/√n／65.6〜70.4 g

公式の形を1つ覚えるだけです。÷ √n を忘れないこと。

【高校数学III】部分積分は微分して簡単になる方を f に／∫x e^x dx = 1

かけ算の形の積分は、部分積分の合図です。

【高校数学III】合成関数の微分は外×中／(2x+1)⁵ の微分は 10(2x+1)⁴

展開する必要はありません。外から1枚ずつ剥がします。

【高校数学III】∞−∞ は有理化してから割る／√(x²+3x) − x = 3/2

そのまま代入すると ∞ − ∞。形を変えてから代入します。

【高校数学III】囲まれた面積は「上−下」／y = √x と y = x で 1/6

まず交点、次に上下の判定、最後に積分です。

【高校数学III】sin² の積分は半角で次数を下げる／答えは π/4

2乗のままでは積分できません。次数を下げます。

【高校数学C】垂直は内積0、平行はたすきがけ0／t = 2/3 と t = −6

垂直は足す、平行は引く。条件は式1本です。

【高校数学C】三角形の面積はたすきがけの半分／答えは 11/2

【高校数学C】双曲線は c² = a² + b²（足す）／焦点 (±5, 0)、漸近線 y = ±(4/3)x

【高校数学C】複素数の累乗は極形式／(1 + i)⁸ = 16

展開して8回かけるのは現実的ではありません。

高校受験数学｜入試で差がつく型

【高校入試】20項が1行で消える／1×2 + 2×3 + … + 20×21

足し算を並べる前に、各項を「差」に化けさせます。

【高校入試】斜辺への垂線は「面積2通り」で一発／AB=6, BC=8

相似で長々と解く前に、面積を2通りで書けば1行で出ます。

【高校入試・図形の証明】正方形2つと七角形の面積／74 + 30√3 cm²

材料は「正方形の等辺」「正方形の90°」「垂線の90°」だけ。角は足し引きで作ります。

【高校入試・円】直交する2弦と網目部分の面積／65π/8 + 2

交わる弦は方べきの定理。円の面積は r を出さず r² を出します。

【高校入試・因数分解】x^4 + 4 は平方の差にする／3問まとめ

たすきがけが効かない4乗の式は、（　）² −（　）² を作りにいきます。

【高校入試・軌跡】中点が動いてできる線は半径1/2の円／3π cm と 9/2 cm²

動く点と固定点の中点は、固定点から見て1/2に縮んだ図形をえがきます。

【高校入試・相似】面積比は辺の比の2乗／△ADE : 四角形DBCE = 4 : 5

平行線を見たら相似。比は「部分どうし」ではなく全体に直してから2乗します。

【高校入試】分数の和は差に直して打ち消す／1/(1·2) + … + 1/(9·10)

通分して9個たすのは負けです。差の形に直せば、真ん中が全部消えます。

【高校入試】放物線と直線でできる三角形の面積／y = x² と y = x + 2

入試の関数の大問は、この1行で終わります。½ ×（y切片）×（xの差）。

【高校入試】食塩水は食塩の重さで式を立てる／5%と12%で8%を350g

パーセントは足せません。混ぜても変わらないのは、食塩水と食塩の重さだけ。

【高校入試】速さの往復は時間で式を立てる／時速4kmと6kmで合計5時間

合計が時間で与えられたら、時間の式1本で終わります。

【高校入試】n/24 と 1080/n がともに整数となる n の個数／答え 6個

分数が整数、という条件は「倍数」「約数」に言いかえるだけです。

【高校入試】7で割ると4余り、9で割ると6余る自然数／4番目は249

余りではなく、あといくつで割り切れるかを見ると暗算で終わります。

【高校入試】n² + 60 が平方数になる自然数 n をすべて／2・14

平方数の条件は、積が定数の形に持ち込むだけです。

中学数学｜高校数学の土台になる計算の型

【中学数学】正負の数は符号を先に決める／(−3)² × (−2) + (−4)² ÷ (−8)

高校数学でつまずく原因の多くは、実はこの符号処理です。

【中学数学】一次方程式の文章題は x の置き方で決まる／12個で840円

文章題が苦手なのは才能ではなく、置き方の順番を知らないだけです。

【中学数学】連立方程式は消す文字を先に決める／2x + 3y = 12、3x − 2y = 5

連立方程式は考える問題ではなく、手順を固定すれば必ず解ける計算です。

【中学数学】1次関数の式は傾き→切片の順／2点 (1,3) と (4,9) で y = 2x + 1

1次関数の式を出す手順は、いつも同じ2ステップです。

【中学数学】三平方の定理／AB=5・BC=12 で AC=13、垂線は面積2通りで 60/13

斜辺は直角の向かい側。どの辺が斜辺かを見るだけです。

【中学数学】y = ax² の変化の割合は a(p+q) で一撃／y = 2x²、x が 1→4

変化の割合を毎回ていねいに計算するのは時間の無駄。1行で終わらせます。
