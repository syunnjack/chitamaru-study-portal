# 知多丸の落ちこぼれ救済チャンネル／チャンネルの土台と運用手順

チャンネル名：**知多丸の落ちこぼれ救済チャンネル**
サブタイトル：**難関大学に合格して、錯覚資産を手に入れて、一流企業に入社しよう！**

## 0. 最初に知っておくこと（重要）

YouTube には「チャンネル登録者だけに全動画を見せる」機能はありません。登録者限定にできるのは有料の**メンバーシップ**だけです。
そこで、このチャンネルは次の形にします。

- 動画はすべて**公開**（誰でも無料で見られる）
- **再生リスト**で科目・単元別に整理して「登録すれば続きが全部そろう」状態にする
- 動画の終わりとサイト・概要欄で**登録を促す**

つまり「登録すれば全部無料で見られる」は、**登録＝新作が自動で届く／シリーズが全部そろう**という導線で実現します。

## 1. チャンネル作成（Googleログインが必要）

1. https://www.youtube.com/ で Google アカウントにログイン
2. 右上アイコン → 「チャンネルを作成」→ 名前を `知多丸の落ちこぼれ救済チャンネル` にする
3. ハンドル（@）は `@chitamaru` 系の空いているものを取る（例：`@chitamaru-study`）
4. カスタマイズ → ブランディング
   - プロフィール写真：`assets/youtube/icon.png`
   - バナー画像：`assets/youtube/banner.png`（中央 1546×423 に文字が収まるよう作成済み）
   - 動画の透かし：`assets/youtube/icon.png`（表示タイミングは「動画全体」＝登録ボタンが常時出る）
5. カスタマイズ → 基本情報
   - 説明：下の「チャンネル説明文」をコピー
   - リンク：解説サイト（GitHub Pages）を1つ目に置く
6. 設定 → チャンネル → 詳細設定 → 「視聴者：子ども向けではない」を選ぶ（コメント欄と通知を使えるようにするため）

## 3. 再生リスト（この2本柱で始める）

| 再生リスト名 | 中身 | 並び |
|---|---|---|
| 高校数学I・A｜暗記数学で解法の型をそろえる | 高校数学17本 | 単元順（2次関数 → 図形と計量 → データ → 場合の数 → 整数） |
| 高校受験数学｜入試で差がつく型 | 高校入試8本 | 計算の工夫 → 図形 → 円 → 因数分解 → 軌跡 |

再生リストの説明文には必ず「この再生リストを上から順にやれば、この単元は終わります」と書く（登録の理由になる）。

## 4. アップロード時の設定（毎回同じにする）

- タイトル・概要欄・タグ：`youtube/metadata.md` からコピー（自動生成）
- サムネイル：`assets/youtube/thumbs/<動画名>.png`
- 再生リスト：上の表のとおりに追加
- 終了画面：最後の20秒に「チャンネル登録」＋「次の動画（同じ再生リスト）」を配置
- カード：解説ページへのリンクを1枚
- 公開方法：最初の10本は**予約投稿**で毎週同じ曜日・同じ時刻に出す（習慣化してもらうため）
- 言語：日本語／字幕：自動生成のあと誤字だけ直す

## 5. 学生を集めるための導線（優先順）

1. **タイトルに答えを入れる**（例「BH = 24/5」）。検索でクリックされるのは「答え合わせ」需要が大きい。
2. **1本1型**。1動画1テーマにして、再生リストで束ねる。
3. **ショート化**：各動画の「型」の場面（30〜50秒）を切り出して縦動画にし、本編へ誘導する。
4. **概要欄の1行目に解説ページ**。サイト → 動画 → 登録の往復を作る。
5. **コメントの質問を次の動画にする**。「あなたの問題を動画にします」と固定コメントに書く。
6. **投稿頻度を固定**（週2本など）。登録者の通知が来る曜日を覚えてもらう。

## 6. 自動アップロード（希望があれば）

YouTube Data API v3 で `videos/*.mp4` を一括アップロードできます。必要なのは次の3つです。

1. Google Cloud プロジェクトで YouTube Data API v3 を有効化
2. OAuth クライアント（デスクトップアプリ）を作成して `client_secret.json` を取得
3. 初回だけブラウザで承認（以後はリフレッシュトークンで自動）

用意ができれば、`youtube/videos.json` を読んでタイトル・概要欄・タグ・サムネイル・再生リストまで自動で設定するアップロードスクリプトを作ります。
